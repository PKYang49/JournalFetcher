3. 研究背景

  • 既有事實：[文內] cTnI 與 cTnT 在臨床上常被視為可互換，用於 myocardial injury / AMI 診斷。
  • 知識缺口：[文內] pilot studies 顯示 cTnI/cTnT ratio 可能因急性壞死性傷害、慢性/非壞死性傷害、type 1 vs type 2 AMI 而不同。
  • Research question：[文內] cTnI/cTnT ratio 是否是一個有生物意義的 construct，可區分心肌傷害類型與嚴重度，並改善 type 1 vs type 2 AMI 鑑別？

4. 研究設計與方法

  • P：三個 prospective studies：APACE、BASEL VIII、Maastricht healthy subcohort；main analysis n=9,704。[文內]
  • Index test：hs-cTnI/hs-cTnT ratio，主要為 Abbott Architect hs-cTnI / Roche Elecsys hs-cTnT；另以 Singulex Clarity、Siemens Centaur 內外部驗證。[文內]
  • Reference standard：central adjudicated cardiac diagnoses，分 no known cardiac disease、chronic cardiac disease、acute cardiac disease；AMI 再分 type 1 / type 2。[文內]
  • Outcome：ratio 在三大診斷群差異；type 1 vs type 2 AMI discrimination；實驗模型中 mild nonlethal vs lethal injury 的 ratio 方向。[文內]
  • 排除：缺 cTn 或低於 LoD 者排除；dialysis ESRD 排除。[文內]
  • 統計：log ratio；OLS regression；調整 cohort、age、sex、kidney function、risk factors、CVD、CV medication；restricted cubic splines；AUC/DeLong；mixed effects model；hierarchical testing。[文內]
  • Reference standard 限制：[無法完整核對] adjudication 的完整流程在 supplement；本 markdown 未提供。

5. 研究結果重點

  • Main cohort：865 無已知心臟病、6,701 慢性心臟病、2,138 急性心臟病；中位年齡67歲，女性30%。[文內]
  • Ratio 主結果：急性 2.06（95% CI 1.89–2.26），慢性 0.66（0.60–0.72），無已知 0.50（0.43–0.59）。[文內]
  • 外部驗證方向一致，但絕對值不同。[文內]
  • Type 1 vs type 2 AMI：加 ratio 後 AUC 0.70→0.73；加到 Neumann score 後 0.69→0.74。[文內]
  • 實驗模型：mild nonlethal injury cTnT-dominant；lethal injury cTnI-dominant。[文內]
  • 重要負面資訊：未提供可臨床使用的 prespecified cut-off、sensitivity/specificity、LR+、LR−、calibration、decision curve、net reclassification 或 patient outcome impact。[文內未提供]

6. 結果分類（CI + MCID / diagnostic utility）

  • 文內 prespecified MCID：無。[文內]
  • 對 AUC 改善的臨床 MCID：[推論] 對急診 AMI 分型，單純 AUC +0.03 通常不足以支持改變流程；若能提供明確 cut-off 且改善 downstream management，才有實務價值。
  • 分類：
    • 「急性 vs 慢性/無已知」的 biological association：POSITIVE，效果方向大且外部驗證一致。
    • 「type 1 vs type 2 AMI 臨床診斷增益」：IMPRECISE / early diagnostic signal。AUC 統計上增加，但臨床可用性未建立。
    • 「routine implementation」：目前 INCONCLUSIVE，缺乏 cut-off、LR、校準、臨床決策與 outcome 試驗。

7. 作者討論與評論

  • 作者主張：[文內] cTnI/cTnT ratio 挑戰 cTnI/cTnT 可互換的假設，可能幫助急性 vs 慢性傷害及 type 1 vs type 2 AMI 鑑別。
  • 作者承認限制：[文內] 可能 misclassification；storage/freeze-thaw 資訊不完整；不能外推 dialysis；實驗模型不能直接比較；模型不完全模擬臨床疾病；STEMI ED 族群不代表所有 STEMI。
  • 評估：作者在 conclusion 對 routine adoption 保持克制，這點合理；但 Clinical Implications / Roadmap 對「測兩個 biomarker」的未來價值敘事較積極，超過目前 AUC +0.03 與缺乏 cut-off 的證據強度。

9. 臨床建議

  • 可採用：可在 journal club、研究設計、診斷公司/實驗室策略討論中視為「cTnI 與 cTnT 可能反映不同 pathophysiology」的強訊號。
  • 不建議直接套用：不要用本篇 ratio 對個別病人直接診斷 type 1 vs type 2 AMI；不要跨 assay 套用 cutoff；不要用於 dialysis ESRD。
  • 實務建議：
    1. 目前臨床仍以症狀、ECG、serial delta、影像與整體臨床判斷區分 AMI subtype。
    2. 若院內同時有 hs-cTnI/hs-cTnT，ratio 可作研究性輔助資訊，不應單獨決策。
    3. 後續需要 assay-specific cutoff、LR、calibration、decision curve 與前瞻性管理試驗。
  • 證據強度：生物與關聯性證據中等偏強；臨床導入證據偏弱。

SKILL-C：診斷/生物標記驗證評讀

A. 補充技術細節

  • Reference standard：central adjudication 是優點，但 supplement 未提供，無法完整判斷是否有 incorporation bias。若 adjudication 使用臨床 cTnI/cTnT 或 serial troponin 資訊，index test 與 reference standard 可能不完全獨立。
  • Index test 盲法：[文內] investigational cTnI/cTnT measurement blinded to clinical diagnoses，這是優點。
  • Spectrum bias：存在。APACE 為急性胸痛/疑似 ACS，BASEL VIII 與 Maastricht 族群不同；主分析又排除低於 LoD 者，低風險族群代表性下降。
  • Cut-off：未建立。這是臨床應用最大缺口。
  • Failed/unreadable tests：低於 LoD 者主分析排除；APACE 排除 2,067/8,267，BASEL VIII 排除 703/4,219，Maastricht 排除 903/1,540。雖有 LoD/2 sensitivity analysis，但主分析族群已偏向 troponin 可測得者。
  • Assay portability：不佳。Architect、Clarity、Centaur 的 ratio 絕對值差很多，因此任何 cutoff 都必須 assay-pair specific。

C. 觀察性與模型偏差

  1. ratio 不是獨立新 biomarker

    • 問題：cTnI/cTnT ratio 是 cTnI 與 cTnT 的數學函數。
    • 文內證據：模型同時放入 cTnI、cTnT 與 log ratio。
    • 風險方向：AUC 改善可能反映非線性轉換或 interaction，而不是新增生物資訊。
    • 需要什麼才放心：預先指定模型、外部 calibration、decision curve、與只用 flexible cTnI/cTnT nonlinear terms 的比較。

  2. 主分析排除 LoD 以下者，可能造成 selection bias

    • 文內證據：大量低於 LoD 者排除，尤其 Maastricht 637/1,540 才進主分析。
    • 風險方向：高估 ratio 在真實低風險族群的可用性。
    • 需要什麼才放心：完整 cohort 的 prespecified handling、multiple imputation 或 censored biomarker modeling，而不只 LoD/2 sensitivity。

  3. Type 1 vs type 2 AMI 的 reference standard 本身困難

    • 文內證據：作者承認 type 1 vs type 2 AMI 是日常臨床重大挑戰。
    • 風險方向：若 type 2 AMI 或 acute myocardial injury 被 misclassified，AUC 可能被稀釋或扭曲。
    • 需要什麼才放心：獨立 adjudication protocol、observer agreement、是否使用 investigational assays、分歧處理流程。

  4. 時間依賴性會影響 ratio

    • 文內證據：late presenters ratio 較高；serial sampling 顯示 ratio 隨時間改變。
    • 風險方向：同一 cutoff 在症狀後 1 小時、3 小時、12 小時可能代表不同意義。
    • 需要什麼才放心：依 symptom-onset time 分層的 cutoff、LR、calibration。

  5. 腎功能與年齡是重要 effect modifier

    • 文內證據：年齡增加 ratio 下降；eGFR 越好 ratio 越高。
    • 風險方向：高齡、CKD、HF 族群可能更容易 cTnT-dominant，造成 type 2/chronic 方向偏移。
    • 需要什麼才放心：年齡/eGFR-specific thresholds，特別是 CKD stage 3–5 與 HFpEF/HFrEF 分層。

D. 實驗模型轉譯評估

優點：

  • mild nonlethal vs lethal injury 的方向與臨床 cohort 一致。
  • 包含 human iPS-derived cardiomyocytes、rat neonatal cardiomyocytes、human LV tissue。
  • 直接處理 cTnT retention、tropomyosin binding、fragmentation 的機轉。

限制：

  • human lethal mechanical injury 來自 single donor heart tissue，外推性有限。
  • neonatal rat cardiomyocytes 與 adult human ischemic myocardium 差距大。
  • 作者明確說 experimental cTn measurement 只能 semi-quantitative，不可直接與人體比較。
  • mild/lethal ischemic models 中，個別 cTnI 或 cTnT concentration 在 normoxia vs hypoxia 間未達統計顯著；主要訊號來自 ratio 方向。
  • n 很小，多為 biological replicates 3–5，適合機轉假說，不適合定量臨床推論。

紅旗清單

  • 設計：非前瞻性臨床決策試驗；未證明 ratio 改善 patient outcome、ED length of stay 或 angiography 選擇。
  • 診斷：未提供 cut-off、sensitivity/specificity、LR+、LR−、calibration。
  • 統計：AUC 增幅小；ratio 與 cTnI/cTnT 原始值數學相依。
  • 外推：dialysis ESRD 排除；低於 LoD 者大量排除；STEMI ED 族群不代表直接進 cath lab 者。
  • Assay：不同 hs-cTnI assay 的 ratio 絕對值不可互換。
  • 敘事：從「biologically meaningful」到「potential diagnostic value」合理；但到「改變 clinical practice/guideline」仍早。
  • COI：多家 troponin assay 公司 funding 與作者 honoraria，與「同時測兩項 troponin」的敘事方向一致。

反向解釋

  1. Ratio 可能主要反映疾病嚴重度與時間，而非病因

    • 支持：STEMI/NSTEMI ratio 高；late presenters ratio 更高。
    • 反對：調整後三大群仍有差異，實驗模型方向一致。

  2. cTnT-dominant 慢性狀態可能由腎功能/年齡/慢性結構性心臟病驅動

    • 支持：age 與 eGFR 均影響 ratio。
    • 反對：慢性與急性心臟病 baseline 腎功能大致相似，調整後訊號仍存在。

  3. AUC 改善可能是統計建模形式造成，而非真正新增資訊

    • 支持：ratio 是 cTnI 與 cTnT 的函數。
    • 反對：外部 cohort 與不同 assay 方向一致，且實驗模型提供生物合理性。

  4. 急性非 CAD 疾病 heterogeneity 稀釋或混淆解讀

    • 支持：tachyarrhythmia、acute HF、hypertensive crisis 等 ratio 較接近慢性。
    • 反對：這正符合作者主張：ratio 可能反映 necrotic vs non-necrotic injury，而非單純 acute label。

最終裁決

整體可信度：中等偏高，用於生物訊號與假說建立；中等偏低，用於立即臨床導入。

可採用的部分：

  • cTnI 與 cTnT 不應被視為完全相同的 pathophysiologic signal。
  • cTnI/cTnT ratio 可能有助於辨認壞死性、急性、type 1 AMI 方向的心肌傷害。
  • 值得設計前瞻性 diagnostic management trial。

不建議採用的部分：

  • 不應用本篇數字直接建立院內 cut-off。
  • 不應以 ratio 單獨判定 type 1 vs type 2 AMI。
  • 不應跨 assay 或跨平台套用 ratio。

若要改觀，最需要：

  1. Assay-specific、symptom-time-specific cutoff，附 sensitivity/specificity、LR+、LR−。
  2. 外部前瞻性 validation，含 calibration、decision curve、net reclassification。
  3. 將 ratio 納入臨床流程的 management trial，證明改善決策、資源使用或病人 outcome。

一句話結論：這篇很有說服力地挑戰 cTnI/cTnT 可互換性，但離臨床常規雙測仍差一個前瞻性決策試驗。
