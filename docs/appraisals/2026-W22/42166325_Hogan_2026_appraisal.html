3. 研究背景

作者指出 Fatmax 是 maximal fat oxidation 所在運動強度；Fatmax 訓練被認為可改善脂肪氧化、endurance performance 與代謝健康 [文內]。臨床與運動實務上，若能用單一次 graded exercise test 的 LT/GET 估計 Fatmax，可節省直接測量 substrate oxidation 的成本與時間。

知識缺口是：既有研究對 Fatmax 與 LT/GET 是否一致結論不一；前一篇 meta-analysis 只納入 14 篇、搜尋資料庫較少且要求兩閾值相關係數，可能排除許多可用研究 [文內]。

Research question：[文內] Fatmax 是否發生在與 LT/GET 相同的 exercise intensity？研究設計、受試者特性、營養狀態、測試流程與分析方法是否調節兩者差異？

4. 研究設計與方法

  • P：BMI <30、表面健康、無已知 cardiometabolic disease/cancer、未使用影響 substrate metabolism 藥物的成人或青少年健康族群。
  • I / Index：Fatmax，即 MFO 對應的運動強度。
  • C：LT / GET / VT，作為 moderate-to-heavy intensity transition surrogate。
  • O：Fatmax 與 LT/GET 對應 exercise intensity 的差異；單位包括 %VO2max、VO2 ml/kg/min、W、HR 等。
  • 搜尋：PubMed、MEDLINE、Embase、Scopus，自建庫至 2022-07-09，更新至 2025-01-20。
  • 篩選：title/abstract 與 full text 皆雙人獨立篩選，衝突由第三人解決。
  • 資料萃取：雙人獨立萃取；缺資料時聯絡作者。
  • RoB：依研究設計選工具，雙人評估，Cohen κ = 0.90。
  • 統計：random-effects multilevel meta-analysis，Hedges g SMD，REML；三層結構處理同研究多個 effect sizes。異質性用 multilevel I²；publication bias 用 funnel plot、Egger、trim-and-fill；leave-one-out sensitivity；23 個 univariate moderator analyses。
  • 主要限制：使用 study-level summary data，無法做 individual-level agreement。

6. 作者討論與評論重點

作者主訊息：整體而言 Fatmax 與 LT/GET 不應被視為同一強度；Fatmax 平均較低。但在特定條件下，例如 sedentary、<20 歲、短 fasting、treadmill、較長 stage 或兩次測試流程，兩者差異可能變小，LT/GET 或可作 surrogate [文內]。

作者承認限制：只納入 apparently healthy，不能外推肥胖或臨床疾病族群；異質性高；測量 Fatmax / LT / GET 方法不一致；只能做 univariate moderator；年長族群不足；summary data 無法評估個體層級 agreement [文內]。這些限制大致誠實，但 clinical/practical implication 仍略超出 group-level meta-analysis 的能力。

8. 臨床建議

  • 可採用情境：健康、非肥胖、運動科學或訓練場域中，用於提醒「LT1/GET/VT1 不等於 Fatmax」，尤其在需要精準脂肪氧化訓練處方時。
  • 不建議直接套用：肥胖、糖尿病、心肺疾病、藥物影響代謝者、年長族群、女性內分泌狀態未控制者；也不應用於個別病人/運動員的 Fatmax 精準估計。
  • 實務建議：若目標是個體化 Fatmax，仍應直接測 substrate oxidation；若只能做 LT/GET，需標準化 fasting、飲食、protocol stage duration、threshold method，且避免把 LT/GET 當作等價替代。
  • 證據強度：中等偏低。系統性搜尋與統計方法佳，但異質性極高、證據多來自 cross-sectional/protocol studies，且缺 individual participant data。

B. 論證架構重建

主論點：Fatmax 通常發生在比 LT/GET 更低的運動強度；兩者不應普遍互換，但在某些測試與族群條件下，LT/GET 可能可作為 Fatmax 的近似 surrogate。

論證主幹

  1. 前提 A：Fatmax 與 LT/GET 都是實務上常用的 submaximal exercise intensity 標記。
    └─ 支撐：Fatmax 訓練與脂肪氧化、體組成、VO2max、insulin sensitivity、lipid profile 改善相關；LT/GET 是 moderate-to-heavy transition marker。
    └─ 推論：若兩者一致，可用較簡便的 LT/GET 估計 Fatmax。

  2. 前提 B：既有文獻結論不一致，前一篇 meta-analysis 搜尋與納入條件較窄。
    └─ 支撐：前文獻僅 14 studies，要求報告 correlation，搜尋 MEDLINE/Google Scholar 且限 2001–2021。
    └─ 推論：需要更完整搜尋與 meta-analysis。

  3. 前提 C：本文更廣泛搜尋後納入 42 studies / 1,505 participants / 158 ES。
    └─ 支撐：四資料庫，自建庫至 2025-01-20，PROSPERO，雙人流程。

  4. 中間結論：整體 pooled ES 顯示 Fatmax 明顯低於 LT/GET。
    └─ 支撐：ES 0.74，95% CI 0.32–1.16，P=0.001；換算約 5.78% VO2max、22 W、11 bpm。

  5. 最終結論：不宜把 Fatmax 與 LT/GET 視為等價；但某些 moderator subgroup 顯示差異較小，因此在無法直接測 substrate oxidation 時，LT/GET 可在特定條件下作替代參考。

敘事策略：由生理背景與實務需求出發，接著指出前人 review 不足，再以更完整 meta-analysis 建立平均差異，最後用 moderator analysis 給出 protocol standardization 建議。

作者承認的限制：健康族群限定、高異質性、univariate moderator、summary data 無法 individual-level agreement、年長族群不足、方法不一致。

D. 過度推論分析

推論 1：group-level 平均差異 → 個體層級可否 surrogate

  • 原始資料：pooled SMD 顯示 Fatmax 平均低於 LT/GET；作者也承認 summary data 無法評估 individual-level agreement。
  • 作者結論：在特定條件下 LT/GET could serve as surrogate when direct substrate oxidation measurement is not feasible。
  • 跳躍：surrogate 需要個體層級 agreement、prediction error 或 limits of agreement；本文主要是 group mean difference。
  • 嚴重程度：中度。

推論 2：subgroup P 值不顯著 → 兩 threshold 相似

  • 原始資料：若 <20 歲、sedentary、treadmill、短 fasting 等 subgroup 未見顯著差異。
  • 作者結論：這些條件下差異較小，可能可互相替代。
  • 跳躍：不顯著不等於等價；需 equivalence margin 或 ROPE，且 subgroup power 可能不足。
  • 嚴重程度：中度到嚴重。

推論 3：23 個 moderator → protocol 建議

  • 原始資料：23 個 univariate moderator 至少各有一 subgroup 顯著。
  • 作者結論：建議標準化飲食 48 小時、overnight fast、使用 Jeukendrup & Wallis equation、3rd order polynomial 或 sine fitting。
  • 跳躍：這些建議多半合理，但來自非隨機、交互混雜的 study-level moderator，不能視為因果證明。
  • 嚴重程度：中度。

E. 論證結構完整性評估

  • 未被支撐的前提：LT/GET 作為 surrogate 的可接受誤差範圍未預先定義。差 5.78% VO2max、22 W 或 11 bpm 在訓練處方上是否 clinically acceptable，文內未建立 MCID 或 practical equivalence margin。
  • 邏輯斷層：meta-analysis 回答的是「平均是否同強度」，但實務問題是「個體是否可用 LT/GET 預測 Fatmax」。兩者不是同一問題。
  • 替代解釋未充分處理：高異質性可能不是生理差異，而是 measurement error、stage duration、gas kinetics lag、公式差異與 threshold adjudication 主觀性共同造成。
  • 結論是否超出證據：主結論「通常不相同」可支持；「特定條件下可 surrogate」只能作假說，不能作臨床/訓練處方確定建議。

紅旗清單

  • 設計紅旗：納入研究方法極不一致；Fatmax、LT、GET、VT 定義與判讀方法多達多種。
  • 統計紅旗：I²=95%；23 個 univariate moderator analyses，未做 multivariable adjustment 或 multiplicity 控制。
  • 證據紅旗：24 篇因資料不足排除；這可能系統性排除報告不完整或結果不典型研究。
  • 推論紅旗：將 subgroup 非顯著差異解讀為「可能相似」；缺 equivalence framework。
  • 外部效度紅旗：健康、非肥胖、年輕到中年族群為主；sedentary 僅 8%，女性-only 研究僅 3 篇，臨床族群不可直接外推。
  • 圖表限制：Figure 1–3 與 supplemental figures/tables 未完整保留於 markdown，無法檢查 forest plot、funnel plot、RoB 圖形細節。

反向解釋

  1. 差異主要是 protocol artifact，而非真正生理分離
    支持：stage duration、single vs separate test、ergometer、公式與 threshold method 都影響 ES；作者也承認 gas-exchange mean response time 未被考慮。
    反對：主效果在多種單位與 LT/GET marker 下仍一致偏向 Fatmax 較低。

  2. LT/GET 與 Fatmax 是相關但不同變異來源的指標
    支持：Fatmax 受營養狀態、substrate availability、公式與 calorimetry 影響；LT/GET 反映 lactate/gas exchange transition。
    反對：部分 subgroup 顯示兩者可能靠近，表示在某些條件下仍可能實務近似。

  3. subgroup 的「相似」可能只是 power 不足
    支持：sedentary、女性、OC、<20 歲與特定設備 subgroup 樣本較少；沒有等價檢定。
    反對：若多個 protocol 條件一致指向差異變小，仍值得未來 IPD 驗證。

最終裁決

  • 論證結構完整性：中等。
  • 引用品質：部分適當。
  • 過度推論嚴重程度：中度。
  • Overall credibility：moderate for group-level conclusion；low-moderate for surrogate-use recommendation。
  • 可採用：Fatmax 平均通常低於 LT/GET；研究或運動處方不可無條件把 LT1/GET/VT1 當 Fatmax。
  • 不應採用：不能用本文直接為個別受試者用 LT/GET 取代 Fatmax，也不能外推到肥胖、糖尿病、心血管疾病或高齡族群。
  • 若要改觀，最需要：
    1. Individual participant data meta-analysis，報告 Bland-Altman limits、prediction error 與可接受誤差範圍。
    2. 預先定義 equivalence margin，檢驗 LT/GET 是否在臨床/訓練可接受範圍內等價於 Fatmax。
    3. 標準化 protocol 的前瞻性研究，控制飲食、fasting、stage duration、gas kinetics、公式與 threshold adjudication。

一句話結論：Fatmax 平均低於 LT/GET；可當研究線索，不能當個體處方的等價替代。
