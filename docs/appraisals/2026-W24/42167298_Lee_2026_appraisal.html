3. 研究背景

既有事實與證據 [文內]：

  • 缺血性心臟病的診療傳統上聚焦於 epicardial coronary artery disease 的偵測與治療
  • 冠狀動脈微循環包含三個層次：傳導性冠狀動脈、小動脈（arterioles）、微血管（capillaries）
  • 2023 ACC/AHA 與 2024 ESC guidelines 建議在特定患者（特別是非阻塞性冠脈疾病）使用 CFR 或 IMR 評估微血管功能
  • 既有 CMD 預後研究限制包括：回顧性設計（Boerhout/ILIAS registry）、小樣本（CorMicA, Lee 2016 JACC）、高度篩選族群（Fearon 2008 STEMI, Yang 2016 heart transplant）

知識缺口 [文內]：

  • 缺乏大規模前瞻性研究在常規臨床實務中系統性評估 CMD 的盛行率與預後意義
  • 既有定義不一致，限制了適用性

Research question [文內]： 在因疑似缺血性心臟病而接受臨床指示性侵入性冠狀動脈攝影的患者中，CMD（以 CFR <2.0 且 IMR ≥25 定義）的盛行率為何？CMD 是否與較差的複合心血管預後相關？

4. 研究設計與方法

PICO：

  • P：年齡 ≥18 歲，因疑似缺血性心臟病接受臨床指示性侵入性冠狀動脈攝影的連續患者，具有至少一條中間程度狹窄（40–90% 直徑狹窄）可供生理評估者
  • I（Exposure）：CMD（CFR <2.0 且 IMR ≥25，在任一評估血管）
  • C：Preserved microvascular function（非 CMD）
  • O（Primary）：Patient-oriented composite outcome — 全因死亡、心肌梗塞、臨床驅動之再次血管重建術、心衰住院
  • O（Secondary）：各組分終點（cardiac death、MI、target/non-target vessel revascularisation、HF hospitalization、stroke）、Seattle Angina Questionnaire

關鍵研究設計細節：

  • 設計：Investigator-initiated，前瞻性多中心世代研究，七家韓國三級醫院
  • 收案期間：2022/04/22–2024/11/19
  • 追蹤：中位數 1.9 年（IQR 1.1–2.1）
  • 生理評估：以 pressure-temperature sensor guidewire（Abbott Vascular）測量 FFR、CFR、IMR，protocol 標準化且預先指定
  • Obstructive epicardial CAD 定義：中間狹窄（40–90%）且 FFR ≤0.80，或 severe stenosis（>90%）直接 PCI 未測 FFR
  • CMD 定義：CFR <2.0 且 IMR ≥25（雙標準同時滿足）
  • 追蹤方式：門診（1、6、12 個月及之後每年）+ 電話 + 韓國全民健保資料庫交叉驗證生存狀態
  • Data and Safety Monitoring Board 與獨立 Clinical Event Adjudication Committee（成員對分組 masked）
  • 統計軟體：R 4.5.1 與 SPSS 25.0
  • ClinicalTrials.gov 註冊：NCT05369182

主要變項定義：

  • CMD 的操作型定義明確（CFR <2.0 AND IMR ≥25），使用公認的 cut-off 值
  • 對於接受 PCI 且有 post-PCI 生理評估的患者，以 post-PCI 的 CFR/IMR 定義 CMD（117 名 PCI+CMD 患者中，97 名依 pre-PCI 分類，20 名依 post-PCI 分類）
  • Primary endpoint 各組分定義見 appendix，心肌梗塞依 Fourth Universal Definition

5. 研究結果重點整理

篩選與收案：5764 名患者篩選 → 1003 名收案（排除率 82.6%）。主要排除原因：嚴重單一狹窄不需生理評估（2293, 39.8%）、AMI（1220, 21.2%）、單一血管疾病（720, 12.5%）、非 infarct-related artery 未做生理評估（358）、臨床不穩定（142）、醫師判定不適合（606）等。[文內 Figure 1]

基線特徵：中位年齡 65 歲，75.4% 男性。CCS 66.2%，ACS 33.8%（其中 STEMI 5.3%、NSTEMI 8.6%、UA 19.9%）。高血壓 70%、糖尿病 40.5%、高血脂 86.7%。LVEF 中位數 62.7%。[文內 Table 1]

CMD 盛行率：

  • 整體 163/1003（16.3%）
  • 有阻塞性 epicardial CAD 者：123/573（21.5%）
  • 無阻塞性 epicardial CAD 者：40/430（9.3%）

6. 作者討論與評論重點

作者主要訊息 [文內]：

  1. CMD 不僅存在於非阻塞性 CAD 患者，亦常見於合併 epicardial CAD 的患者（21.5%）
  2. CMD 與更差的複合心血管預後獨立相關
  3. 支持一個整合 epicardial 與 microvascular 病理的冠心病框架

限制（作者觀點） [文內]：

  1. 生理評估結果未對治療醫師遮蔽 → 可能影響後續處置
  2. 僅納入中間程度狹窄需要生理評估者 → 正常或極輕微冠脈疾病者未系統性納入
  3. 大多數只評估單一血管 → CMD 空間異質性可能導致誤分類
  4. 純韓國族群 → 外推性限制
  5. 生理評估增加費用 → 成本效益需評估
  6. 部分患者以 post-PCI 生理評估定義 CMD → 可能誤分類
  7. 未做 acetylcholine vasomotor testing → vasospasm + CMD 混合型未納入
  8. 未標準化停用血管活性藥物 → on-treatment physiology

[評估]：作者對限制的討論相當完整且誠實，七項限制中有數項具有實質影響結果的潛力（特別是第 1、2、3 點）。然而，作者對第 1 點（unblinding）的回應——「以預先指定的終點定義、盲化核心實驗室與獨立裁定委員會緩解」——僅能緩解 hard endpoints（死亡、MI）的偏差，對於 soft endpoint（clinically driven revascularisation）的 surveillance bias 效果有限（見下方 B3 詳述）。作者未充分討論的關鍵限制是：高達 82.6% 的排除率造成的嚴重選擇偏差，以及 CMD 組與 preserved 組之間基線特徵的系統性差異。

8. 臨床建議

可採用的情境：

  • 對於接受侵入性冠脈攝影且有中間程度狹窄的患者，若已使用 pressure wire 測量 FFR，額外測量 CFR 與 IMR 可提供微血管功能的附加風險分層資訊
  • 特別是 FFR >0.80（deferred revascularisation）但仍有持續症狀的患者，CMD 評估有助解釋症狀來源

不建議直接套用的情境：

  • 不應將本研究結論直接應用於正常或極輕微冠脈疾病者（未被納入）
  • 非韓國族群需審慎外推（不同種族、不同 practice pattern）
  • 本研究為觀察性設計，不能據此推論「治療 CMD 可改善預後」——因果關係未建立

給臨床醫師的實務建議：

  1. 在已有 pressure wire 平台的導管室，對 intermediate stenosis 患者額外取得 CFR/IMR 具有合理依據，但需權衡額外 procedure time 與成本
  2. CMD 的存在提醒臨床醫師：即使 PCI 成功，殘餘風險可能來自微血管層面，需要更密集的醫療優化與追蹤
  3. 在正式 RCT 證實 CMD 導向治療可改善預後之前，不宜僅因 CMD 而改變治療決策

研究證據強度分級：中（前瞻性多中心設計加分，但觀察性本質、高排除率、低事件數、殘餘混淆與裝置商贊助構成實質限制）

SKILL-A：觀察性研究批判性評讀

A. 補充技術細節

（SECTION-0 第 3–6 節已詳述 PICO、設計、主次終點與資助。此處僅補充統計與設計細節。）

樣本數估算 [文內]：

  • 預估 1003 人可提供 ≥80% power（α=0.05, two-sided, log-rank test），假設 preserved 組年事件率 8.0%、CMD 組年事件率 20.0%，accrual 2 年、follow-up 1 年、dropout 0.5%
  • 預估 CMD 盛行率約 6.7%（preserved:CMD = 15:1），引用 Lee 2016 JACC
  • 實際結果：CMD 盛行率 16.3%（遠高於預估 6.7%），比例 840:163 ≈ 5.2:1（非預設的 15:1）。事件率：CMD 組 2 年 18.8%（年化 ~10%，低於假設的 20%）、preserved 組 2 年 10.5%（年化 ~5.5%，略低於假設的 8%）。雖然 CMD 盛行率遠高於預期使得 CMD 組人數更多（有利 power），但事件率低於預期抵消了部分 power 增益

多重比較處理：Primary endpoint 為單一預先指定的複合終點。Secondary endpoints 未做多重比較校正，文內未明確說明此點。14 項次要終點的 p 值應視為探索性。[文內]

多變量模型：以 backward selection 建構 Cox proportional hazards regression model。總事件數 96 件，按 events-per-variable（EPV）≈ 10 原則，最多可放入 ~9–10 個變項。文內引用 Peduzzi et al. 1995 為 EPV 依據。模型以 Harrell's c-index 評估 discrimination。[文內]

比例風險假設：以 scaled Schoenfeld residuals 的 two-sided score test 檢驗（α=0.05）。[文內]

缺失資料：未使用任何填補方法。[文內]

競爭風險分析：以 Fine-Gray subdistribution hazards model 處理非致命終點（以全因死亡為競爭事件），cardiac death 以非心臟死亡為競爭事件。結果與主分析一致。[文內]

殘餘混淆：

  • CMD 組與 preserved 組基線有系統性差異：CMD 組年齡較大、高血壓比例較高、慢性腎功能不全較多、NT-proBNP 較高、FFR ≤0.80 比例更高（60.7% vs 41.1%）、接受 PCI 比例更高（71.8% vs 44.6%）[文內 appendix pp 30–31]
  • 未測量但可能重要的混淆因子：瀰漫性動脈硬化程度（SYNTAX score 未報告）、LV diastolic function 細節（僅報告 LVEF）、發炎指標（CRP、IL-6）、微量白蛋白尿、實際運動能力
  • CMD 可能是整體心血管疾病負擔的標記（marker），而非獨立致病因子——此為觀察性設計無法排除的根本問題

B. 批判性評估（四大面向）

B1. 假說與理論邏輯

假說：CMD（CFR <2.0 且 IMR ≥25）獨立預測不良心血管預後——此假說預先指定，protocol 已註冊於 ClinicalTrials.gov（NCT05369182）。非 post-hoc hypothesis。(Methods)

機轉合理性：

  1. CMD 導致心肌缺血（即使 epicardial 血管通暢）→ 反覆缺血 → 心肌纖維化 → 心室重塑 → 心衰 [文內引用 ref. 23, Löffler 2019]
  2. CMD 反映內皮功能障礙與發炎 → 動脈硬化進展與冠脈血管運動異常 [文內引用 ref. 19, Kunadian 2020]
  3. CFR 整合 epicardial + microvascular 阻力；IMR 較特異性地反映微血管阻力

最可能合理機轉：上述三點皆有文獻支持，邏輯鏈完整。

最可疑敘事跳躍：

  1. 作者從「CMD 與 adverse outcome 相關」跳到「支持 integrated framework 結合 epicardial 與 microvascular assessment」——這是合理推論，但隱含「評估 CMD 可改善 outcome」的暗示，而此因果鏈未被證實 (Discussion, paragraph 3)
  2. 作者討論 CMD 在 PCI 患者中 association 減弱時，推測「可能反映 PCI 相關微血管改變」(Discussion)——此為純粹推測，無資料支持，且替代解釋可能更簡單（PCI 改善 epicardial flow 降低事件率，diluting CMD 的 signal）

B2. 受試者與外推性

受試者與宣稱對象的一致性：

  • 文章標題與結論宣稱研究「patients undergoing clinically indicated invasive coronary angiography」，暗示為常規臨床族群
  • 但實際上 82.6% 被排除——僅 1003/5764（17.4%）被納入。這不是「常規」族群的縮影，而是高度篩選後的子集：必須有中間程度狹窄（40–90%）可供生理評估、排除了嚴重單一狹窄（2293 人）、AMI（1220 人）、vasospasm（329 人）等 (Figure 1)
  • 納入者以中間狹窄、多血管疾病為主；這與「所有接受 CAG 的患者」之間有本質性差距

基線平衡 [文內 appendix pp 30–31]：

  • CMD 組系統性地更「病重」：更老、更多高血壓、更多 CKD、更高 NT-proBNP、更多 epicardial 疾病、更多 PCI → 即使 adjusted analysis，殘餘混淆方向傾向高估 CMD 的獨立效果

外推性分級：

  1. 一般健康族群：不適用——本研究僅納入接受侵入性 CAG 的患者
  2. 中間程度冠脈狹窄、需 FFR 評估的患者：有條件可外推——前提是有完整的 pressure wire 設備與操作經驗，且患者 profile 類似（東亞族群、tertiary center）
  3. 非韓國族群：需謹慎——CMD 盛行率可能受種族、飲食、合併症分布影響。作者亦承認此限制 (Discussion, limitation 4)
  4. STEMI/cardiogenic shock/severe single-vessel disease：不可外推——這些族群被系統性排除

B3. 研究設計與偏差

最可能造成偏差的三大設計問題：

1. CMD 結果未遮蔽治療醫師 → Surveillance bias / Intervention bias（方向：高估效果）

這是本研究最關鍵的方法學弱點。CMD 的評估結果對治療醫師公開 → 知道患者有 CMD 的醫師可能：

  • 更頻繁安排追蹤、更容易發現新症狀或缺血證據 → 增加 repeat revascularisation 的機會（surveillance bias）
  • 對 deferred lesion 的再介入閾值降低 → 增加 deferred vessel revascularisation
  • 更積極調整藥物 → 此方向可能減少事件（保護性偏差），但複合終點中的 soft component 更容易受 surveillance 影響

佐證：primary composite 的驅動力中，repeat revascularisation（HR 2.30, p=0.016）與 deferred vessel revascularisation（HR 2.60, p=0.019）是具統計顯著性的組分。相較之下，MI（HR 1.03, p=0.97）與 HF hospitalization（HR 1.71, p=0.22）並未達顯著。死亡雖顯著（cardiac death HR 3.38, p=0.0077），但事件數極少（8 vs 12）。Non-target vessel revascularisation 的 HR 5.21（p=0.0042）更是顯著偏高——這恰恰是最容易受 surveillance bias 影響的終點。(Table 3)

2. 高排除率造成的選擇偏差（方向：不確定，可能高估或低估）

5764 篩選 → 1003 收案。排除的 4761 人中有大量重要臨床族群（嚴重狹窄 2293 人、AMI 1220 人、vasospasm 329 人、醫師判定不適合 606 人）。尤其「deemed ineligible by physician（606 人）」這項排除具有主觀性，可能引入系統性選擇。

3. CMD 定義時點不一致（方向：可能雙向誤分類）

117 名接受 PCI 的 CMD 患者中，97 名以 pre-PCI 評估定義，20 名以 post-PCI 評估定義。Pre-PCI 與 post-PCI 的微血管生理狀態不同（PCI 本身可能造成微血管損傷或改善 flow），混合兩種時間點的定義增加雜訊。作者承認此限制並提供 pre-PCI only 的 sensitivity analysis（結果一致），部分緩解此疑慮。

對照組適當性：本研究為世代比較（CMD vs preserved），非 RCT，故「對照組」為自然對照。但 preserved 組本身不是同質群體——包含 FFR >0.80 deferred 患者與接受 PCI 後 preserved microvascular function 的患者。

B4. 測量工具與實務意義

測量工具信度：

  • CFR 與 IMR 使用 thermodilution method（Abbott Vascular pressure-temperature wire），在標準化 protocol 下執行。CFR 的 test-retest variability 已知約 10–15%，IMR 的 reproducibility 在文獻中被認為優於 CFR [外部文獻]
  • CFR <2.0 的 cut-off 接近生理 borderline，部分患者可能因單次測量誤差而被誤分類
  • 未做 acetylcholine testing → functional CMD（vasospasm 型）未被評估，僅捕捉 structural CMD
  • 未標準化停藥 → on-treatment physiology 可能低估 CMD 的真實盛行率

終點臨床意義：

  • Primary composite 混合 hard endpoints（death, MI）與 soft endpoints（revascularisation, HF hospitalization）
  • Repeat revascularisation 在介入性研究中是最受爭議的終點——高度依賴醫師決策、surveillance 強度、與對 CMD 結果的認知
  • 若移除 revascularisation，僅看 death + MI + HF hospitalization，CMD 的效果需重新評估。從 Table 3 數據看：cardiac death HR 3.38（p=0.0077，但僅 8 events）、MI HR 1.03（p=0.97，本質上無差異）、HF hospitalization HR 1.71（p=0.22）——除 cardiac death 外，其他 hard endpoints 均未顯著

實務意義：「就算結果完全為真，真實世界可能有多大用處？」

  • NNH 12（95% CI 1–15.6），意即每 12 位被標記為 CMD 的患者，2 年內額外多出 1 件複合事件
  • 但此 NNH 建立在「CMD 是因果因子」的假設上；若 CMD 只是 marker，知道 CMD 狀態本身不改變預後
  • 目前無任何 RCT 證明「知道 CMD → 改變治療 → 改善預後」；CorMicA 試驗僅在非阻塞性 CAD 患者中改善 6 個月 angina severity，非 hard outcomes

C. 統計與資料完整性

C1. 結果分類（CI + MCID 框架）

Step 1 — MCID 確認：

文內未預先指定 MCID。對於包含全因死亡、MI、revascularisation、HF hospitalization 的複合終點，目前無公認 MCID。[推算] 在類似冠脈世代研究中（如 FAME 2 等 FFR-guided trials），HR 1.2–1.3 通常被視為具有臨床意義的下限；ARD 2–3% 在 2 年的 time horizon 可作為近似 MCID。

Step 2 — CI 位置判讀（主要終點）：

  • HR 1.91（95% CI 1.22–2.99），p=0.0047
  • CI 下界 1.22 > 1.0（null）→ 排除 null
  • CI 下界 1.22 接近 MCID（推算 ~1.2–1.3）→ CI 下界勉強超越 MCID
  • CI 上界 2.99 → 非常寬，效果量可能從小（HR 1.22）到大（HR 2.99）
結果類別 判斷
Unadjusted primary endpoint IMPRECISE (+) — p < 0.05 且 CI 完全排除 null，但 CI 寬度跨越一個數量級（1.22–2.99），MCID 的下界恰好勉強被排除。效果存在但精確度不足。
  • Adjusted HR 1.65（95% CI 1.02–2.66），p=0.041 → CI 下界 1.02 幾乎觸及 null。校正後效果減弱，CI 甚至更不精確。

Step 3 — 禁止的統計謬誤檢查：

  • 作者未犯「p > 0.05 = no difference」的錯誤。對於 HF hospitalization（p=0.22）等非顯著結果，用語為「numerically worse」而非「no difference」(Discussion)
  • 未使用 post-hoc power
  • 未宣稱 negative findings 為「等效」

C2. Underpowered 判斷與 Winner's Curse

整體 primary endpoint：96 events / 1003 patients，power calculation 基於 preserved 年事件率 8% 與 CMD 年事件率 20%。實際年化事件率偏低（preserved ~5.5%, CMD ~10%），但 CMD 組人數高於預期（163 vs 預計 ~67），部分補償。Primary endpoint 達顯著——非 underpowered positive。

但個別組分嚴重 underpowered：Cardiac death 僅 20 events、MI 僅 12 events、HF hospitalization 僅 28 events。這些終點的 CI 極寬，無法可靠判斷效果方向或大小。

無阻塞性 CAD 亞群的 Winner's Curse 風險：

  • 40 名 CMD 患者中 10 人發生 primary endpoint → 25% event rate
  • HR 3.45（95% CI 1.69–7.06）——效果量極大
  • 此亞群的 power 極低（40 人中 10 events），如此大的 HR 可能受 Winner's Curse 影響——低 power 研究中只有隨機偏高的估計值才能跨越顯著門檻，published HR 很可能被系統性誇大
  • 若此 HR 3.45 被用於未來 RCT 的 power calculation，所需樣本數將被嚴重低估

C3. Bayesian 補充分析

本文未提供 Bayesian 分析。Adjusted HR 1.65（95% CI 1.02–2.66, p=0.041）位於「borderline significant」區域，特別適合 Bayesian 補充。以下為推估：

以 non-informative prior 且假設近似 log-normal posterior：

  • Pr(HR > 1.0) ≈ 98%（觀察到 benefit 的機率高）
  • Pr(HR > 1.5) ≈ 55–65%（具臨床意義效果的機率中等）
  • 使用 skeptical prior（假設 CMD 無效）可能將 Pr(HR > 1.0) 降至 ~85–90%

解讀：即使用頻率派觀點 p=0.041 是 borderline，Bayesian 角度仍偏向存在某種程度的 association。但 association 不等於 causation。

C4. 報告完整性與其他統計問題

樣本數與 power（雙向評估）：

  • 未 overpowered——96 events 是合理但不充裕的事件數
  • 個別組分嚴重 underpowered（見 C2）

Kaplan-Meier 圖細節判讀：

  • Numbers at risk 遞減主要因中位追蹤 1.9 年（研究收案至 2024/11，database lock 2025/11/18）——多數患者尚未達 2 年，非 informative censoring
  • 曲線無交叉
  • Panel B（無阻塞性 CAD）末段 CMD 僅 11 人 at risk → 曲線尾段不可靠

多重比較：14 項 secondary endpoints 均未校正。若做 Bonferroni 校正（α = 0.05/14 ≈ 0.0036），僅 cardiac death（p=0.0077 → 不過）與 non-target vessel revascularisation（p=0.0042 → 不過）可能通過。所有 secondary endpoints 的 significance 應以探索性看待。

報告完整性：

  • Protocol 與統計分析計畫完整公開（appendix pp 48–201）✅
  • 效果量與 CI 均完整報告 ✅
  • ARD 與 NNH 有報告 ✅
  • 但基線特徵僅呈現整體族群（Table 1），CMD vs preserved 的對照表在 appendix（pp 30–31）而非正文——這使得快速判斷組間差異不便

統計面紅旗清單：

  1. Adjusted HR CI 下界 1.02：幾乎觸及 null，方法學上的微調（不同 covariate 選擇、不同 CMD cut-off）可能改變結論
  2. 96 events 支撐多變量模型：EPV 理論上足夠（~10），但 backward selection 在有限 events 下的穩定性存疑
  3. Secondary endpoints 無多重校正：14 項終點至少 5 項達 p < 0.05，若校正可能僅 cardiac death 的信號較穩健
  4. CMD 組與 preserved 組基線不平衡：CMD 組系統性更病重，adjusted analysis 只能部分緩解
  5. 未報告 model discrimination（c-index）的具體數值：文內提到使用 Harrell's c-index 但 markdown 中未見數值 [限制：可能在 appendix 圖表中但 markdown 未完整保留]
  6. Pre-PCI / post-PCI CMD 定義混合：20/117 PCI 患者依 post-PCI 定義，增加分類雜訊

D. 次組分析評估

預先指定的次組分析 [文內 appendix pp 23–24, 43]：包括 initial presentation（CCS vs ACS）、symptom status、treatment strategy（medical alone vs PCI）、functionally significant stenosis、age、sex、diabetes、CKD、previous non-invasive testing。

唯一顯著交互作用：Treatment strategy（medical alone vs PCI）× CMD，p(interaction) = 0.034。CMD 在藥物治療組的效果更顯著。

以 JAMA Subgroup Criteria 評估此交互作用：

標準 評估
1. Interaction p-value? ✅ p = 0.034
2. 結果方向與其他研究一致？ 部分一致——CorMicA 也在非阻塞性 CAD（多為 medical therapy）中看到 CMD 的影響
3. 假說預先指定？ ✅ 預先指定（appendix p 23）但無預期方向說明

E. 紅旗清單

  1. 裝置商贊助 + 通訊作者為裝置商顧問：Abbott Vascular 贊助研究 + JM Lee 收取 Abbott 顧問費——而 Abbott 的 pressure wire 正是此研究的核心工具。若 CMD 評估成為常規，直接擴大 Abbott 產品需求。結構性 COI。

  2. CMD 狀態未遮蔽治療醫師 + composite endpoint 包含 revascularisation：知道 CMD 的醫師可能更積極安排再介入 → revascularisation（composite 的重要驅動力）受 surveillance bias 污染。Non-target vessel revascularisation HR 5.21（p=0.0042）是所有終點中最高的——恰恰是最受醫師決策影響的終點。

  3. 82.6% 排除率：號稱「routine practice」但排除了 >4/5 的篩選患者，大幅限制外推性，且「deemed ineligible by physician」（606 人）具主觀性。

  4. Adjusted HR 1.65（95% CI 1.02–2.66）：CI 下界 1.02 幾乎觸及 null。結論的 robustness 對模型規格高度敏感。

  5. 作者一貫立場與 self-citation：通訊作者過去十年持續發表 CFR/IMR 預後價值的研究，power calculation 直接引用自己 2016 JACC 論文。本研究可視為其 research programme 的「確認性研究」——自然偏向支持既有假說。

  6. 無阻塞性 CAD 亞群數據過度強調：40 名 CMD 患者中 10 events → HR 3.45（95% CI 1.69–7.06），具 Winner's Curse 高風險。Figure 2B 被放在正文中（非 supplement），2 年末段僅 11 人 at risk，曲線末端不可靠。

  7. MI 無差異（HR 1.03, p=0.97）但未獲充分討論：在一個號稱微血管功能障礙導致缺血的研究中，MI——最直接的缺血後果——在兩組間完全無差異。作者未解釋此矛盾。

F. 反向解釋

替代解釋 1：CMD 是整體心血管疾病嚴重度的 marker，非獨立致病因子

文內支持：CMD 組有更多 epicardial disease（FFR ≤0.80: 60.7% vs 41.1%）、更多 PCI（71.8% vs 44.6%）、更高 NT-proBNP、更多 CKD、更多高血壓。Adjusted HR 從 1.91 降至 1.65（降幅 14%），顯示部分效果由 confounders 解釋。CI 下界 1.02 顯示殘餘效果微弱。 文內反對：subgroup analysis 在有無 epicardial disease 的亞群中均見效果。

替代解釋 2：Surveillance / detection bias 驅動複合終點

文內支持：revascularisation 是 composite 的重要驅動力；MI（最不受 surveillance 影響的終點）完全無差異。知道 CMD 的醫師更可能對 deferred lesion 安排 follow-up angiography。 文內反對：cardiac death（相對不受 surveillance 影響）也顯著升高（HR 3.38），但僅 20 events。

替代解釋 3：CFR/IMR 測量誤差導致的 reverse causation

CMD 的定義要求 CFR <2.0 且 IMR ≥25。這些測量在有嚴重 epicardial disease 的血管中可能受 epicardial 因素干擾（即使 IMR 有校正公式）。IMR 的「校正值」仍然對 FFR 有殘餘依賴。因此「CMD」可能部分反映的是 epicardial disease 的嚴重度而非真正的微血管異常。

替代解釋 4：Post-PCI CMD 可能反映急性 procedural microvascular injury 而非 baseline pathology

20 名以 post-PCI 評估定義 CMD 的患者，其 CMD 可能是 PCI 本身（stent deployment、no-reflow、distal embolisation）的後果而非基線微血管疾病。

G. 最終裁決

整體可信度：中

這是一項方法學上認真的前瞻性多中心世代研究，具有標準化 protocol、獨立核心實驗室、盲化事件裁定、預先註冊與完整的 protocol 公開等優勢。CMD 與複合心血管終點之間存在 association 的信號是合理的，方向符合既有文獻。

然而，以下因素限制了證據強度：

  • 觀察性設計無法建立因果關係
  • Adjusted HR 的 CI 下界 1.02 — 結論 robustness 令人擔憂
  • Unblinded CMD 狀態 + 含 revascularisation 的 soft composite → surveillance bias 是真實且無法完全排除的威脅
  • 裝置商贊助與通訊作者 COI 的結構性利益衝突
  • 高排除率限制外推性
  • 個別 hard endpoints 除 cardiac death 外均未顯著，且事件數極少

可採用的條件：在已有 pressure wire 平台的導管室，對中間程度狹窄患者測量 CFR/IMR 作為「附加風險資訊」是合理的——但應理解其為風險標記（risk marker），而非已驗證的治療靶點。

不建議採用的情境：不應僅因本研究結果就將 CMD 評估納入所有 CAG 患者的常規流程；不應以 CMD 結果單獨驅動治療決策（如加做 PCI 或改變藥物策略）；不應將此結果外推至正常冠脈、非東亞族群或社區醫院。

若要改觀，最需要的 3 個關鍵改進：

  1. RCT 證明 CMD-guided therapy 改善 hard outcomes（如 CorMicA 的升級版，以 death/MI/HF 為 primary endpoint，非 angina severity）
  2. 以 blinded CMD 狀態的世代研究複製——治療醫師不知 CMD 結果，消除 surveillance bias 對 revascularisation 終點的干擾
  3. 多種族、多地區的 independent replication——非 JM Lee 團隊主導的研究

一句話結論：CMD 與不良心血管預後具有 association，但因果關係未確立、adjusted HR 幾乎觸及 null、且 surveillance bias 可能膨脹 soft endpoints，臨床實用性仍需 RCT 驗證。

APPENDIX：因果推論補充評估框架

Target Trial 思維框架

理想試驗設計：若以 RCT 回答「CMD 診斷是否改善預後」，應為：對中間狹窄的 CAG 患者隨機分配至「知道 CMD 結果並據此調整治療」vs「不知道 CMD 結果（blinded），維持標準治療」，以 hard composite endpoint 追蹤 2–3 年。

本觀察性研究的落差：

  • 沒有隨機分配 → 無法確保 exchangeability
  • CMD 結果公開 → 治療行為受汙染
  • 主要結果是「CMD 的存在 vs 不存在」的預後比較，而非「CMD-guided therapy vs standard care」的治療效果比較 → 即使 CMD 是因果因子，「知道 CMD」不等於「改善 outcome」

三大可識別性條件

條件 評估
Exchangeability 未滿足：CMD 組系統性更病重。Multivariable adjustment 部分校正，但殘餘混淆方向明確（高估 CMD 效果）。未測量的混淆因子包括 SYNTAX score、diastolic function、inflammatory markers、diffuse atherosclerosis burden
Positivity 部分滿足：在所有臨床亞群中，CMD 與 preserved 均有患者分布。但 CMD 盛行率在無阻塞性 CAD 組僅 9.3%（40/430），某些特定亞群的 CMD 患者數極少
Consistency 部分問題：CMD 定義明確（CFR <2.0 AND IMR ≥25），但測量時點不一致（pre-PCI vs post-PCI）。「Preserved microvascular function」涵蓋了異質的群體（單純 CFR 低但 IMR 正常、或 CFR 正常但 IMR 高——各有 221 與 135 人，35.5% 為 discordant）

Time-varying Confounding

  • 本研究非縱貫性治療比較，而是基線暴露（CMD 狀態）與後續事件的關聯性分析
  • 未涉及 time-varying treatment → marginal structural models 或 g-formula 不適用
  • 但追蹤期間的藥物調整（受 CMD 狀態影響的 post-baseline treatment changes）可能作為中介因子或 time-varying confounder → 未被模型處理
