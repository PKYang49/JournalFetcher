3. 研究背景

作者指出臨床診斷與治療長期聚焦 epicardial CAD 與 FFR-guided revascularisation，但冠脈循環還包含 arterioles / capillaries，CMD 可能是缺血症狀與預後風險的重要來源。現行 ACC/AHA 2023 與 ESC 2024 指引已建議在特定患者可用 CFR / IMR 評估微血管功能，但既有預後研究多為 retrospective、小樣本或高度選擇族群。[文內]

Research question [推論]：在 routine invasive coronary angiography 場景中，CMD 是否常與 obstructive epicardial CAD 共存，且是否與後續 death / MI / repeat revascularisation / HF hospitalisation 相關？

4. 研究設計與方法

  • P：18 歲以上、疑似 ischemic heart disease、因臨床需要接受 invasive coronary angiography，來自韓國 7 間 tertiary hospitals；共 5764 篩選、1003 納入。[文內]
  • Exposure / Index classification：CMD 定義為任一評估血管 CFR <2.0 且 IMR ≥25；部分 PCI 病人用 post-PCI physiology 定義 CMD。[文內]
  • Comparison：preserved microvascular function。
  • Outcome：主要終點為 all-cause death、MI、clinically driven repeat revascularisation、HF hospitalisation 的 patient-oriented composite outcome。[文內]
  • 設計：prospective multicentre cohort；ClinicalTrials.gov NCT05369182；protocol / SAP 在 appendix，但目前 markdown 未提供全文內容。[文內；限制：appendix 細節未完整保留]
  • 追蹤：門診 1、6、12 個月及每年，電話補追蹤；死亡狀態用 Korean National Health Insurance database cross-validation。[文內]
  • 統計：Kaplan–Meier、Cox proportional hazards、Schoenfeld residuals 檢查 PH assumption、Fine–Gray competing risk sensitivity、multivariable Cox backward selection；未做 missing baseline imputation。[文內]

6. 作者討論與評論重點

作者主張：CMD 常與 epicardial CAD 共存，且能補充 epicardial stenosis / FFR 之外的 risk stratification。作者也明確承認 observational design 無法因果推論，且 CMD 結果未對 treating physicians masked，可能影響後續處置。[文內]

評估：作者在結論中使用「associated with」大致克制；但「incorporating microvascular functional assessment for risk stratification」仍比資料更進一步，因為本文沒有證明測量 CMD 會改變治療、改善症狀或改善 hard outcomes。更準確說法應是：CMD 是高風險 phenotype marker，是否值得常規測量仍需 intervention trial 或 cost-effectiveness analysis。

8. 臨床建議

  • 可採用情境：在 tertiary center、已接受 invasive coronary physiology assessment 的疑似 ischemic heart disease 患者，CFR <2.0 且 IMR ≥25 可視為較高風險 marker，尤其可提醒追蹤 angina、HF、再血管化風險與 aggressive risk-factor control。
  • 不建議直接套用情境：一般門診胸痛、低風險族群、正常冠脈或 minimal disease、非韓國族群、未接受 invasive physiology 的病人；也不應把本文解讀為「所有 angiography 都應加做 CFR / IMR」。
  • 給臨床醫師的實務建議：
    1. 若已做 invasive physiology 且發現 CFR <2.0 + IMR ≥25，可把病人列為較高風險 phenotype，而非單純「PCI 成功就結束」。
    2. 對 persistent angina after PCI 或 non-obstructive CAD 病人，CMD 評估可協助解釋症狀，但治療仍需個別化，不能由本文推出特定 CMD-targeted therapy。
    3. 對高齡、CKD、HTN、NT-proBNP 高或 diffuse CAD 患者，要警覺 CMD 可能只是整體血管病變與心肌疾病負荷的指標。
  • 證據強度：中等偏弱。前瞻性、多中心、endpoint adjudication 是優點；但因觀察性設計、選擇性納入、未盲治療醫師、混雜控制有限，不能支持因果或常規篩檢政策。

A. 補充技術細節

  • 樣本數估算：計畫 1003 人，80% power，假設 No CMD 年事件率 8%、CMD 年事件率 20%、CMD 盛行率約 6.7%、dropout 0.5%。實際 CMD 盛行率 16.3%，主要終點 96 件。[文內]
  • 主要分析：time-to-event Cox model；PH assumption 用 Schoenfeld residuals 檢查。[文內]
  • 多重比較：主要終點單一；但 secondary endpoints、subgroups、endotypes、alternative cutoffs 多，且多數未見 multiplicity adjustment。作者將多數 subgroup / sensitivity 視為 exploratory，這點合理。[文內]
  • 缺失資料：baseline missing 不補值；但 markdown 未保留各變項缺失比例，無法判斷 missingness 是否影響 Cox model。[文內]
  • 暴露測量：CMD 以 CFR <2.0 且 IMR ≥25，偏向 structural CMD phenotype；但 356/1003 有 CFR 與 IMR discordant classification，顯示二分法會丟失大量生理異質性。[文內]

觀察性研究混淆控制

本文使用 multivariable Cox backward selection，而非 propensity score、IP weighting、target trial emulation 或 instrumental variable。JAMA Users’ Guide 對觀察性研究提醒：傳統 risk adjustment 仍容易受未測量或未知預後因子差異影響，propensity 方法也不能取代 randomization。[參考: jama_agoritsas_2017_ug_160001.md Conclusions]

Hernán & Robins 的 target trial 框架要求先明確指定欲模擬的隨機試驗，包括 eligibility、intervention、comparator、outcome、time zero 與 causal contrast。[參考: hernanrobins_WhatIf_2jan25.md 第 3.6 節] 本文若問題是「CMD 是否造成事件」，介入策略並不明確；若問題是「量測 CMD 並依結果治療是否改善預後」，本文也沒有比較 screening / treatment strategy。因此本文主要是 prognostic cohort，不是 causal effect study。

B. 批判性評估

B1. 假說與理論邏輯

問題：CMD 可能是 causal mediator，也可能只是 diffuse atherosclerosis、LV remodeling、CKD、HTN、糖尿病、HFpEF biology 的 marker。
文內證據：CMD 組較老、HTN / chronic renal insufficiency 較多、NT-proBNP 較高、FFR ≤0.80 與 PCI 比例較高。[Results]
風險方向：這些因素本身會提高 death、HF admission、repeat revascularisation，可能使 CMD-HR 被高估。
需要什麼才放心：預先指定 DAG、完整共變項清單、非線性處理、center/operator adjustment、medication / PCI strategy time-updated adjustment、negative control 或 external validation。

合理機轉包括：

  1. CMD 造成反覆微缺血與心肌纖維化，增加 HF / death 風險。
  2. CMD 反映 systemic endothelial dysfunction / inflammation，與 atherosclerotic progression 共同存在。
  3. 在 PCI 後 persistent angina 或 residual risk 中，微循環病變可能解釋部分非 epicardial stenosis 風險。

最可疑敘事跳躍：從「CMD associated with events」推進到「應納入常規 invasive risk stratification」。本文沒有證明測量後的治療行動會改善 outcome。

B2. 受試者與外推性

  • 5764 篩選但僅 1003 納入，納入率約 17.4%。大量排除 single severe stenosis、AMI、single-vessel disease、vasospasm、CABG、無 atherosclerosis、clinical instability 等。[Figure 1]
  • 族群為韓國 7 間 tertiary hospitals；男性 75.4%，median age 65。[Table 1]
  • Data on race / ethnicity not collected。[Methods]

外推性分級：中等偏低。
可外推到「韓國或類似高量 tertiary PCI center、接受 invasive physiology 的疑似 IHD 患者」。不宜外推到一般胸痛門診、低風險 non-invasive testing population、女性 INOCA 族群、正常冠脈族群或非亞洲族群。

B3. 研究設計與偏差

  1. Selection bias
    5764 screened → 1003 enrolled；physiology assessment 本身需要技術與臨床穩定性，留下的是「適合做 physiology」的族群，而非所有疑似 IHD。[Figure 1]

  2. Confounding by disease severity
    CMD 組更多 obstructive physiology、PCI、高齡、腎功能不全、NT-proBNP 高。[Results] 即使 Cox 調整後 HR 仍 1.65，但從 unadjusted 1.91 縮小，顯示混雜確實存在。

  3. Treating physician 未盲
    作者承認 coronary physiological results 未對治療醫師 masked。[Discussion limitations] 這特別會影響 repeat revascularisation、HF hospitalisation、用藥與追蹤密度等受臨床決策影響的終點。

  4. Composite endpoint 混合 hard 與 soft outcomes
    all-cause death / MI 較硬；repeat revascularisation 與 HF hospitalisation 較易受照護行為與醫師認知影響。主要效果可能部分由 repeat revascularisation 推動，而 MI HR 幾乎無差異。

  5. Post-PCI physiology 定義 CMD 的時間點問題
    20 名 PCI 患者以 post-PCI measurement 分類 CMD；PCI 本身可影響微循環，可能造成 exposure misclassification。[Results / limitations]

B4. 測量工具與實務意義

CFR / IMR 是有臨床生理意義的 invasive 指標，但本文採「任一血管」達 CFR <2.0 且 IMR ≥25 作 patient-level CMD，且多數病人不是三條主冠脈全測。作者承認 spatial heterogeneity 可能造成誤分類。[Discussion limitations]

臨床意義方面，2 年主要終點 KM 18.8% vs 10.5%，ARD 8.3%，數字上不小；但其中 repeat revascularisation 8.8% vs 4.0%、non-target revascularisation HR 5.21，可能反映疾病負荷、後續檢查與治療行為，而不一定是 CMD 自身造成硬事件。

C. 統計與資料完整性

C1. 結果分類

這不是治療試驗，因此不適合用 MCID 判定療效 positive / negative。作為 prognostic association：

  • 主要結果：HR 1.91, 95% CI 1.22–2.99；調整後 HR 1.65, 95% CI 1.02–2.66。
  • 分類：統計上支持 CMD 與較高 composite event risk 相關，但調整後 CI 下限接近 1，穩健性中等。
  • 臨床解讀：CMD 可作為風險分層 marker；不能作為因果治療標靶的直接證明。

C2. Underpowered / 精確度

整體主要終點 96 件，對一個主要 association 尚可；但 subgroup 不足：

  • Non-obstructive CAD + CMD 僅 40 人，主要事件 10 件，HR 3.45 的 CI 1.69–7.06 很寬。
  • Individual endpoints 事件少：MI 僅 12 件、cardiac death 20 件、HF hospitalisation 28 件；這些 endpoint 的 HR 不應過度解讀。
  • Treatment strategy interaction pinteraction=0.034，但作者也承認事件少且 exploratory；可信度低。

C3. Bayesian 補充分析

本文 p 值不在 borderline 解讀核心，且不是治療效果試驗；不執行 Bayesian benefit / ROPE 分類。

C4. 報告完整性與統計紅旗

  1. Composite endpoint 受 soft endpoint 影響：repeat revascularisation 會受醫師知道 CMD 結果影響。
  2. Backward selection：在 96 events 下做變項篩選，模型不穩與 overfitting 風險存在。
  3. 未提供完整 missingness：未 impute baseline variables，但 markdown 未呈現缺失比例。
  4. 多重 subgroup / secondary endpoints：未校正，多數只能探索性。
  5. NNH 表述疑點：Table 3 footnote 稱 NNH 12.0，但 95% CI 在 markdown 中呈現為 1.0–15.6，與 ARD 8.3%（95% CI 1.1–15.6）換算不一致；若用 ARD CI 換算，NNH 約 12，CI 應約 6.4–90.9。可能是 PDF 轉檔錯誤或原文表述問題，需查原 PDF。
  6. No public IPD：可合理申請 de-identified IPD，但 participant consent 未取得，資料透明度有限。
  7. No acetylcholine testing：vasospastic / endothelial CMD phenotype 未涵蓋，會限制 CMD endotype 完整性。

E. 紅旗清單

  • 主要暴露 CMD 結果未對治療醫師 blinded，soft endpoint 易受影響。
  • 只納入 1003/5764，外推性明顯受限。
  • CMD 組基線風險較高，殘餘混雜可能解釋部分 association。
  • Composite endpoint 混合 death、MI、repeat revascularisation、HF hospitalisation，臨床重要性不等。
  • MI 沒有增加訊號，主要風險可能不來自硬 coronary thrombotic events。
  • Subgroup 中 non-obstructive CAD + CMD 僅 40 人，HR 大但不精確。
  • 以 post-PCI physiology 定義部分 CMD，時間序列與分類一致性有問題。
  • 未做 acetylcholine testing，排除了重度 vasospasm，無法代表完整 ANOCA / INOCA spectrum。
  • 商業資助與作者領域立場均偏向推廣 invasive physiology assessment。

F. 反向解釋

  1. CMD 是 diffuse vascular disease marker，而非 causal driver
    支持：CMD 組較老、HTN / CKD / NT-proBNP / FFR-positive / PCI 比例較高。
    反對：調整後 HR 仍 1.65，但殘餘混雜不能排除。

  2. 較高 repeat revascularisation 來自 surveillance / treatment bias
    支持：醫師知道 physiology 結果，repeat revascularisation 是 clinically driven。
    反對：death 與 cardiac death 也有方向一致訊號，但事件少。

  3. CMD 分類捕捉到未充分處理的 epicardial / diffuse CAD
    支持：CMD 組 FFR ≤0.80 與 PCI 比例更高，non-target / deferred vessel revascularisation 增加。
    反對：non-obstructive CAD subgroup HR 更高，但該 subgroup 樣本小。

  4. 測量誤分類使效果被稀釋或扭曲
    支持：多數非全冠脈測量、23.6% multivessel discordance、356 人 CFR/IMR discordant。
    反對：sensitivity analyses 使用 pre-PCI-only 與 CFR <2.5 cutoff 方向一致。

G. 最終裁決

  • 整體可信度：中等。
    作為「CMD 與較差預後相關」的前瞻性 cohort，可信；作為「應常規加做 CMD assessment」或「治療 CMD 可改善 outcome」的證據，仍不足。

  • 可採用條件：已在 invasive coronary physiology 流程中的疑似 IHD 患者，CMD 可當作 residual risk marker，幫助安排追蹤與風險因子治療強度。

  • 不建議採用情境：不可把本文當成支持全民或所有 angiography 病人加做 CFR/IMR 的依據；不可據此選擇 PCI 或特定 anti-anginal therapy；不可直接外推到正常冠脈、女性 INOCA 主體族群或非韓國醫療體系。

  • 最需要的 3 個改進：

    1. 以 CMD-guided management vs usual care 設計 pragmatic RCT，終點分硬終點與症狀終點。
    2. 治療醫師對 CMD 結果 blinded 的 prognostic validation cohort，或至少避免 soft endpoint 被暴露資訊影響。
    3. 更完整 endotype：三主冠脈測量、acetylcholine testing、非侵入性 perfusion / CMR fibrosis 結合，並做外部族群驗證。
