Effects of Finerenone on Sudden Death Across the Cardio-Kidney-Metabolic Landscape: A FINE-HEART Analysis.

0. 文章身份證

  • 題名：Effects of Finerenone on Sudden Death Across the Cardio-Kidney-Metabolic Landscape: A FINE-HEART Analysis
  • 期刊 / 年份：JACC, 2026；DOI 10.1016/j.jacc.2026.04.045；PMID 42233928 [文內；JACC 頁面]
  • 文章類型：prespecified participant-level pooled analysis of 3 placebo-controlled RCTs。核心治療效果來自隨機分派，但本篇的主要終點 sudden death (SD) 是 pooled secondary / cause-specific outcome，不是三個原始試驗的共同 primary endpoint。

3. 研究背景

作者的出發點是：CKM syndrome 患者有高 CV mortality，HF、CKD、糖尿病個別都與 sudden death 增加有關，但重疊 CKM 條件下 SD 風險與 finerenone 對 SD 的效果仍不清楚 [Introduction]。Finerenone 已被證明可改善 CV / kidney outcomes，但 SD 並非過去試驗主要 powered outcome。

Research question：[推論] 在 FINE-HEART 三個 phase III 試驗 pooled population 中，哪些 baseline factors 預測 SD？finerenone 是否降低 adjudicated SD？

4. 研究設計與方法

  • P：18,991 名 CKM spectrum 患者；FIDELIO-DKD / FIGARO-DKD 為 CKD + T2D；FINEARTS-HF 為 HFmrEF / HFpEF，LVEF ≥40% [Methods]
  • I：finerenone，依 eGFR 起始 10 或 20 mg，FINEARTS-HF 部分可 titrate 至 40 mg [Methods]
  • C：placebo
  • O：本分析 primary endpoint 為 centrally adjudicated SD；另看 CV death、HF death、MI、stroke、other CV death、non-CV、undetermined death [Methods, Table 3]
  • 設計：prespecified、registered、participant-level pooled analysis；三個母試驗皆為 randomized, double-blind, placebo-controlled trial。
  • 主要分析：ITT；Cox models stratified by region and trial；Fine-Gray competing risk model；trial-level random-effects meta-analysis；subgroup interaction；predicted-risk spline interaction [Statistical Analysis]
  • SD 定義：unexpected death in otherwise stable subject with last contact within 24h；FINEARTS-HF 的 presumed SD 未納入 pooled SD definition；FIDELIO/FIGARO undetermined deaths 主分析不納入 CV mortality [Cause-specific death definitions]。

6. 作者討論與評論重點

作者主張：SD 是 CKM syndrome 重要且低估的死亡型態；finerenone 可能透過抗發炎、抗纖維化、抗氧化、減少 AF、穩定 potassium homeostasis 來降低 arrhythmic vulnerability [Discussion]。

作者限制有誠實列出：死因可能誤分類、other CV mortality 類別異質、FIDELIO/FIGARO 未收 LVEF、ICD baseline 未系統收集、三試驗族群異質、CKM stage 0–1 缺席、stage 2–3 合併、嚴格試驗條件限制外推性 [Study Limitations]。這些限制相當關鍵，尤其 SD without autopsy、ICD 缺失與 LVEF 缺失會直接影響 SD 解釋。

[評估] 作者把結果寫成「associated with lower risk」相對保守，但 Perspective / Central Illustration 的「mitigation of arrhythmic mortality」已接近機轉性宣稱；本文沒有 ventricular arrhythmia、ICD therapy、hypokalemia mediation analysis 或 rhythm monitoring，不能證明抗心律不整機轉。

8. 臨床建議

可採用情境：已符合 FIDELIO / FIGARO / FINEARTS-HF 類似條件的 CKD+T2D 或 HFmrEF/HFpEF 患者，且 potassium、eGFR、血壓符合 trial eligibility，可把「可能降低 SD」視為 finerenone 整體 CV / kidney benefit 的附加支持。

不建議直接外推：baseline K 接近或高於排除門檻者、HFrEF、advanced HF、kidney failure、CKM stage 0–1、ICD 高比例族群、非試驗照護環境、無法密切監測 potassium / renal function 的病人。

實務建議：不要為了「預防猝死」單獨開 finerenone；應在已符合 CKD+T2D 或 HFmrEF/HFpEF 適應症時，把此結果納入整體風險效益討論。臨床採用仍要優先看 potassium safety、腎功能、血壓與既有 guideline indication。

證據強度：中等。優點是 participant-level randomized pooled data、central adjudication、prespecified analysis；弱點是 SD 是少事件的 cause-specific secondary outcome，CI 貼近 1，絕對效益小，且機轉未直接驗證。

B. 批判性評估

B1 假說與理論邏輯
假說合理：MRA 可能減少 fibrosis、inflammation、AF、potassium fluctuation，進而降低 arrhythmic death。但本文只觀察 adjudicated SD，沒有 arrhythmia endpoint 或 mediation analysis。最可疑跳躍是：SD reduction → arrhythmic mortality mitigation；SD adjudication 並不等於 documented ventricular arrhythmia。

B2 受試者與外推性
外推性中等偏窄。母試驗排除高 potassium、kidney failure、HFrEF、very advanced HF；CKM stage 0–1 不在資料中；FIDELIO/FIGARO 沒有 baseline LVEF 與 ICD 系統資料 [Study Limitations]。真實世界 CKM 患者常更老、更高鉀、更多 device / HFrEF / kidney failure，效益與安全性不一定相同。

B3 研究設計與偏差
主要優點是 randomized treatment assignment、central blinded adjudication、participant-level harmonization。主要風險是 endpoint harmonization 的取捨：FINEARTS-HF presumed SD 不納入，FIDELIO/FIGARO undetermined deaths 主分析不納入 CV mortality；若 misclassification 與 trial / region / treatment 有關，SD HR 可能偏移。Other CV death 反向增加 HR 1.83 也提醒 cause-of-death reclassification 可能影響各死因桶子的方向。

B4 測量工具與實務意義
SD 是臨床重要硬終點，但死因分類本身不是硬到沒有誤差；沒有 autopsy、ICD data、rhythm documentation 時，unexpected death within 24h 仍可能混入 MI、PE、stroke、HF worsening 或 non-CV causes。絕對效益小：0.16/100 PY，約 216 人治療中位 2.9 年避免 1 件 SD；臨床上有意義，但不應被誇大為主要開藥理由。

C. 統計與資料完整性

C1 CI + MCID 分類
文內未預先指定 SD 的 MCID。若以死亡 outcome 常見臨床門檻粗估，HR 0.81 看似達到相對 15%–20% 降幅，但 CI 0.67–0.98 下緣有臨床吸引力、上緣只差 2% relative reduction，精確度不足。分類：IMPRECISE (+)，不是穩健 positive。p=0.034 不應單獨作為結論核心。

C2 Underpowered / Winner’s Curse
SD 418 事件，在 pooled RCT 中不算極少，但不是預設 powered endpoint；CI 貼近 null，且各 trial subgroup 均跨 1：FIDELIO 0.84 (0.53–1.31)、FIGARO 0.71 (0.50–1.01)、FINEARTS-HF 0.87 (0.66–1.13)。整體顯著可能受 pooled precision 推動，效果量有 winner’s curse 風險，後續試驗不應直接用 HR 0.81 當保守設計假設。

C3 Bayesian 補充解讀
未做正式 Bayesian 分析。以頻率派 CI 來看，posterior 直覺會是「有一定機率有小到中等利益，但仍保留接近無效的可能」。若臨床問題是「finerenone 是否真正 anti-arrhythmic」，目前資料不足以給高機率結論。

C4 統計紅旗清單

  1. SD 非三個母試驗 primary endpoint，且本文未對 SD powered。
  2. 多個 cause-specific death outcome 與 subgroup analyses，未見 multiplicity correction。
  3. Predictor model 使用 stepwise forward selection；雖做 bootstrap stability，但 stepwise 仍容易選出不穩定或過度樂觀的 predictors。
  4. 死因分類可能 misclassification；undetermined / presumed SD 的處理會影響估計。
  5. 缺 LVEF、ICD、autopsy、arrhythmia documentation，限制 SD 機轉解釋。
  6. Subgroup consistency 多數只是 interaction p 不顯著，不等於各 subgroup 都證實有效。
  7. Other CV death 顯著較高，雖事件少且異質，但需要避免只強調有利死因分類。

D. 次組分析評估

主要 subgroup 包括 age、sex、race、trial、CKM condition number、DM、MI、AF/AFL、HF、CKD；interaction p for trial 0.71、CKM condition 0.93、CKM stage 0.68 [Results / Figure 5]。

可信度：低到中等。有 interaction testing 是優點，但多數 subgroup event counts 小、CI 寬，且沒有明確預先指定每個 subgroup 的方向與生物假說。正確解讀是「未見明確異質性」，不是「所有 subgroup 均有確定效益」。

E. 紅旗清單

  • Sponsor 與多位作者 COI 高度密集，且結論有利於擴大 finerenone positioning。
  • 絕對效益小，敘事中相對降幅 19% 較醒目。
  • SD adjudication 不等於 documented arrhythmic death。
  • 缺 LVEF / ICD / autopsy 資訊，正好是猝死風險與預防最關鍵資料。
  • p=0.034、CI 0.67–0.98：結果脆弱，接近 null。
  • Other CV death HR 1.83 不利訊號需要後續釐清。
  • Real-world 高鉀與 advanced CKM 患者外推有限。

F. 反向解釋

  1. 死因重分類效應：finerenone 組 SD 較少，但 other CV death 較多；若部分 unexpected deaths 被分類到不同死因桶，SD benefit 可能被放大。支持線索：other CV HR 1.83；反對線索：all-cause death 方向仍 favor finerenone。
  2. 整體 CV risk reduction 而非特異 anti-arrhythmic effect：SD 下降可能只是 HF / ischemic / renal events 整體改善的下游結果，不代表直接抗 ventricular arrhythmia。
  3. trial population selection：低鉀風險、嚴格監測、排除高鉀者，使 benefit-risk 在試驗中較理想；真實世界未必重現。
  4. chance finding under multiplicity：在多個 cause-specific endpoints 中 SD 達 p=0.034，仍可能是多重檢定下較有利的訊號。

G. 最終裁決

整體可信度：中等。

可採用條件：對已符合 finerenone 適應症、可監測 potassium / eGFR、且類似 FIDELIO / FIGARO / FINEARTS-HF 族群者，可把 SD 降低視為額外支持證據。

不建議採用情境：不要把本篇當作 finerenone「猝死預防藥」的單獨依據；不要外推到 HFrEF、advanced kidney failure、高鉀、ICD 高風險族群或 CKM stage 0–1。

若要改觀，最需要：

  1. 以 SD / arrhythmic death 為預設 endpoint 的獨立驗證。
  2. 系統收集 LVEF、ICD、rhythm documentation、autopsy 或 device therapy。
  3. 釐清 other CV death 增加與 cause-of-death adjudication 穩健性。

一句話結論：Finerenone 可能降低 CKM 患者猝死，但目前更像有利訊號，不是確證的抗心律不整證據。
