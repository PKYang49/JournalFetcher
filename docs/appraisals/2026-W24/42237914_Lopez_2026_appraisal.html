Incremental Prognostic Value of Subendocardial Myocardial Flow Reserve in Patients With Normal Perfusion.

  • 標題：Incremental Prognostic Value of Subendocardial Myocardial Flow Reserve in Patients With Normal Perfusion
  • 期刊 / 年份 / DOI：Circulation，2026，10.1161/CIRCULATIONAHA.125.078816 [文內]
  • 文章類型：多中心 registry 的回溯性觀察性預後研究；不是診斷準確度研究，也不是介入試驗。

3. 研究背景

作者的出發點是：PET MFR 已是評估 coronary microvascular dysfunction / diffuse atherosclerosis 的重要非侵入性指標；但傳統 transmural MFR 是整層心肌平均，可能稀釋 subendocardium 的早期灌流異常。subendocardium 因壁張力、代謝需求與灌流壓敏感性，理論上較早受損 [Introduction]。知識缺口是：在 transmural MFR preserved、perfusion normal 的「看似低風險」病人中，MFRSE 是否仍提供獨立預後資訊。

4. 研究設計與方法

  • P：2007–2024 年 3 個 academic centers，接受 rest-stress Rb-82 PET、normal perfusion（stress TPD ≤5%）者；排除 CABG、心臟移植 / 其他心臟手術、LVEF <40%、非血管擴張壓力測試、影像品質不足或無臨床資料者 [Methods]。
  • E / index marker：subendocardial MFR，以 QPET research version 進行 layer-specific segmentation；inner half LV wall 作為 subendocardial approximation [Quantification of MBF and Flow Reserve]。
  • C：concordant-normal（MFRTM ≥2.0 且 MFRSE ≥2.1）與 abnormal MFRTM（MFRTM <2.0）。
  • O：primary MACE = all-cause death、nonfatal MI、HF hospitalization、late revascularization ≥90 天；secondary = all-cause mortality [Clinical Outcomes]。
  • 統計：MFRSE 2.1 cutoff 由 derivation set 的 Youden index 決定，另以 1:1 split validation；Cox models 調整 age、sex、diabetes、hypertension、hyperlipidemia、prior MI、prior PCI、BMI、LV mass index、LVEF、CAC；Schoenfeld residuals 檢查 proportional hazards；Poisson regression 估 adjusted annualized event rate [Statistical Analysis]。
  • 關鍵限制：這是 marker prognostic association，不是測試 MFRSE-guided management 是否改善 outcome。

6. 作者討論與評論重點

作者主張 MFRSE 能在 normal perfusion、preserved MFRTM 的病人中揭露額外風險異質性，並可能代表早期 CMD 或局部 subendocardial vulnerability [Discussion]。作者也承認：回溯性 clinically referred cohort、residual confounding、MFRSE 無既定 reference values、PET spatial resolution 使 subendocardial flow 只能以 inner half wall 近似、hospitalization 事件可能漏抓、無 angiographic anatomy、僅 Rb-82 PET [Limitations]。

評估：作者對限制的描述相當完整，但「may guide diagnosis, risk assessment, and personalized treatment strategies」這類 clinical implication 已經超過資料能直接證明的範圍。本文能支持 risk stratification association；不能支持改變治療會改善 outcome。

8. 臨床建議

  • 可採用情境：已做 Rb-82 PET、perfusion normal、MFRTM ≥2.0 但臨床風險仍高或症狀持續者，可把低 MFRSE 視為「較高風險標記」，加強風險因子控制與後續評估。
  • 不建議直接套用：一般健康篩檢、非 PET 平台、非 Rb-82 tracer、低品質影像、或用 MFRSE 單獨診斷 CMD / 排除 obstructive CAD。
  • 實務建議：若報告 MFRSE，應同時報告 MFRTM、stress/rest MBF、CAC、LVEF reserve、TID 與影像品質；低 MFRSE 不應自動等同於需要 invasive angiography 或特定藥物。
  • 證據強度：中等。樣本大、事件多、多中心且有 adjusted HR / absolute risk；但 cutoff data-derived、無外部獨立 cohort、無 decision-curve / NRI / C-statistic 改善資料，臨床可行性仍未驗證。

SKILL-A：觀察性預後研究批判性評讀

A. 補充技術細節

  • 樣本數估算：未見事前 sample size / power calculation；registry study 通常以可得資料為主。事件數 1661 MACE 對主要 Cox model 來說足夠，但 cutoff derivation 與 subgroup analysis 仍有 optimism 風險。
  • 暴露定義：MFRSE cutoff 2.1 由 Youden index 在本 cohort derivation set 選出。這是本文最大方法學節點：cutoff 是資料驅動，不是外部標準。
  • Cox 模型：有檢查 Schoenfeld residuals [Statistical Analysis]。
  • 缺失資料：follow-up 99.7% 可得，但 clinical covariates missingness / imputation 未在 markdown 中看到；無法判定是否 complete-case。
  • 混淆控制：調整多個臨床與影像 covariates，包括 CAC。但沒有藥物治療、腎功能、血壓控制、症狀嚴重度、社經因子、site/scanner/protocol 變異的完整處理資訊。
  • Target trial 對應：若臨床問題是「測 MFRSE 並據此治療是否改善預後」，本文尚未模擬 intervention；只能回答 prognostic enrichment。

B. 批判性評估

B1. 假說與理論邏輯

理論合理：subendocardium 較易受壁張力、灌流壓與代謝需求影響，整層平均 MFRTM 可能遮蔽內層異常 [Introduction / Discussion]。但本文的論證有一個關鍵跳躍：MFRSE 較低與事件較多，可能是 microvascular disease 訊號，也可能是更高 comorbidity burden、rest MBF 較高、CAC 較高、血壓 / 心率 / referral indication 差異的殘餘風險標記。

B2. 受試者與外推性

  • 外推性中等偏窄：三個 academic PET centers，病人為 clinically referred cohort，平均 66 歲、79.6% White、hypertension 78.9%、diabetes 28.0% [Table 1]。這不是一般低風險門診人口。
  • discordant 組比 normal 組年齡更高、糖尿病 / 高血壓 / PAD / prior PCI 更多，CAC 也更高 [Table 1, Table 2]。調整後 HR 仍顯著，但這種 baseline gradient 讓 residual confounding 很難完全排除。
  • 不宜外推到：年輕低風險、非 White 族群比例高的 population、非 Rb-82 PET、或沒有 Cedars-Sinai QPET layer-specific pipeline 的系統。

B3. 研究設計與偏差

  1. 問題：cutoff 由本文資料決定。
    文內證據：MFRSE threshold 2.1 由 Youden’s index 在 derivation set 決定 [Statistical Analysis / Results]。
    風險方向：會高估分組的預後差異與臨床可用性。
    需要什麼才放心：完全外部 validation cohort，固定 2.1 cutoff，不再重調。

  2. 問題：MACE composite 由 all-cause death 主導。
    文內證據：1661 MACE 中 death 1223；MACE first event 中 death 60.9% [Clinical Outcomes]。
    風險方向：MFRSE 可能主要是在捕捉整體健康狀態 / frailty / comorbidity，而非特異性 CAD/CMD 事件。
    需要什麼才放心：cardiovascular death、MI、HF、revascularization 分別報告 adjusted HR，以及 cause-specific validation。

  3. 問題：無 coronary anatomy。
    文內證據：作者承認無 angiographic coronary anatomy，不能 definitively exclude multivessel CAD [Limitations]。
    風險方向：部分 discordant low-MFRSE 可能不是 isolated CMD，而是 occult multivessel / diffuse epicardial disease。
    需要什麼才放心：CCTA 或 invasive angiography / FFR / plaque burden 的整合分析。

B4. 測量工具與實務意義

QPET centralized batch processing、motion correction 與 kinetic model 是優點 [Methods]。但 subendocardial flow 受 PET spatial resolution 與 partial volume effect 限制，作者承認 inner half wall 近似可能包含 mid-myocardial layers 並 overestimate MFRSE [Limitations]。因此，若連 overestimated MFRSE 都偏低，可能確有訊號；但同時也代表不同 scanner、reconstruction、software version 的可重複性非常關鍵，本文 markdown 未提供 inter-site reproducibility 或 test-retest reliability。

實務上，discordant 組 MACE adjusted AER 5.79%/yr vs 3.99%/yr，絕對差約 1.8%/yr；這在風險分層上有意義。但文內未報告加入 MFRSE 後 C-statistic、NRI、IDI、calibration、decision curve 或 treatment threshold impact，所以「incremental prognostic value」目前主要是 adjusted HR / event rate 層級，不是完整 prediction-model 層級。

C. 統計與資料完整性

C1. 結果分類：CI + 臨床意義

本文未預先指定 MFRSE 的 MCID 或臨床決策門檻。就預後 marker 而言，比較合理的臨床判讀是絕對風險差與是否改變處置。

分類：不是 causal positive，而是「預後關聯明確、臨床決策效用尚未確立」。

C2. Underpowered / Winner’s Curse

整體事件數大，主要比較不是 underpowered。真正風險是 data-derived cutoff 與 split-sample validation 仍來自同一 registry 生態；外部效度可能被高估。Winner’s curse 在這裡不是小樣本陽性，而是 threshold optimism。

C3. Bayesian 補充分析

主要 HR CI 不貼近 null，Bayesian 補充不是必要。更需要的是 prediction utility：固定 cutoff 的外部 validation、net benefit、calibration 與 reclassification。

C4. 統計紅旗清單

  • MFRSE cutoff 2.1 由同一研究資料衍生，缺外部 validation。
  • 「incremental value」未見 C-statistic / likelihood ratio χ² / NRI / decision curve。
  • composite MACE 由 all-cause death 主導，疾病特異性較弱。
  • covariates 調整不足以排除 residual confounding，尤其 medication、renal function、site effects、socioeconomic status。
  • 無 coronary anatomy，normal perfusion 不等於排除 diffuse / balanced multivessel CAD。
  • 未見 competing risk 對 all-cause death 主導 composite 的完整處理；CV-specific composite 有 Fine-Gray，但細節有限。
  • sex subgroup 中女性 mortality association 調整後不顯著；不應過度宣稱男女 mortality utility 完全一致。

D. 次組分析評估

文內有 sex-stratified analysis。可信度：中低。

  • interaction p-value：markdown 未見；不能只因男女各自 HR 顯著與否不同就推論 sex difference。
  • 預先指定：文內只說 subanalysis stratified by sex，未見 protocol。
  • 生物機轉：CMD / INOCA 在女性較常見，具合理性，但本結果女性 mortality HR 1.20（0.94–1.51）不顯著。
  • 結論：MACE association 在男女看似一致；mortality 的 sex-specific claim 應保守，最好報 interaction p 與 sex-specific absolute risks。

E. 紅旗清單

  • 把「風險標記」語氣推到「personalized treatment strategies」，超過資料。
  • cutoff 未外部驗證。
  • commercial/software COI 與研究結論方向一致。
  • 無 coronary anatomy，無法把 CMD 與 diffuse epicardial CAD 清楚分開。
  • composite endpoint 包含 late revascularization，可能受醫師行為與後續檢查影響。

F. 反向解釋

  1. Comorbidity marker，而非獨立病理機轉：discordant 組年齡、HTN、DM、PAD、prior PCI、CAC 都較高；MFRSE 可能是整體血管老化 / comorbidity burden 的影像代理。
  2. Rest MBF elevation 驅動 MFRSE 下降：discordant 組 subendocardial rest MBF 1.40，高於 normal 1.22；MFR 是 stress/rest ratio，rest flow 升高本身會降低 ratio，可能反映血壓、心率、代謝或藥物狀態。
  3. Occult diffuse / multivessel CAD：normal relative perfusion 與 MFRTM ≥2 不排除 diffuse CAD；無 CCTA / angiography 是核心限制。
  4. Site / scanner / processing artifact：layer-specific PET flow 接近解析度極限，若不同中心 protocol 差異與 patient mix 相關，可能造成系統性偏差。

G. 最終裁決

  • 整體可信度：中等。
  • 可採用的條件：作為 PET 報告中的額外風險分層資訊，尤其在 normal perfusion 但臨床風險偏高或症狀持續者。
  • 不建議採用的情境：單獨用 MFRSE 診斷 CMD、決定侵入性檢查、或啟動特定治療；也不宜跨 tracer / scanner / software 直接套用 2.1 cutoff。
  • 若要改觀，最需要：
    1. 固定 2.1 cutoff 的外部多中心 validation。
    2. 報告 C-statistic、calibration、NRI / IDI、decision-curve net benefit。
    3. 整合 CCTA / angiography、藥物、腎功能與 site random effects，拆解 CMD vs diffuse CAD vs comorbidity。
  • 一句話結論：MFRSE 是有潛力的風險標記，但還不是能直接改變治療的決策工具。
