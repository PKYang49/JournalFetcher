Incremental Prognostic Value of Subendocardial Myocardial Flow Reserve in Patients With Normal Perfusion.

0. 文章身份證

  • 標題：Incremental Prognostic Value of Subendocardial Myocardial Flow Reserve in Patients With Normal Perfusion
  • 期刊 / 年份 / DOI：Circulation, 2026; DOI: 10.1161/CIRCULATIONAHA.125.078816 [文內]
  • 文章類型：多中心回溯性臨床登錄世代研究，屬於觀察性預後研究。
  • 核心問題：在 stress/rest Rb-82 PET 顯示正常灌流、且傳統 transmural MFR 看似正常的病人中，subendocardial MFR 是否能額外辨識較高風險族群？

通訊作者 Diana M. Lopez 來自 Brigham & Women’s Hospital；共同 senior authors 為 Piotr J. Slomka 與 Marcelo F. Di Carli [文內]。團隊組成橫跨 Brigham、Cedars-Sinai、Intermountain、Mayo、Columbia、Zurich 等心臟影像與核醫中心，屬於 PET myocardial blood flow / nuclear cardiology 的核心研究群。

Piotr Slomka 的 Cedars-Sinai lab 官方介紹聚焦於核醫心臟影像自動化分析、PET/CT angiography 整合與 machine learning；這與本文使用 QPET、layer-specific segmentation、DL CAC quantification 高度一致 外部: Cedars-Sinai Slomka Lab。ACC 對 2024 年 Xu/Divakaran/Weber 等同一研究脈絡的 hypertensive cohort 摘要指出，較低 subendocardial MFR 與較高 CV risk、心肌 injury marker、HF hospitalization/all-cause death 相關 外部: ACC Journal Scan。因此本文不是首次切入，而是同一研究主軸的擴大、多中心預後驗證。

COI / funding：NIH、AHA、ASNC 等資助 [文內]。但多位作者揭露與 GE HealthCare、Siemens、Philips、QPS software、APQ Health、MedTrace、Ionetix 等影像、軟體、核醫相關產業關係 [文內]。這不直接否定結果，但本文結論會推動 layer-specific PET quantification 與特定軟體流程的臨床價值，COI 與敘事方向有合理關聯，解讀時要提高警覺。

3. 研究背景

作者的出發點是：PET MFR 已是評估 coronary microvascular dysfunction 的重要非侵入工具，但傳統 MFR 是 full-thickness 平均；subendocardium 因代謝需求與灌流壓脆弱性，可能較早出現異常。既有研究提示 reduced subendocardial flow 與 adverse outcomes 相關，但在 preserved transmural MFR 的病人中，MFR_SE 是否有獨立/增量預後價值仍不清楚 [Introduction]。

4. 研究設計與方法

PICO

項目 內容
P 2007–2024 年 3 個 academic centers，接受 rest-stress Rb-82 PET、normal perfusion（stress TPD ≤5%）的臨床轉介病人
Exposure MFR group：concordant-normal、discordant low MFR_SE with normal MFR_TM、abnormal MFR_TM
Comparator 主要為 concordant-normal；另比較 abnormal MFR_TM vs discordant
Outcome 主要：time to first MACE，含 all-cause death、nonfatal MI、HF hospitalization、late revascularization ≥90 天；次要：all-cause mortality

關鍵方法：QPET 中央批次處理；MFR_TM abnormal cutoff 採既有 <2.0；MFR_SE 無既有標準，本文用 1:1 derivation/validation split 加 Youden’s index 得到 2.1。Cox 模型調整 age、sex、diabetes、HTN、hyperlipidemia、previous MI/PCI、BMI、LV mass index、LVEF、CAC；並檢查 Schoenfeld residuals [Statistical Analysis]。

6. 作者討論與限制

作者主張：MFR_SE 可在傳統 MFR_TM 正常與 normal perfusion 的病人中，重新分類約 17.8%（885/4988），辨識 intermediate-risk phenotype。作者承認的限制包括：回溯觀察性、臨床轉介族群、殘餘混淆、MFR_SE 無 established reference values、PET 空間解析度限制、hospitalization ascertainment 可能不完整、無 angiographic anatomy、僅 Rb-82 PET [Limitations]。

我的評估：限制寫得相對完整，但最關鍵的「cutoff 在同一 cohort 內 data-driven 產生」與「incremental value 是否超越連續 MFR_TM/CAC/TID/LVEF reserve 的正式 reclassification 指標」仍不足。作者說 “clinically meaningful risk heterogeneity” 合理；若推到「應常規改變 PET interpretation 或治療策略」則超出本文資料。

7. 臨床建議

可採用情境：已在高品質 PET MPI 中取得 layer-specific MBF/MFR、病人為 symptomatic / clinically referred、relative perfusion normal、MFR_TM 接近正常低端時，MFR_SE 可作為風險分層補充訊號。

不建議直接套用：無症狀篩檢族群、低風險健康族群、非 Rb-82 tracer、非 QPET 或未驗證軟體、沒有標準化動態影像品質控管的中心。

實務建議：

  1. 不要把 MFR_SE <2.1 當成診斷 obstructive CAD 或必須介入的門檻。
  2. 可把 discordant low MFR_SE 視為「microvascular / diffuse atherosclerotic risk marker」，加強風險因子控制。
  3. 若症狀持續，應結合 CCTA、CAC、症狀型態與其他 ischemia/CMD 評估，而不是只靠 MFR_SE 決策。

證據強度：中等。樣本大、多中心、事件多、效果一致；但仍是回溯觀察性、cutoff data-driven、治療可改變性未證明。

A. 補充技術細節

沒有事前樣本數估算或 power calculation；這是 registry prognostic analysis，可接受但仍限制 inferential planning。MFR_SE cutoff 用 derivation/validation split 與 Youden’s index，但補充表 S1 未在 markdown 中呈現，無法評估 validation set 的效能、AUC、calibration 或 optimism。比例風險假設以 Schoenfeld residuals 驗證 [Statistical Analysis]。缺失 outcome 僅 19/6603，完整性佳；但 hospitalization 外院事件可能漏抓。

B. 批判性評估

B1 假說與理論邏輯：機轉合理，subendocardium 較易受 wall stress、灌流壓與微血管功能影響。但本文結果也可由較高 rest MBF、血壓、CAC、糖尿病與年齡組合反映整體 cardiometabolic burden，而非純粹「早期 subendocardial ischemia」。

B2 受試者與外推性：三中心 academic PET registry，White 79.6%，臨床轉介、胸痛為主。可外推到類似高階 PET 中心的 symptomatic population；不能外推到一般門診低風險族群或亞洲族群。Discordant 組比 normal 組年長、HTN/DM/PAD/PCI/CAC 更高，雖有調整，但 residual confounding 很可能仍存在。

B3 設計與偏差：最大問題是 exposure threshold 由 outcome 最佳化產生。即使用 split validation，也仍需外部驗證，否則 MFR_SE <2.1 可能是本 registry 的 calibration artifact。另一問題是 MACE composite 以 all-cause death 為最大成分，death first event 60.9%；這提高事件數與統計力，但其病理特異性低，較難說明是 subendocardial microvascular abnormality 造成。

B4 測量與實務意義：subendocardial layer 被定義為 LV wall inner half；作者承認受空間解析度限制，可能包含 central myocardium 並高估 MFR_SE。這是核心測量限制。臨床上 adjusted MACE AER 從 3.99% 到 5.79%/year，絕對差約 1.8%/year，對風險溝通有意義；但尚未證明根據此資訊治療會改善 outcome。

C. 統計與資料完整性

主要結果不是治療效果，MCID 不適用；應以預後 discrimination、calibration、reclassification 與 clinical utility 判讀。本文提供 HR 與 AER，但缺少 C-statistic change、net reclassification improvement、integrated discrimination improvement、decision curve analysis。題名使用 “incremental prognostic value”，但 markdown 中可見資料主要是 adjusted association 與分層 event rate，尚不足以完整證明臨床層級的 incremental value。

統計紅旗：

  • MFR_SE cutoff 2.1 是 data-driven，需外部驗證。
  • 多個 outcome、pairwise comparison、sex subgroup，未見多重比較校正。
  • Composite MACE 混合 all-cause death、MI、HF、late revascularization，臨床重要性與機轉特異性不等。
  • 調整模型未見 renal function、medication、socioeconomic factors、site/scanner protocol、stress agent/site effect。
  • 未提供連續 MFR_SE 的 dose-response / spline 結果於主文 markdown。
  • 未正式呈現 incremental discrimination / calibration。
  • 女性 all-cause mortality subgroup CI 跨 1，仍應稱為不精確，不是「男女死亡風險一致」。

D. 次組分析

Sex subgroup：文內有 stratified Cox/Poisson。可信度 中低。有生物合理性，但 markdown 未見 interaction p-value；不能只因男女各自 HR 類似或其中一組顯著就宣稱 effect modification。女性 ACM discordant vs normal HR 1.20（0.94–1.51）顯示不確定性仍大。

E. 紅旗清單

  • 「incremental value」未搭配正式 reclassification / discrimination 指標。
  • Cutoff 由同一研究族群推導，臨床門檻尚未穩固。
  • 產業與軟體相關 COI 多，且研究結論支持更廣泛使用進階影像軟體。
  • 無 angiographic anatomy，balanced multivessel CAD 雖少見但不能完全排除。
  • 事件主要由 all-cause death 驅動，與 subendocardial physiology 的因果連結較弱。
  • Figure 3 後期 number-at-risk 小，KM 尾端不可過度詮釋。

F. 反向解釋

  1. 整體 cardiometabolic risk marker：MFR_SE 低可能只是年齡、HTN、DM、CAC、resting hemodynamics 的綜合表現；調整後仍殘餘混淆。
  2. 低正常 MFR_TM 的邊界現象：discordant 組 MFR_TM 中位數 2.15，接近 cutoff 2.0；所謂 layer-specific 訊號可能部分是 transmural MFR 連續風險被二分法遮蔽。
  3. 技術/軟體量測現象：inner-half segmentation、partial volume、scanner/site protocol 差異可能影響 MFR_SE，需跨 tracer、跨軟體驗證。

G. 最終裁決

整體可信度：中等。
這篇研究支持 MFR_SE 是有價值的預後風險標記，尤其在 normal perfusion 且 MFR_TM ≥2 的病人中，可辨識一群風險介於 normal 與 abnormal MFR_TM 之間的人。但它還沒有證明 MFR_SE <2.1 是可直接改變臨床處置的標準化門檻。

最需要的 3 個改進：

  1. 外部 cohort 驗證 MFR_SE 2.1 cutoff，最好跨 tracer / scanner / software。
  2. 報告 C-statistic、calibration、NRI/IDI、decision curve，證明真正 incremental value。
  3. 前瞻性研究測試依 MFR_SE 風險分層後的治療策略是否改善症狀或 hard outcomes。

一句話結論：MFR_SE 可補強 PET 預後分層，但目前是風險標記，不是治療決策門檻。
