IVUS-Guided versus Angiography-Guided PCI in Unprotected Left Main Coronary Disease.

0. 文章身份證

  • 標題：IVUS-Guided versus Angiography-Guided PCI in Unprotected Left Main Coronary Disease
  • 期刊 / 年份：New England Journal of Medicine, 2026
  • DOI / PMID：10.1056/NEJMoa2600440 / PMID 41911017
  • 文章類型：多國、多中心、開放標籤、1:1 隨機分派、superiority RCT
  • 路由：SKILL-A，人體臨床隨機對照試驗
  • 核心問題：在 unprotected left main coronary artery disease 接受 PCI 的病人，常規 IVUS-guided PCI 是否比 angiography-guided PCI 改善臨床結果？

3. 研究背景

作者指出 unprotected left main disease 約見於 4–6% 接受 diagnostic coronary angiography 的病人，預後風險高；CABG 長期為首選，但 RCT 已支持低至中等解剖複雜度病人可接受 PCI。[文內 Introduction]

IVUS 的理論優勢是較佳病灶評估、stent sizing、apposition、expansion 與 edge dissection 檢出；既有觀察性研究與 meta-analysis 顯示 IVUS 可能降低死亡、MI、stent thrombosis，但專門針對 unprotected left main PCI 的大型 RCT 不足。[文內 Introduction]

Research question：在適合 PCI 的 unprotected left main coronary disease 病人中，IVUS-guided PCI 是否能降低 ischemic events 或死亡，相較於 angiography-guided PCI？[文內]

4. 研究設計與方法

  • P：18 歲以上、unprotected left main coronary artery disease，視覺估計 stenosis ≥50%，由 heart team 或 operator 判定適合 PCI；需有中重度 ischemia 或症狀且接受 guideline-directed medical therapy。[文內 Methods]
  • I：IVUS-guided PCI；術前 IVUS 強烈建議，術後 IVUS mandatory，並依 lumen area / malapposition / edge dissection criteria 進行追加處置。[文內]
  • C：angiography-guided PCI；除安全理由外不鼓勵 IVUS。[文內]
  • O：主要終點為 patient-oriented composite：any stroke、any MI、any revascularization、all-cause death，取 longest follow-up。[文內]
  • 設計：investigator-initiated, international, multicenter, open-label, randomized superiority trial；1:1 分派；web-based concealed randomization，依 center stratified。[文內]
  • 樣本數：計畫 800 人，80% power，雙側 alpha 0.05；假設 angiography 組 2 年 primary event 26%，IVUS 組 17%，HR 0.65，允許 6% attrition、4% crossover。[文內]
  • 分析：primary ITT；Cox proportional hazards；PH assumption 以 time-dependent covariate 評估；secondary outcomes 未做 multiplicity adjustment，只給 95% CI。[文內]
  • 缺失資料：primary endpoint incomplete follow-up：IVUS 21 人、angiography 24 人；無 formal imputation。[文內]

6. 作者討論與評論重點

作者主要訊息是：在專家、高量歐洲中心，routine IVUS guidance 沒有降低 patient-oriented composite、device-oriented composite、vessel-oriented composite 或其主要 components。[文內 Discussion]

作者合理指出幾個可能原因：operator 已高度熟悉 IVUS，angiography 組也採用由 IVUS 經驗衍生的嚴格 angiographic algorithm；left main vessel 大、近端、stent delivery 相對容易；現代 DES 與技術降低 stent thrombosis 與 revascularization 差異。[文內 Discussion]

限制方面，作者列出 open-label、COVID-19 影響收案與 follow-up、trial powered for 35% relative risk reduction、subgroup hypothesis-generating、歐洲中心外推限制。[文內]
評估：作者的限制大致完整，但「primary composite 過寬」與「control arm 其實是 expert angiography-guided PCI，不是一般 angiography practice」應再更明確。本文不能解讀成「IVUS 沒用」，較精準是「在高 IVUS 經驗 operator 與高標準 angiographic optimization 下，routine IVUS 未證明可帶來額外臨床 benefit」。

7. 外部專業意見

同期 NEJM editorial：Frederick Welt, “Seeing the Left Main Coronary Artery Clearly — Is IVUS Always Necessary?” DOI 10.1056/NEJMe2602959。[外部: editorial/comment 全文]

該 editorial 的核心解讀是：OPTIMAL 確實挑戰「left main PCI 一律需要 IVUS」的強主張，但不代表 IVUS 在所有情境無價值。Welt 強調 IVUS 本身不是治療，只有當影像資訊導致 procedural modification 才可能改善 outcome；在 OPTIMAL，根據 IVUS findings 做改善 apposition / expansion 的 maneuvers 只有 29.3%，可能反映 operator 已很有經驗，也暗示 IVUS 的邊際效益被專家操作稀釋。[外部: editorial/comment 全文]

Editorial 也提出三個關鍵質疑：第一，IVUS 可能對較不熟練 operator 更有價值；第二，left main 是大血管、近端血管，影像 guidance 的收益可能小於小血管或更難判讀病灶；第三，stroke 在 IVUS 組較高雖可能是 chance finding，但額外操作時間與導管操作不能完全排除，需未來試驗處理。[外部: editorial/comment 全文]

Editorial 的臨床結論偏務實：實務模式可能不會劇烈改變，因為 high-risk left main PCI 通常由有經驗 operator 執行，並會選擇性使用 adjunctive tools；但 OPTIMAL 提醒，PCI 後這群病人年事件率仍約 10%，長期追蹤與二級預防同樣重要。[外部: editorial/comment 全文]

8. 臨床建議

可採用本文結論的情境：高量中心、operator 對 left main PCI 與 IVUS 都很熟、angiography-guided PCI 已有嚴格 optimization workflow、使用 contemporary DES、病人類似歐洲 trial population 且不屬 cardiogenic shock / 近期 STEMI 48 小時內族群。

不建議直接套用的情境：低量中心、operator 不常做 left main PCI、angiographic sizing / bifurcation optimization 經驗不足、病灶極度鈣化或影像判讀困難、非歐洲醫療系統、低 SYNTAX 或急性 high-risk subgroup，因外推性不明。

給臨床醫師的實務建議：

  1. 不應把 OPTIMAL 解讀成「left main PCI 不需要 IVUS」；應解讀成「expert angiography-guided PCI 可達到與 routine IVUS 相近的臨床結果」。
  2. IVUS 的使用應更偏向選擇性：病灶 sizing 不確定、鈣化重、bifurcation strategy 複雜、stent expansion/apposition 有疑慮時仍有合理價值。
  3. 若中心 angiography-guided optimization 品質不穩，OPTIMAL 不足以支持省略 IVUS。

證據強度：中等偏高。理由是 RCT、樣本數合理、ITT、crossover 低、事件 adjudication 獨立；但 open-label、專家中心、歐洲限定、composite endpoint 過寬與 CI 仍允許中等 harm，使臨床結論需限縮。

A. 補充技術細節

  • Power calculation：假設 HR 0.65，即 IVUS 可讓 2 年 primary event 從 26% 降到 17%。實際 primary event 反而 33.7% vs 30.9%，HR 1.11。[文內 Statistical Analysis / Table 3]
  • 隨機化：web-based concealed randomization，center-stratified，分派隱藏描述充分。[文內]
  • 致盲：open-label；endpoint 由 independent clinical events committee adjudicated，降低 outcome adjudication bias，但 procedure-related decision / follow-up 行為仍可能受知情影響。[文內]
  • DSMB：未設 independent data and safety monitoring board；steering committee 監測 cumulative endpoint events。對高風險 left main PCI RCT 而言，這是治理上較弱的一點。[文內]
  • ITT vs PP：primary ITT；modified ITT、per-protocol、as-treated sensitivity 一致。[文內]
  • 多重比較：secondary outcomes 不調整 multiplicity，作者明確警告 CI 不應用於推論 treatment effect。[文內]
  • PH assumption：文內稱 met。[文內]
  • 缺失：primary incomplete follow-up 約 5.2% vs 5.9%，接近原先 attrition allowance；但未 impute。[文內]

B. 批判性評估

B1. 假說與理論邏輯

假說合理：IVUS 可改善 sizing、stent expansion、apposition、edge dissection detection，理論上應降低 stent thrombosis、MI、target-lesion revascularization。[文內 Introduction / Procedures]

但主要終點設計與機轉不完全貼合。IVUS 最可能影響的是 device-oriented 或 vessel-oriented events，而 primary endpoint 包含 all-cause death、any stroke、any MI、any revascularization，許多 component 不一定可由 left main stent optimization 改變。這會稀釋真正的機轉效果。

最可疑的敘事跳躍：作者說結果可能挑戰 guideline 對 complex / left main PCI 的 class I imaging guidance requirement；這可以討論，但本文是在 expert centers 測試 routine IVUS 的 incremental value，不足以全面挑戰低經驗中心或複雜病灶中 selective IVUS 的價值。

B2. 受試者與外推性

族群平均 71.4 歲、78.4% 男性、34.7% 糖尿病、SYNTAX 29.7±12.6，屬 intermediate-to-high anatomical complexity，且歐洲高量中心。[文內 Results]

外推性分級：中等。
可外推到高量歐洲型中心與熟練 left main PCI operator；不宜外推到低量中心、訓練早期 operator、非歐洲醫療體系、STEMI 48 小時內、cardiogenic shock 或壽命 <2 年病人，因為被排除或未充分代表。

基線不平衡：previous heart failure 25.8% vs 19.8%，IVUS 組較高。這可能讓 IVUS 組事件風險偏高；但 LVEF 類似，且 sensitivity analyses 未顯示方向翻轉。[文內 Table 1]

B3. 研究設計與偏差

內部效度整體不錯：隨機化與分派隱藏清楚、crossover 低、endpoint adjudication 獨立、ITT 與 sensitivity analyses 一致。

主要設計弱點有三個：

  1. Open-label：operator 知道分組，可能影響 procedural intensity、post-dilation、追加處置與 follow-up decision。雖然硬終點較不受影響，revascularization 仍可能受臨床判斷影響。
  2. Control arm 太強：angiography-guided PCI 不是一般真實世界 angiography，而是由高 IVUS 經驗 operator 執行，且 procedure standards 嚴格；這會降低 IVUS 可偵測的 incremental benefit。
  3. Primary endpoint 過寬：把 stroke、all-cause death、any revascularization 都放入，使 IVUS 機轉相關 outcome 被非機轉事件稀釋。

對照組適當性：angiography-guided PCI 是合理對照，但其「高品質 expert angiography」屬高標準對照，不代表所有中心的日常 practice。

B4. 測量工具與實務意義

IVUS 組的 intervention fidelity 高：97.5% 任一時間成功 IVUS；angiography 組 imaging crossover 3.0%。因此不是因為分組污染而導致陰性。[文內 Table 2]

然而，兩組 post-dilation 97.0% vs 96.0%、proximal optimization 89.6% vs 85.1%，顯示 angiography 組也做了高比例 optimization。若兩組實際 procedural optimization 已非常接近，IVUS 的邊際效益自然難以顯現。

臨床上，IVUS 增加 procedure duration 24.7 分鐘，卻未降低 revascularization、MI、death 或 composite。若在同等專家品質下，routine IVUS 的成本與時間代價需要重新被證明，而不是由 observational benefit 自動推論。

C. 統計與資料完整性

C1. CI + MCID 結果分類

文內未指定 MCID。以本文原始設計假設 HR 0.65 作為作者期待的 clinically important effect，OPTIMAL 明確排除了這種大幅 benefit：observed HR 1.11，95% CI 0.87–1.42。

若以較保守的臨床 MCID，例如 HR ≤0.85 或 absolute risk reduction 約 3–5% 作為 IVUS routine use 值得付出時間與成本的門檻，本文仍幾乎排除明顯 benefit，但不能排除非常小的 benefit；同時 CI 上限 1.42 仍允許中等 harm。

分類：不是 POSITIVE；也不是嚴格 NEUTRAL。較精準是「對原先假設的大幅 superiority 為 negative；對小幅 benefit / harm 仍屬 imprecise」。禁止寫成「兩組完全沒有差異」。

C2. Underpowered 與 Winner’s Curse

這不是典型 underpowered positive；相反，是 event rate 高於預期但效果方向未支持 IVUS。原設計預期 control event 26%，observed control 30.9%；事件數足以排除 HR 0.65 這種大效果。

但若臨床問題是「IVUS 是否降低 10–15% relative risk 或少數百分點絕對風險」，本研究可能仍不足以做等效或非劣性結論。本文是 superiority trial，不應轉述為 angiography “noninferior” to IVUS。

C3. Bayesian 補充解讀

未做正式 Bayesian analysis。就頻率派 CI 而言，資料最支持「沒有 clinically large benefit」；若 skeptical prior 對 IVUS routine use，posterior 應會偏向不採用 routine IVUS；若 optimistic prior 來自過去 meta-analysis，OPTIMAL 會明顯拉低對 left main expert-center routine IVUS 的信念。正式 Pr(benefit) / Pr(ROPE) / Pr(harm) 無法由文內資料直接計算。

C4. 報告完整性與統計紅旗

  1. Primary composite 機轉混雜，部分 component 不容易被 IVUS 改變。
  2. Secondary outcomes 未 multiplicity adjustment；stroke HR 3.11 應視為安全訊號而非確證傷害。
  3. 沒有 formal imputation；雖然 missing rare，但 primary events 約 30%，5–6% incomplete follow-up 不完全可忽略。
  4. Open-label 使 revascularization 類 endpoint 可能受 decision bias 影響。
  5. Trial powered for large effect；對小至中度 benefit 或 harm 的排除能力有限。
  6. 無 independent DSMB，對高風險 trial 的安全監測架構較弱。
  7. Operator expertise 高，使 treatment effect 可能被 effect modification 稀釋，但 subgroup / interaction 未能充分回答。

D. 次組分析評估

文內提到 prespecified subgroup 包含 clinical presentation、sex、diabetes、SYNTAX score；Figure S6 在 supplement，markdown 未保留具體數字與 interaction p values。[限制：PDF converted markdown 未保留 Figure S6 細節]

依 JAMA subgroup credibility criteria，可信度目前只能評為低至推測性：subgroup 是否有 interaction p-value、是否預先指定方向、是否有強生物學理由、是否跨研究一致，markdown 均不足以判定。[參考: jug130002.md “How to Use a Subgroup Analysis”]

實務上不應根據本篇 subgroup 改變特定族群是否使用 IVUS；最多作為後續 hypothesis generation。

E. 紅旗清單

  • Superiority trial 被讀者誤解成 equivalence / noninferiority 的風險高。
  • Primary endpoint 過寬，與 IVUS 機轉不完全對齊。
  • Control arm 是 expert angiography-guided PCI，外推到一般中心有限。
  • Open-label，尤其 revascularization decision 可能受知情影響。
  • Stroke HR 3.11 雖可能偶然，但不能用「非預期」直接消除。
  • 沒有 independent DSMB。
  • 產業資助與裝置研究相關，雖然結果不利於 routine IVUS，仍需保留 COI 意識。
  • 結論若推到「guidelines 不需 IVUS」會超出資料；本文只支持特定環境下 routine IVUS 未證明有額外 benefit。

F. 反向解釋

  1. 真正解釋不是 IVUS 無效，而是 angiography 組太強：高經驗 operator 已能用 angiography 達到接近 IVUS 的 stent optimization。支持線索：兩組 post-dilation 與 proximal optimization 率都很高。
  2. IVUS 的 benefit 只存在於低經驗 operator、小血管、非 left main 或特定 complex lesion；OPTIMAL 的 left main 大血管與專家中心設計降低可見效益。支持線索：editorial 也提出此點。
  3. IVUS 可能帶來小幅 harm 或 procedural burden：procedure duration 增加 24.7 分鐘，stroke 事件較多。反對線索：stroke median 19 個月，非明顯 periprocedural，事件數少且未校正多重比較。
  4. Primary endpoint 稀釋了 device-specific benefit：若 IVUS 只降低 stent-related revascularization 或 thrombosis，all-cause death / stroke / non-target events 會稀釋效果。反對線索：device-oriented 與 vessel-oriented composite 也未顯示 benefit。

G. 最終裁決

整體可信度：中等偏高。

可採用的條件：高量中心、熟練 left main PCI operator、嚴格 angiographic optimization、現代 DES、病人類似本研究歐洲族群時，可以不把 routine IVUS 視為絕對必要。

不建議採用的情境：低量中心、operator 經驗不足、影像判讀或 stent sizing 不確定、嚴重鈣化或 bifurcation anatomy 複雜、angiography-only 品質無法保證時，不應用 OPTIMAL 取消 IVUS。

最需要的 3 個改進：

  1. 設計 pragmatic trial，比較一般中心 angiography-guided PCI vs IVUS-guided PCI，以測試 operator expertise effect modification。
  2. 使用更貼近機轉的 primary endpoint，例如 target-lesion failure、target-vessel MI、clinically indicated TLR，並保留 patient-oriented outcomes 為關鍵 secondary。
  3. 預先規劃安全監測與 stroke mechanism analysis，包含 procedural manipulation、aortic arch disease、antithrombotic adherence 與 post-procedure care。

一句話結論：OPTIMAL 支持「專家中心可選擇性用 IVUS」，不支持「left main PCI 一律不用 IVUS」。
