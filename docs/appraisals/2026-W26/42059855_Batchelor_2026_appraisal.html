3. 研究背景

既有事實與證據 [文內]：

  • 重度 AS 影響 > 3% 的 75 歲以上成人；中重度至重度 MR 影響 2–3% 的 ≥ 65 歲成人
  • 未治療重度症狀性 AS 的 2 年死亡率接近 50%
  • 現有指引建議 90 天內完成 MHT 評估與瓣膜介入（2024 ACC/AHA Clinical Performance Measures）
  • 不到一半符合 Class I/IIa 建議的重度 AS 患者接受瓣膜介入
  • 治療率受醫師個人差異、性別、種族、社經地位、城鄉差距顯著影響

知識缺口 [文內]：

  • DETECT-AS 試驗已證明 ECN 在單一醫療系統中提升重度症狀性 AS 的 AVR 率，但該試驗僅在單一系統、種族多樣性低（96% White）、僅限 AS
  • 尚無多系統、同時涵蓋 AS 與 MR、且族群多樣性較高的 ECN 隨機試驗

Research question [文內]：在多個美國醫療系統中，自動化 EHR 整合的 ECN 警報能否改善重度 AS 與 MR 的指引導向評估與瓣膜介入？

4. 研究設計與方法

PICO：

  • P：5 個美國醫療系統、35 家醫院，由非 MHT 成員醫師所開立心臟超音波且檢出重大 AS 或 MR 的成人患者（≥ 18 歲）
  • I：自動化 ECN 警報——由 Tempus Next 平台透過 NLP 偵測心超報告中的重大 AS/MR，將含指引建議的通知送至醫師 EHR 收件匣
  • C：無 alert 的標準照護（usual care）
  • O：
    • 主要終點：hierarchical composite，以 stratified win ratio 分析——優先比較瓣膜介入（surgical 或 transcatheter）的時間，再比較 90 天內 MHT 門診評估的時間
    • 次要終點：各組成成分單獨分析

關鍵研究設計細節：

  • 設計：叢集隨機（cluster-randomized），隨機化單位 = 醫師，1:1，依機構與歷史心超開單量分層
  • 收案期間：2024 年 8 月至 2025 年 9 月
  • 追蹤時長：90 天
  • 隨機化方式：由 Tempus 軟體工程師在研究啟動前程式化並驗證，全程自動化於 Tempus Next 平台
  • 致盲：醫師對分組保持盲性；所有現場人員（含 PI、資料分析師、生統師）不可取得分配資訊；分配僅限 Tempus 指定人員存取
  • 知情同意：IRB 核准豁免患者與醫師的知情同意
  • 統計方法：win ratio（BuyseTest R package），依 AS/MR 分層；Cox proportional hazards regression（次要終點）；KM 估計；cumulative incidence function（死亡為競爭風險）；prespecified multistate model
  • 預計樣本數：1,246 名患者，80% power，單側 alpha = 2.5%，假設各階層終點 5% 絕對改善
  • 主要分析族群：modified intention-to-treat（mITT）
  • 統計顯著性閾值：單側 P < 0.025

6. 作者討論與評論重點

作者的主要訊息 [文內]：

  • ECN alerts 成功將已有的診斷資訊轉化為臨床行動
  • 效果在 ITT / mITT / PP 三個族群一致且穩健
  • 效果不因年齡、性別、種族、社經地位、照護場域或醫師專科而異

與現有文獻的異同 [文內]：

  • 與 DETECT-AS 結果方向一致，但 ALERT 跨越更多醫療系統、更高種族多樣性、同時涵蓋 AS 與 MR
  • 即便有 alerts，高梯度 AS 僅 45% 轉介 MHT、嚴重 MR 僅 30% 轉介——差距仍然巨大

限制（作者觀點） [文內]：

  1. 叢集隨機後仍可能有殘餘混淆
  2. 各機構 alert 措辭、臨床人員意識、轉介支援基礎設施不同
  3. Alert fatigue 可能削弱效果
  4. 技術部署失敗保留於 mITT 分析中
  5. 轉介未透過自動轉介機制，仍依賴醫師決策
  6. 可能遺漏在參與系統外接受治療的患者
  7. 90 天追蹤無法評估長期結果
  8. 死亡資料透過 HL7 介面取得，可能不完整

[評估]：作者的限制陳述相對完整但有數個明顯迴避：(1) 未討論兩組間死亡率的顯著差異（4.1% vs 2.1%）；(2) 未討論基線不平衡（住院比例 42% vs 33%、性別差異）對結果的潛在影響；(3) 未討論 MR 次群未達顯著的臨床意涵——卻在結論中將 AS 與 MR 並列宣稱有效；(4) 未對「endpoints 全為過程指標而非臨床結果」這個根本限制做充分討論。

8. 臨床建議

可採用的情境：

  • 擁有整合型 EHR 且願意投入技術整合的大型醫療系統，可考慮導入 NLP-based echo 報告自動通知，作為減少 AS 低治療率的系統層級策略
  • 特別適合 high-gradient AS 患者（win ratio 1.67）且以門診 echo 為主的場景（WR 1.41）

不建議直接套用的情境：

  • MR 患者：本試驗中 MR 次群 win ratio 未達顯著（P = 0.094），且 alert 未增加 valve intervention 率——MR 的臨床決策路徑本質上更複雜，90 天可能不足以看到效果
  • Low-gradient AS：post hoc 分析 WR 僅 1.15（P = 0.196），提示效果可能集中在 high-gradient AS
  • 單一醫院或小型系統：本研究的技術部署需大量 IT 資源與 Tempus Next 平台合約，不具直接可移植性
  • 期待改善臨床硬終點（死亡、心衰住院、生活品質）的場景：本研究未提供任何臨床結果改善的證據

給臨床醫師的實務建議：

  1. 此研究支持的是「過程改善」而非「臨床結果改善」——alert 增加了轉介與介入率，但未證明這些轉介實際改善了患者預後。在決定是否在自家醫療系統導入類似工具時，應將此定位為品質改善工具，而非療效介入。
  2. 即使有 alert，仍有 76% 的重大 VHD 患者在 90 天內未獲 MHT 評估、87% 未接受介入——alert 只是系統層級改善的第一步，不能取代結構性的轉介流程改造。
  3. 注意 alert 的潛在反效果：本研究中 alert 組 90 天死亡率為 4.1% vs 對照組 2.1%，雖可能與基線差異有關，但臨床醫師應意識到 alert-triggered 的加速評估不一定等同於臨床獲益。

研究證據強度：中（多中心 RCT、主要終點達顯著、效果方向一致，但為叢集隨機非個體隨機、基線不平衡、主要終點為過程指標而非臨床結果、死亡率不平衡未解釋、MR 次群未達顯著、且由被測平台開發商與器材廠商共同資助）

SKILL-A：原始研究批判性評讀

A. 補充技術細節

樣本數估算：預計需 1,246 名患者，80% power，單側 alpha = 2.5%，假設各層 5% 絕對改善。實際收入 1,905 名患者（mITT），超過計畫樣本數約 53%。實際觀察到的 composite 絕對差異約 4.4%（24.3% vs 19.9%），略低於假設的 5%；但因超額收案仍達顯著。

隨機化細節：醫師層級 1:1 隨機，依機構與歷史心超開單量（3 層：≤1、2–10、> 10 次/2 個月）分層。由 Tempus 軟體工程師程式化並驗證 [文內]。分配隱藏由 Tempus 平台自動執行，不可變更的稽核日誌追蹤 [文內]。問題：randomization sequence generation 與 allocation concealment 均由贊助商 Tempus 直接執行，無獨立第三方驗證。

致盲：醫師對分組盲性、所有現場人員（含 PI）無法存取分配資訊 [文內]。但盲性本質上不完美——Alert 組醫師「看到了 alert」，這是不可遮蔽的介入。Control 組醫師「沒看到 alert」但可能透過同事間交流得知 alert 的存在。文內未報告致盲成功度的驗證。

mITT vs ITT vs PP：

  • ITT：783 clinicians / 2,118 echos
  • mITT（主要分析）：765 clinicians / 2,016 echos（排除 102 echos 因技術限制無法送出 alert）
  • PP：710 clinicians / 1,653 echos（進一步排除 164 echos alert 未送達 + 165 echos 對照組汙染 + 34 echos 不符收案標準）

以 mITT 而非 ITT 作為主要分析族群，雖作者稱此為「保守」，但實際上排除了技術失敗的病例，偏離了 ITT 的核心精神——ITT 的目的正是要評估介入在真實世界（含技術失敗）的效果。

汙染率：165/879 = 18.8% 的對照組 echos 錯誤收到 alert——這是非常高的汙染率，會系統性地將效果量推向虛無值。PP 分析（排除汙染後）win ratio 升至 1.50（vs mITT 的 1.27），部分支持汙染確實稀釋了效果的解讀。

多重比較處理：主要終點為單一 hierarchical composite，以 win ratio 分析。次要終點與次群分析未進行多重比較校正。文內報告了大量次群分析、post hoc 分析（high vs low gradient AS、MR by LVEF），均無校正。

Echo 數目不平衡：儘管醫師 1:1 隨機（394 vs 389），Alert 組 echos 數顯著多於 No-Alert 組（ITT: 1,239 vs 879）。這是叢集隨機的固有問題——高開單量醫師被隨機到 Alert 組的比例較高。此不平衡可能引入系統性差異（高開單量醫師的患者特徵與轉介模式可能不同）。

缺失資料：NYHA functional class 在兩組均有 85% unknown [文內 Table 1]——這是極嚴重的資料缺失。NYHA class 是判斷 AS/MR 是否有症狀的核心指標，而症狀是 guideline 建議 intervention 的關鍵 qualifying criterion。85% 的 NYHA 不明意味著我們無法確認多少患者實際符合 Class I indication for intervention。

B. 批判性評估（四大面向）

B1. 假說與理論邏輯

  • 假說預先指定？ 是。試驗為 superiority design，hypothesizing ECN > usual care for the composite of valve intervention + MHT visit [文內, protocol registered NCT06099665]。
  • 機轉邏輯：alert 提醒醫師注意到心超報告中的重大 VHD → 醫師因此更可能轉介 MHT 或安排 intervention。這是合理的行為經濟學/nudge 理論應用——資訊不對稱或注意力不足是低治療率的已知因素之一。
  • 機轉的限制：
    1. 假設醫師「沒注意到」echo 報告中的重大發現是低治療率的主要原因。但低治療率的成因是多因素的——包括患者偏好、共病、年齡歧視、結構性不平等等——alert 僅能解決「注意力/認知」這一個維度。
    2. 假設更多的 MHT 評估與 valve intervention = 更好的臨床結果。這在群體層級大致成立（來自觀察性研究的證據），但對個別患者而言，額外被推向 intervention 的患者是否真正受益，需要臨床結果數據支持。

B2. 受試者與外推性

  • 受試者與宣稱對象的一致性：

    • 年齡約 76 歲，符合 VHD 高盛行率族群
    • 種族：White 80–82%、Black 15–16%、Other 3.5–4%——相較 DETECT-AS（96% White）有改善但仍以白人為主
    • 5 個醫療系統、35 家醫院——覆蓋面較 DETECT-AS（單一系統）大幅提升
    • 62% AS、38% MR——AS 為主

  • 基線不平衡 [文內 Table 1]：

    • Alert 組女性比例較高（54% vs 49%, P = 0.048）
    • Alert 組住院比例較高（42% vs 33%, P < 0.001）
    • 非西班牙裔比例差異（70% vs 64%, P = 0.002）
    • 醫療系統分布差異（P < 0.001）
    • → 這些差異在叢集隨機試驗中不罕見，但住院比例差異 9% 是重大的混淆來源——住院患者更可能及時接受 MHT 評估或 intervention（因為已在醫院中）

  • 外推性分級：

    1. 適用於：擁有 EHR 整合能力的美國大型醫療系統，主要服務 > 65 歲心臟病患者的機構
    2. 謹慎外推：非美國醫療體系（EHR 整合度、轉介流程、保險覆蓋不同）；以 MR 為主的照護情境（本研究 MR 次群未達顯著）
    3. 不建議外推：社區診所、單一醫師的小型實務（缺乏 IT 基礎設施）；低收入國家

B3. 研究設計與偏差

叢集隨機的固有限制：

  • 問題 → 文內證據 → 風險方向：
    1. 隨機化單位（醫師）≠ 分析單位（echo/patient）：叢集內相關性（ICC）可能導致有效樣本數被高估。Win ratio 方法本身不直接處理 ICC。→ 風險方向：可能低估 P 值（誇大統計顯著性）
    2. 叢集大小嚴重不平衡：Alert 1,137 echos vs No-Alert 879 echos，差距達 29%。高開單量醫師的叢集較大 → 若這些醫師碰巧被分到 Alert 組較多，其患者特徵（可能較常規性、較不急性）可能系統性地影響結果。
    3. 基線不平衡（見 B2）：住院比例差 9%、性別差 5%，這些在個體隨機 RCT 中幾乎不會發生的差異，在叢集隨機中頗為常見。→ 風險方向：住院比例較高的 Alert 組患者可能本身就更容易接受評估與 intervention（因已在院），這會讓 alert 的效果被人為膨脹。

死亡率不平衡（核心紅旗）：

  • Alert 組 90 天死亡率 4.1%（43/1,054）vs No-Alert 組 2.1%（18/851）——近乎 2 倍差距 [文內 Results]
  • 死亡被 right censored——意味著較多 Alert 組患者因死亡被移出 at-risk pool，這在過程終點分析中會造成 informative censoring（死亡非隨機事件，死亡患者是最無法接受 intervention 的群體）
  • 作者在 cumulative incidence function 中將死亡作為 competing risk 處理（結果仍顯著），但從未直接討論或解釋此死亡率差異
  • 可能解釋：(1) Alert 組住院比例較高（42% vs 33%），住院患者更為急性，90 天死亡率較高；(2) 隨機偶然；(3) NLP 偵測到更多急性患者而將其歸入 Alert 組的較大叢集中
  • 無論原因為何，2 倍死亡差異在一個宣稱改善照護品質的試驗中應被更嚴肅地討論

對照組適當性：

  • 對照組為 "usual care"——醫師正常處理 echo 報告但不收到額外 alert。這是合理的比較組。
  • 但 usual care 的定義不精確——不同醫療系統、不同專科醫師的 usual care 差異巨大（見 forest plot 中 Site 間的異質性）

汙染：18.8% 的對照組 echos 收到了 alert——這是嚴重的汙染，但方向是保守的（dilutes effect toward null）。

最可能造成偏差的設計點：

  1. 住院比例不平衡（Alert 42% vs No-Alert 33%）→ 讓 Alert 組效果看起來更好（住院患者更容易被評估和介入）
  2. 死亡率不平衡 + informative censoring → 方向不確定：移除較多 Alert 組的死亡患者可能讓存活者的 event rate 看起來較高，但也可能是相反
  3. Randomization 與 allocation 由贊助商 Tempus 執行 → 雖有稽核日誌，但無獨立第三方驗證

B4. 測量工具與實務意義

  • NLP 偵測準確度：Tempus Next 對重度 AS 的偵測準確度 98.6%（已發表驗證，Ref 28）[文內]。但 MR 的偵測準確度未單獨報告——MR 使用定性分類（qualitative classification），而定性 MR 分級本身即有顯著的觀察者間變異 [文內承認此限制]
  • 終點為過程指標而非臨床結果：
    • MHT evaluation 與 valve intervention 在 90 天內是 surrogate / process endpoints——它們是指引推薦的照護流程指標，但不是硬終點（死亡、心衰住院、生活品質改善）
    • 核心假設是：更快的 MHT evaluation + valve intervention = 更好的臨床結果。此假設來自觀察性研究，在此試驗中未被驗證
    • 「就算結果是真的」：Alert 增加了 4% 的 MHT 評估率（18% → 23%）和 4% 的 intervention 率（10% → 13%）。NNT ≈ 25（每發送 25 個 alert，1 位額外患者接受 intervention）。RMST 差異 2.5 天（90 天內提早 2.5 天）。這些在系統層級是有意義的（每年數百位額外患者接受評估），但在個體層級影響有限
    • 即使有 alert，仍有 76% 的 flagged 患者 90 天內未獲 MHT 評估，87% 未接受 intervention——alert 不能解決 VHD 低治療率的根本問題

C. 統計與資料完整性

C1. 結果分類（CI + MCID 框架）

本試驗主要終點為 win ratio，以下用 win ratio 的 CI 進行分類。

對 win ratio 而言，null value = 1.0。MCID 的概念較難直接套用（win ratio 沒有公認的 MCID 門檻），但可參考 net benefit 的 CI：4.21%（95% CI: 0.63–7.77%）。

Step 1 — MCID 確認：

  • 文內未預先指定 MCID for win ratio
  • 文內 power calculation 假設各組成成分有 5% 絕對改善——可以此作為作者隱含的「最小有意義差異」
  • 實際觀察的 net benefit 4.21% 接近但略低於 5%
  • [推算] 對於過程指標，在系統層級，3–5% 的絕對改善通常被視為有意義

Step 2 — CI 位置判讀：

解讀：

  • 整體結果為統計顯著但效果量的精確度有限——CI 下界 1.05 僅略超過 null（win ratio 1.0），上界 1.54 則提示可能有 moderate benefit。Net benefit 的 CI 下界 0.63% 在臨床上是非常小的差異。
  • AS 次群：CI 下界 1.01——勉強排除 null，效果量的不確定性高
  • MR 次群：CI 跨越 null（0.90–1.69），無法得出 alert 對 MR 有效的結論

C2. Underpowered 判斷與 Winner's Curse

  • 整體分析非 underpowered（實際 n = 1,905 > 計畫 n = 1,246，且主要終點達顯著）
  • MR 次群 underpowered：CI 0.90–1.69 同時包含 null 與有意義效果——樣本不足以對 MR 單獨回答問題
  • Winner's Curse 風險：在此設計中較不適用，因主要終點達顯著且效果方向與 DETECT-AS 一致。但 AS 次群 CI 下界 1.01 值得注意——若有微小偏差調整（如校正基線不平衡），效果量可能消失

C4. 報告完整性與其他統計問題

Win ratio 方法學的特殊考量：

  • Win ratio 是較新的統計方法，將 hierarchical composite 中各組成成分賦予優先順序——先比較 valve intervention 的時間，若打平再比較 MHT visit 的時間
  • 優點：反映了臨床上 intervention > evaluation 的重要性層級
  • 缺點：當大多數配對在第一層「打平」（大多數患者都沒有 intervention），結果主要由第二層（MHT visit）驅動——實際上 valve intervention 層的 wins 差距可能被 MHT visit 層放大

KM 圖判讀（來自 page_010.png 圖像）：

  • Panel A（Composite）：曲線從約 day 10–15 開始分離，分離幅度穩定維持至 90 天。Y 軸 0–30%，刻度適當，無起點誇大。
  • Panel B（MHT visit）：分離模式相似，24.3% vs 19.9%。
  • Panel C（Valve intervention）：分離較明確，13.4% vs 9.6%。曲線在前 30 天即見分離，之後幅度漸增。
  • Numbers at risk 後期銳減問題：Panel A 在 90 天 Alert 組剩 810/1137 = 71%、No-Alert 剩 679/879 = 77%——後期仍有良好的 at-risk 數量，末段曲線可靠。Panel C 在 90 天 Alert 921/1137 = 81%、No-Alert 764/879 = 87%——同樣穩定。無後期急劇銳減問題。

Forest plot 判讀（來自 page_009.png 圖像）：

  • 所有 interaction P > 0.10——形式上無異質性
  • 但點估計分散相當大：Age < 65 WR 0.93、Site D WR 0.82、Other race WR 0.70 均在 null 左側（favors No Alert）
  • Site 間異質性值得關注：Site C WR 1.76（顯著）vs Site D WR 0.82 vs Site E WR 1.03——但各 site 樣本量差距極大（Site C n=398 vs Site D n=167 vs Site E n=96），P_int = 0.231 部分受限於統計力不足
  • Black 次群 CI 極寬（0.63–2.90, n=306）——無法判定 alert 對 Black 患者的效果，這與作者在摘要中宣稱「consistent across race」的敘事形成張力

統計面紅旗清單：

  1. 85% NYHA class unknown——無法確認多少患者為症狀性 AS/MR，而症狀是 guideline-directed intervention 的核心適應症
  2. 基線住院比例不平衡 42% vs 33%（P < 0.001）——住院患者更容易在 90 天內被評估與介入，此差異直接偏向 Alert 組
  3. 死亡率不平衡 4.1% vs 2.1% + informative censoring——死亡被 right censored 而非作為 endpoint 或 competing risk（cumulative incidence 僅為輔助分析），可能造成估計偏差
  4. 18.8% 汙染率——雖方向保守，但極高的汙染率意味著試驗在現實中的「separation of interventions」不足，削弱了因果推論力度
  5. Randomization 與 allocation 由贊助商 Tempus 全權執行——無獨立第三方 DSMB 或分配驗證的描述
  6. MR 次群未達顯著但結論中 AS 與 MR 並列宣稱有效——選擇性敘事
  7. 大量 post hoc 次群分析未校正多重比較（high vs low gradient AS、MR by severity、MR by LVEF）

E. 紅旗清單

  1. 過程終點而非臨床結果：增加 MHT 評估與 valve intervention 率 ≠ 證明改善臨床預後——此試驗無法回答最重要的問題
  2. 死亡率反向訊號 4.1% vs 2.1% 未被作者討論——在品質改善試驗中出現 2 倍死亡差異是必須嚴肅面對的發現
  3. 贊助商 Tempus 既開發被測平台、又執行隨機化、又有 3 名員工為共同作者——結構性 COI 達到少見的集中程度
  4. MR 次群未達顯著但結論中混為一談——「improved…for clinically significant AS and MR」的措辭誇大了 MR 的證據
  5. 85% NYHA unknown——無法確認所 flag 的患者有多少真正符合症狀性 intervention 的適應症，可能有一大部分被 alert 推向評估的患者是無症狀或 borderline 的
  6. 叢集隨機導致的基線不平衡（住院比例差 9%）未在主要分析中校正（win ratio 未 adjust covariates）
  7. 資料不可公開取得——"complexity and proprietary nature of the dataset" 是 Tempus 的商業考量，阻礙獨立驗證
  8. 汙染率 18.8%——試驗 integrity 的重大缺陷，雖方向保守

F. 反向解釋

  1. 住院比例差異驅動的偽效應：Alert 組住院比例高 9%，住院患者本身更容易在 90 天內接受評估與介入（因在院期間就可直接轉介），即使沒有 alert，住院比例較高的族群也可能有更高的 MHT/intervention 率。雖然次群分析中 inpatient 的 WR 1.16 低於 outpatient 的 1.41，但住院比例的不平衡仍可能系統性地偏移整體效果量。

    • 文內支持：基線 Table 1 確認住院比例差異 P < 0.001
    • 反對：次群分析 P_int = 0.714 不顯著；Cox 模型有校正住院狀態

  2. Hawthorne 效應 + 注意力偏差：Alert 組的效果可能不是來自 alert 本身的訊息內容，而是來自「收到一個關於此患者的額外通知」所引發的注意力——即使通知內容換成不含建議的簡短提醒，效果可能類似。因為缺乏 active comparator（如：送出不含建議的一般性提醒），無法區分「資訊內容的效果」與「被提醒這件事本身的效果」。

    • 文內支持：無 active comparator 設計
    • 反對：ECN 包含 site-specific guideline-based care recommendations，理論上資訊內容有附加價值

  3. Tempus Next 平台偵測偏差：NLP 的 98.6% 準確度僅驗證於 AS——MR 使用定性分類，其偵測準確度未單獨報告。若 NLP 在 MR 的偵測敏感度較低，可能解釋 MR 次群效果較弱。另外，「measured but not reported」的 echo 數值不會被 NLP 偵測到 [文內]——不同機構的 echo 報告完整度差異可能影響跨機構的效果一致性。

    • 文內支持：作者明確承認 MR 使用 qualitative classification 的限制

  4. 時間效應與外部趨勢：研究進行期間（2024–2025）正值 TAVR 在社區醫院快速普及、ESC 2025 瓣膜指引更新強化 90 天 benchmark。若 alert 組所在的機構碰巧更早或更積極地採用這些外部趨勢，效果可能被誇大。

    • 文內支持：Site 間 WR 差異顯著（Site C 1.76 vs Site D 0.82）提示機構層級因素的強大影響
    • 反對：隨機化理論上應消除時間趨勢的差異性效應

G. 最終裁決

  • 整體可信度：中

  • 可採用的條件：大型醫療系統考慮在 EHR 整合 NLP-based echo alert 作為品質改善工具，特別針對 high-gradient AS 的辨識與轉介。須清楚認知這是過程改善措施，不是療效介入。

  • 不建議採用的情境：以此試驗作為 MR 患者部署 alert 系統的充分依據（MR 次群未達顯著且 valve intervention 無差異）；以此試驗作為 alert 改善臨床預後（死亡、心衰、生活品質）的證據。

  • 若要改觀，最需要的 3 個關鍵改進：

    1. 以臨床硬終點（全因死亡、心血管死亡、心衰住院、生活品質）為主要終點的隨機試驗——過程改善不等於結果改善，特別是在存在死亡率反向訊號的情況下
    2. 對 MR 次群進行獨立的、足夠 power 的試驗，追蹤期延長至 ≥ 1 年（反映 MR 的治療決策時程）
    3. 由獨立學術機構（非 Tempus/Medtronic）執行隨機化、資料管理與統計分析，且資料公開可供獨立驗證

  • 一句話結論：ECN alert 在 AS 可增加約 4% 的短期轉介與介入率，但效果量有限、MR 未達顯著、且無臨床結果改善的證據——這是一個有希望的品質改善工具，但離 practice-changing evidence 仍有距離。
