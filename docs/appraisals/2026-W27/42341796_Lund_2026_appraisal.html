3. 研究背景

[文內]

既有事實與證據：

  • HFrEF 的核心病理是左室收縮力下降；現有 GDMT（RASi、β-blocker、MRA、SGLT2i）調控神經荷爾蒙軸但不直接增強收縮力
  • 傳統正性肌力藥（dobutamine、milrinone）透過增加細胞內 Ca²⁺ 濃度提高收縮力，但伴隨心搏過速、心律不整、缺血、低血壓，甚至增加死亡率（PROMISE 試驗，ref 4）
  • Myosin activators（omecamtiv mecarbil）增加收縮期射出時間，但 GALACTIC-HF 顯示對心衰住院有modest benefit，對死亡率無幫助，且有 troponin 上升與缺血疑慮（ref 6–9）
  • Ghrelin 是由胃分泌的 28 胺基酸胜肽荷爾蒙，作用於 GHSR1a 受體；動物模型顯示抑制心臟交感神經活性、改善心臟功能、減緩 cachexia（ref 14–17）
  • 三項小型 HFrEF 人體研究（ref 18–20）顯示 ghrelin 靜脈注射可改善 cardiac output、LVEF、stroke volume，且無心搏過速、心律不整、缺血或低血壓
  • Lund 2023 年 Eur Heart J 論文（ref 20）同時在小鼠心肌細胞顯示 ghrelin 透過降低 troponin I 磷酸化提升 Ca²⁺ 敏感度，而非動員 Ca²⁺

知識缺口：

  • 此前的 ghrelin 研究均為靜脈注射，無口服製劑數據
  • AC01（前稱 HM01）是首個口服 ghrelin receptor agonist 小分子，在前臨床模型中顯示與 ghrelin 相同的機轉（ref 21），但從未在 HFrEF 病患中進行臨床試驗

Research question：AC01 在 HFrEF 病患中的安全性、耐受性、藥物動力學與探索性效能訊號為何？

4. 研究設計與方法

PICO：

  • P（Population）：18–80 歲、HFrEF 診斷 ≥ 6 個月、NYHA class II–III、LVEF ≤ 40%、已接受最大耐受劑量 GDMT、植入 ICD（一次預防）、竇性節律或心房顫動/撲動（phase 2a 允許至多 25%）、安靜心率 55–90 bpm
  • I（Intervention）：AC01 口服，每日兩次
    • Phase 1b：四個遞增劑量隊列（0.1 mg、0.3 mg、1.0 mg、3.0 mg），各 7 天
    • Phase 2a：1.0 mg 或 3.0 mg（第 1–2 天先給 1.0 mg，第 3 天起 3.0 mg），共 28 天
  • C（Comparison）：安慰劑（外觀相同的 minitablets）
  • O（Outcome）：
    • 主要終點：安全性與耐受性（AE 類型與頻率、生命徵象、ECG、troponin I、NT-proBNP、eGFR、實驗室異常）
    • 次要終點：藥物動力學（AC01 與活性代謝物 M6）、藥效學生物標記（growth hormone 等）
    • 探索性終點：血流動力學（cardiac output、stroke volume，以 inert gas rebreathing 非侵入性測量）、超音波心動圖（LVEF、chamber volumes，僅 phase 2a）

關鍵設計細節：

  • 設計類型：Phase 1b/2a，兩階段設計——先 MAD（multiple ascending dose）再平行組擴展
  • 隨機化：permuted blocks（phase 1b block size 4、phase 2a block size 3）；中央 IWRS 分配；分配隱藏透過系統存取限制與編號藥品容器
  • 致盲：病患、研究人員、結果評估者、數據分析者、sponsor 均被遮蔽；AC01 與安慰劑 minitablets 外觀相同
  • Phase 1b 隨機比 3:1（每隊列 6 AC01 + 2 placebo）；Phase 2a 隨機比 1:1:1
  • 14 個研究中心（荷蘭 5、英國 4、瑞典 3、義大利 2）
  • 收案期間：2023/2/23–2025/8/28（約 30 個月）
  • 統計方法：純描述性統計，無正式統計假說檢驗；SAS 9.4；PK 用 Phoenix WinNonlin 非房室法分析；無缺失資料填補
  • 樣本數估算：未進行正式 sample size calculation——作者聲明這是探索性試驗

重大方案修訂（2 次）：

  1. Phase 1b 期間（2023/6/6）：放寬心率、LVEF、cardiac index、BMI 的納入標準 → 表示原始標準招募困難
  2. Phase 2a 啟動前（2024/10/18）：將四組平行設計改為三組；定義劑量隊列；高劑量組改為漸進遞增；允許至多 25% AF 病患與 digoxin 使用；移除 cardiac index 納入標準與空腹限制 → 多項放寬

最常見 TEAE（> 2 patients in any phase）：低血壓、非持續性心室頻脈（NSVT）、呼吸困難、高血糖、頭暈/眩暈、頭痛——但分布上 AC01 與 placebo 組間差異不明顯。

ECG 與心律安全訊號：

  • 首劑暫時性心搏過緩：Phase 1b 3.0 mg 組首劑後 1 小時最大平均心率下降 −17.5 bpm (SD 5.3) vs placebo −7.3 bpm (7.1)
  • 首劑暫時性 QTcF 延長：Phase 1b 3.0 mg 組首劑後 6 小時最大平均 QTcF 變化 +17.0 ms (SD 13.4) vs placebo −4.4 ms (10.7)；Phase 2a 因漸進劑量遞增與進食給藥而減輕（pooled AC01 +8.6 ms [13.0] vs placebo −2.6 ms [21.0]）
  • 無病患 QTcF ≥ 500 ms 或 ΔQTcF ≥ 60 ms
  • 無心室或心房性快速心律不整、缺血徵象或傳導異常的跡象

代謝安全訊號：

  • 空腹血糖上升：Phase 2a 3.0 mg 組 +3.25 mmol/L (SD 3.03) vs 1.0 mg +1.14 mmol/L (1.46) vs placebo +0.02 mmol/L (0.80)——劑量依賴性，臨床顯著升高者均有 type 2 DM 病史
  • 體重增加：Phase 2a 3.0 mg +1.1 kg (SD 2.7)、1.0 mg +1.5 kg (0.9) vs placebo −0.1 kg (1.2)——至 day 42 回到基線
  • CNAQ 食慾問卷未顯示明確食慾增加

6. 作者討論與評論重點

作者的主要訊息：

  • AC01 在 HFrEF 病患中安全且耐受良好，未見與傳統正性肌力藥相關的心搏過速、心律不整或缺血
  • 機轉差異：AC01 透過 Ca²⁺ 敏感度增加（而非 Ca²⁺ 動員）提升收縮力，可能解釋安全性優勢
  • 探索性效能訊號（cardiac output、stroke volume、LVEF 增加，chamber volumes 減小）方向上與 ghrelin 前臨床/臨床數據一致，但必須在更大規模研究中驗證
  • 首劑暫時性心搏過緩與 QTcF 延長透過漸進劑量遞增策略有所減輕
  • 代謝效應（血糖、體重）與已知 ghrelin/GH 軸訊號一致，需長期追蹤

限制（作者觀點）[文內]：

  1. 樣本數小、治療期短
  2. 女性 < 10%，限制外推性
  3. NT-proBNP 偏低，代表招募的是穩定門診病患
  4. 缺血性病因占 67–100%，比例偏高
  5. 所有病患均有 ICD，無法完全描述低於 back-up pacing rate 的心搏過緩
  6. 血流動力學為非侵入性測量，存在測量不精確
  7. 探索性效能分析未做統計假說檢驗
  8. NT-proBNP 無一致變化

[評估]：作者的限制討論合理且相當坦誠，有一定程度的自我批判。但他們未提及以下重要限制：(1) PI 身兼公司創辦人的嚴重 COI；(2) 缺乏獨立 DSMB；(3) 方案修訂放寬納入標準的影響；(4) 在如此小樣本下報導 "numerical signals" 的語言可能引導讀者過度解讀；(5) Phase 1b 空腹給藥 vs Phase 2a 進食給藥的差異對安全性訊號比較的干擾。

同期 Comment：Saldarriaga C, Rendon J. Oral ghrelin receptor agonist: a new promise for the improvement of systolic function. Lancet 2026. DOI: 10.1016/S0140-6736(26)01023-8

來自哥倫比亞 Cardio VID Clinic / Pontificia Bolivariana University 的兩位心臟科醫師，為獨立於研究團隊的外部評論者。核心論點如下：

肯定面：

  • 試驗設計允許精確評估安全性——遠端心律監測 patch、多時間點生物標記與 ECG，使心臟傳導變化的理解更精確
  • 結果與先前 ghrelin 研究一致
  • 這是近十年來首個具有新穎機轉的正性肌力藥物進入臨床

質疑面：

  • 族群多樣性極低：女性極少、近乎全為白人——限制外推性
  • 疾病嚴重度不足以代表目標族群：多數為 NYHA class II (76%)、NT-proBNP 相對偏低，但 AC01 的潛在目標族群是晚期心衰——安全性需在更嚴重的病患中再現
  • 空腹血糖上升與體重增加的長期影響需追蹤

後續試驗資訊：Comment 提到已註冊的 NCT07584967 試驗——400 名慢性晚期 HFrEF 病患、三組（AC01 3 mg / 1 mg / placebo）、每日兩次共 12 週、主要終點為超音波評估的心臟結構與功能。

Comment 結論：若結果在大型試驗中獲得確認，AC01 可能成為晚期 HFrEF 的新治療選項——但目前結論仍屬探索性，需謹慎解讀至 phase 3 RCT 完成。

8. 臨床建議

  • 可採用情境：目前無法採用——這是一個 phase 1b/2a 安全性試驗，AC01 尚未取得任何藥物核准。結果僅能支持繼續進行更大規模試驗。
  • 不建議直接套用的情境：所有臨床情境——數據不足以支持任何臨床決策。
  • 給臨床醫師的實務建議：
    1. 了解 ghrelin receptor agonist 作為新型 Ca²⁺ sensitizer 的機轉概念，但不要將探索性數據視為效能證據
    2. 關注後續 NCT07584967 Phase 2b 試驗結果，特別是超音波 remodeling 指標與安全性在晚期心衰族群的表現
    3. 代謝副作用（血糖、體重）在合併糖尿病的心衰病患中需特別警惕
  • 研究證據強度分級：弱——安全性數據來自 n=58 的早期試驗，效能為探索性且無統計檢驗，follow-up 僅 28 天

  • 隨機化細節：SAS 9.4 產生排列區塊隨機序列；中央 IWRS（Suvoda）分配；透過系統存取限制與編號藥品容器維持分配隱藏。Phase 1b block size 4（3:1 比例下必然固定分配）、Phase 2a block size 3（1:1:1 比例下同理）——小區塊大小加上小樣本，理論上分配可被預測，但雙盲應可抵消此風險。
  • 致盲細節：五重盲（病患、研究人員、結果評估者、分析者、sponsor）；AC01 與安慰劑 minitablets 外觀相同。未報告致盲成功度檢查。
  • ITT vs per-protocol：安全性分析集定義為所有接受至少一劑研究藥物的病患（等同 modified ITT = safety population）。58 名隨機分配者均進入分析，一名提早退出者（3.0 mg 組，因禁用伴隨用藥於第 14 天停藥）仍納入安全性分析。
  • 多重比較處理：不適用——無正式統計假說檢驗，所有效能分析為描述性。
  • 缺失資料處理：未進行資料填補（no imputation）。

A1. 特殊設計子模組

本試驗為 phase 1b/2a 安全性試驗，不屬於 non-inferiority、platform、或 surgical RCT，不啟動這些子模組。

但有一個設計特色值得注意：所有病患均需植入 ICD 作為 back-up pacing——這是一個特殊的安全保護措施，意味著如果 AC01 導致嚴重心搏過緩，ICD 會提供 back-up pacing。但這也代表：(1) 排除了大多數無 ICD 的 HFrEF 病患（尤其 LVEF > 35% 或無一次預防適應症者）；(2) 無法完全描述 AC01 的心搏過緩效果，因為低於 back-up pacing rate 的情形被 ICD 遮蔽。

B. 批判性評估（四大面向）

B1. 假說與理論邏輯

假說是否預先指定？

主要假說（安全性與耐受性）是預先指定的，且與 phase 1b/2a 的目的完全一致 → 無撒網式問題。探索性效能假說來自前臨床與先前人體 ghrelin 靜脈注射試驗的一致方向。

機轉是否合理？

  1. Ca²⁺ sensitization via reduced troponin I phosphorylation：有直接前臨床證據支持（ref 20, 21；小鼠心肌細胞中 ghrelin 與 AC01 降低 troponin I 磷酸化 → 增加 Ca²⁺ 敏感度 → 增加收縮力而不增加 Ca²⁺ 動員） → 機轉邏輯合理
  2. GHSR1a 作為心肌受體的直接作用：GHSR1a 在心肌與骨骼肌表達（ref 11），growth hormone 釋放證實靶點接合 → 合理
  3. 口服小分子能否重現靜脈注射 ghrelin 胜肽的效果？：前臨床支持（ref 21），但 ghrelin 有多重生理功能（食慾、GH 軸、葡萄糖代謝、交感調控），口服長期給藥可能啟動靜脈注射短期研究中未見的慢性適應或脫敏。本試驗 28 天數據尚不足以排除此風險。

最可疑的敘事跳躍：

  1. 作者在 Discussion 中將探索性數值差異（未做任何統計檢驗、SD 遠大於組間差異）描述為 "consistent with the preclinical and clinical findings of ghrelin"——這種框架將隨機變異歸因為藥物效果的風險很高（Discussion 段 "Exploratory analyses showed numerical changes in cardiac output, stroke volume, and cardiac structure and function that warrant further evaluation"）
  2. 文章標題包含 "exploratory efficacy"，在 Lancet 這樣的高影響力期刊會引導讀者認為已有效能訊號——但 n=8 的 box plot 差異完全可以是隨機噪音

外推性分級：

  1. 一般心衰族群：低外推性——ICD 要求排除大多數無 ICD 的穩定門診心衰病患；性別與族群嚴重偏斜
  2. 晚期心衰族群（本藥最可能的目標族群）：無法外推——本試驗幾乎不含 NYHA class IV、低血壓、近期住院或接受靜脈藥物治療的病患（這些均為排除標準）
  3. 合併糖尿病的心衰族群：需特別關注——本試驗已見到劑量依賴性血糖上升，但糖尿病患者占比約 25–50%（各組不等），樣本太小無法評估安全性

B3. 研究設計與偏差

隨機化與分派隱藏：充分——中央 IWRS、編號藥品容器、外觀相同的安慰劑。

致盲：理論上充分（五重盲），但未報告致盲成功度評估。AC01 的首劑心率下降（−17.5 bpm）與血壓下降（−16.5 mmHg）理論上可被有經驗的臨床醫師或病患感知，可能破盲。[文內未提及此風險]

對照組適當性：安慰劑作為對照在此設計中合理——這是一個加載於標準治療之上的安全性試驗（add-on design），所有病患均在最大耐受劑量 GDMT 之上接受研究藥物。

方案修訂影響：

  • Phase 1b 方案修訂放寬心率、LVEF、cardiac index、BMI 納入標準 → 暗示原始標準下招募嚴重困難 → 可能改變了原始設計目標的研究族群
  • Phase 2a 方案修訂將四組改為三組 → 減少了中間劑量的數據點 → 但在小型試驗中合理
  • 移除空腹限制 → Phase 1b（空腹）vs Phase 2a（進食）的安全性數據直接比較受限 → 作者用此解釋 Phase 2a 首劑 QTcF 延長較輕，但這與漸進劑量遞增的效果無法拆分

安全監督：

  • Safety review committee 包含 3 名獨立學術臨床醫師 + 2 名 sponsor 代表 → sponsor 參與安全審查決策
  • 未設置獨立 DSMB → 作者以 "early-phase design" 和 "protocol-defined objective stopping rules" 解釋。在僅 58 名病患的試驗中，此作法在法規上可以接受，但考慮到新型正性肌力藥物的歷史風險（PROMISE、SURVIVE），獨立監督的缺失是一個值得注意的治理缺口。

最可能造成偏差的設計點（最多 3 個）：

  1. PI / 公司創辦人 / 股東三位一體→ 影響結果解讀的中立性，尤其對探索性效能的「數值訊號」框架
  2. Phase 1b 與 Phase 2a 的給藥條件不同（空腹 vs 進食、7 天 vs 28 天）→ 跨 phase 比較安全性訊號（如 QTcF、心率變化）的能力受限，但作者直接進行了此類比較
  3. ICD back-up pacing 遮蔽心搏過緩效果 → 無法完全描述 AC01 的真實心搏過緩幅度與持續時間

B4. 測量工具與實務意義

血流動力學測量：使用 Innocor 非侵入性 inert gas rebreathing 測量 cardiac output 與 stroke volume → 這是一種經過驗證的方法，但精確度低於 thermodilution 或 Fick 法，且受操作者依賴。在 n=8–9 的組別中，測量誤差可能與藥物效果量相當甚至更大。

超音波心動圖：Phase 2a 由 Northwestern University Echocardiography Core Laboratory 集中判讀 → 減少 reader bias，為設計優勢。但 LVEF 的 test-retest variability（典型 ±5–8%）在 n=8 的組別中幾乎等於觀察到的組間差異（3.2 percentage points）。

就算結果是真的，真實世界可能有多大用處？

  • Phase 2a 3.0 mg 組 cardiac output 增加約 +0.6 L/min（vs placebo）——方向上有臨床意義，但在 n=8 的單次測量、無統計檢驗、非侵入性測量的背景下，這個數值的可信度極低
  • LVEF 增加約 3.2 percentage points（vs placebo）——若可重現且持續，理論上有意義（Kramer et al. 2010, ref 30 顯示 LVEF 改善可預測死亡率降低），但在此樣本量下無法做任何推論
  • 安全性數據是本文真正有價值的產出：28 天內無嚴重藥物相關不良事件、無 QTcF ≥ 500 ms、無心室快速心律不整，支持進入更大規模試驗

C. 統計與資料完整性

C1. 結果分類（CI + MCID 框架）

本試驗的主要終點為安全性，不涉及效能的正式假說檢驗。探索性效能終點僅報告 mean (SD) 或 median (IQR)，未報告任何 95% CI 或組間比較的效果量與 CI。因此，完整的 CI + MCID 分類框架無法執行。

對探索性效能的定性分類：

指標 MCID 參考 觀察方向 可信度 臨床分類
ΔCardiac output ~0.5 L/min 為有意義 +0.6 L/min (vs placebo) 極低 INCONCLUSIVE ❓
ΔLVEF ~3–5% points 為有意義 +3.2% points (vs placebo) 極低 INCONCLUSIVE ❓
ΔLVESV ~10–15 mL 為有意義 −8.7 mL (vs placebo) 極低 INCONCLUSIVE ❓
ΔNT-proBNP 30% 下降為有意義 無一致方向 極低 INCONCLUSIVE ❓

分類理由：每個效能指標的 SD 均大於或接近組間差異，加上 n=8–9 per group、無統計檢驗，任何數值差異都可能完全由隨機變異解釋。在這個 phase 1b/2a 的脈絡下，這不是批判而是合理的設計限制。

C2. Underpowered 判斷

試驗明確宣告為探索性、未進行 sample size calculation，因此 "underpowered" 的標籤不完全適用——試驗根本不打算有 power。但這代表所有效能「訊號」必須被框定為「hypothesis-generating」而非「evidence of effect」。作者在正文中適當使用了 "numerical" 一詞，但 Discussion 的語氣（"consistent with...findings of ghrelin"）可能過度引導解讀。

C3. Bayesian 補充分析

不適用——本試驗無正式 p 值或 CI，無法執行 Bayesian 補充分析。

C4. 報告完整性與其他統計問題

統計面紅旗清單：

  1. 未報告效能終點的 95% CI 或任何 formal effect estimate → 即使是探索性分析，報告 CI 是基本要求（CONSORT extension for pilot/feasibility trials 建議報告 CI 以輔助未來試驗設計），其缺失使讀者無法自行評估效果量的不確定性
  2. 圖表呈現使用 mean ± SD 而非 mean ± SE 或 95% CI → SD 在小樣本中與 CI 差異巨大；使用 SD 的 whisker plots 可能視覺上壓縮組間差異的不確定性（但也可能讓差異看起來更小）
  3. 探索性效能的多重終點未做任何校正或預先指定優先層級 → cardiac output、stroke volume、LVEF、LVESV、LA volume index、NT-proBNP、troponin——7 個以上的效能指標，任何一個「數值上有利」的機率相當高（即使純隨機下）
  4. 基線不平衡未以任何方式調整 → Phase 2a 三組在多個基線特徵上有數值差異（例如 1.0 mg 組 NT-proBNP 中位數 993 pg/mL vs 3.0 mg 組 545 vs placebo 551；心率 1.0 mg 67.4 vs placebo 62.1；心衰病程 1.0 mg 8.7 年 vs 3.0 mg 5.9 年 vs placebo 12.8 年）→ 在 n=8–9 per group 下，這些不平衡可能對效能訊號產生實質性混淆
  5. Fasting vs fed 給藥條件改變跨 phase 比較 → Phase 1b（空腹）與 Phase 2a（進食）的 PK 與 PD 不直接可比，但作者在 Discussion 中交叉引用兩 phase 的 QTcF 數據
  6. Fridericia QTcF 校正在低心率時可能過度校正 → 作者在 Discussion 中自行提及此問題（"Fridericia correction can overestimate QTc at lower heart rates"），但未使用替代方法（如 individual-corrected QTc）進行敏感度分析

E. 紅旗清單

  1. PI = 藥物發現者 = 公司創辦人 = 股東：這是最高級別的 COI 配置，文內雖有揭露但 Discussion 對探索性數據的 "consistent with" 框架可能受此影響
  2. 未設獨立 DSMB：在新型正性肌力藥物（有歷史增加死亡率的前例）的首次人體試驗中，缺乏獨立安全監督是治理缺陷
  3. 探索性效能未報告 CI：使 reader 無法自行判斷效果量的不確定性——在 Lancet 發表此等級試驗，不報告 CI 令人意外
  4. Sponsor 全面參與：AnaCardio 負責試驗設計、管理、數據收集、分析、撰稿與投稿決定——且 6 名 AnaCardio 員工為共同作者，其中 2 名參與安全審查委員會
  5. 兩次方案修訂放寬納入標準：暗示原始設計的可行性不佳，且改變了研究族群特徵
  6. 空腹 vs 進食給藥條件差異跨 phase 比較安全性訊號（QTcF、心率），但作者未將此列為主要限制
  7. 首劑暫時性 QTcF 延長 +17 ms（3.0 mg 組）與收縮壓下降 −16.5 mmHg：雖然暫時且無症狀，但在無 ICD 保護的真實世界病患中，此幅度的心搏過緩與低血壓可能有臨床意義
  8. 血糖上升劑量依賴性明確（3.0 mg +3.25 mmol/L），但樣本太小無法評估長期影響——心衰合併糖尿病的族群佔很大比例

F. 反向解釋

  1. 探索性效能訊號為純隨機變異：n=8–9 per group、SD 大於組間差異、7+ 個效能指標中任何一個出現「數值差異」的機率很高——即使 AC01 完全無效能。Placebo 組 day 28 的 LVEF 也增加了 1.6 percentage points，顯示測量本身有回歸均值或時間效應。
  2. 安全性「良好」可能因族群太健康：NT-proBNP 中位數 557 pg/mL、76% NYHA II、100% 有 ICD back-up pacing——這些都是「安全」的病患。真正需要正性肌力藥物的晚期心衰族群（低血壓、腎功能差、高 NT-proBNP、無 ICD）的安全性完全未知。
  3. 首劑心搏過緩的臨床意義被 ICD 遮蔽：−17.5 bpm 的心率下降在有 ICD back-up pacing 的情況下不會產生臨床事件，但在無 ICD 的病患中可能觸發症狀性心搏過緩。
  4. Phase 2a 較輕的首劑反應不一定歸因於漸進劑量遞增：Phase 2a 改為進食給藥（降低吸收速率與 Cmax）可能是主因，而非漸進劑量策略的功勞——兩個變數同時改變，無法拆分。

G. 最終裁決

  • 整體可信度：中——安全性數據在 phase 1b/2a 的脈絡下品質可接受（多中心、雙盲、集中判讀、完整追蹤），但 COI 配置嚴重、無獨立 DSMB、效能數據僅為描述性。Lancet 發表賦予的高能見度可能使讀者過度解讀探索性訊號。

  • 可採用的條件：目前不可採用於臨床——僅能作為 Phase 2b/3 試驗設計的參考依據

  • 不建議採用的情境：所有臨床決策

  • 若要改觀，最需要的 3 個關鍵改進：

    1. 獨立於 sponsor 的大型 Phase 2b/3 試驗（至少數百名病患、含晚期心衰族群），以 clinical outcomes 或經驗證的 surrogate（如 NT-proBNP 變化）為主要終點，並設置獨立 DSMB
    2. 納入多元族群（女性 ≥ 30%、非白人族群）且不要求 ICD，以評估真實世界安全性
    3. QT 專題研究（thorough QT study, ICH E14）以正式排除直接心臟複極效應，區分心率依賴性 QTc 變化與藥物直接效應

  • 一句話結論：AC01 在 58 名穩定 HFrEF 病患中 28 天內安全可耐受，但效能證據僅為不可推論的探索性數值差異，距離臨床實用仍需大型隨機試驗驗證。
