3. 研究背景

既有事實與證據 [文內]：

  • 耐力跑表現取決於在生理負荷累積下維持配速的能力（ref 1-2）
  • 即使在訓練良好的馬拉松跑者中，完賽時間與配速仍存在相當大的個體差異（ref 3-5）
  • 精神疾病與降低的任務持續性（task persistence）、在認知/情緒/生理負荷增加下維持目標導向行為的能力減退有關（ref 10-16）
  • 運動員心理健康問題日漸受重視（ref 6-9），但精神科診斷對馬拉松表現的影響從未被系統性研究

知識缺口 [文內]：精神科診斷相關的脆弱性（vulnerability）是否會轉化為實際耐力運動表現的可測量差異？既有實驗室證據的生態效度有限，需真實世界高負荷情境驗證。

Research question [文內]：

  1. 波士頓馬拉松跑者中終身精神科診斷的盛行率為何？
  2. 有精神科診斷的跑者是否在完賽時間、目標達成率與分段配速軌跡上表現出差異？

4. 研究設計與方法

PICO：

  • P：2024 年波士頓馬拉松註冊跑者，18 歲以上，自願填寫賽前問卷
  • I（Exposure）：自報終身精神科診斷（二元：有/無）
  • C：無精神科診斷的跑者
  • O：
    • 主要：實際完賽時間（秒）、目標達成率（goal realization，%）
    • 次要/探索性：5 公里分段累積時間軌跡（split-level trajectory）

關鍵研究設計細節：

  • 設計類型：橫斷面問卷調查 + 前瞻性連結官方賽事紀錄
  • 樣本來源：BAA 於賽前三天以電子郵件發送給所有註冊跑者（N=25,660），自願填寫線上問卷
  • 問卷回收：N=450（回應率 ~1.75%），排除 2 名帕拉田徑選手後 N=448
  • 精神科診斷組 n=76（16.74%），無診斷組 n=372
  • 統計方法：
    • 獨立樣本 t-test + Mann-Whitney U（group comparison）
    • 四組多元線性迴歸（分別加入 Grit / BRS / Big-Five / GAD-7），Bonferroni 校正 α=0.0125
    • Linear mixed-effects model（分段軌跡分析，random intercept + sensitivity with random slope）
  • Power analysis：t-test 需 N=128（Cohen's d=0.50），迴歸需 N=123（f²=0.15）→ 實際 N=448 滿足

主要變項定義：

  • 精神科診斷：「是否曾被合格心理健康專業人員正式診斷精神疾患」（自報，二元，無診斷類別、嚴重度、時間資訊）
  • 目標達成率：goal time ÷ actual time × 100（>100% = 跑得比預期快）
  • 分段數據：官方 5 公里 split（5, 10, 15, 20, 21.1, 25, 30, 35, 40, 42.195 km）

倫理審查 [文內]：Southwest Baptist University Research Review Board 核准，符合 Helsinki Declaration，取得電子知情同意。

  • [評估]：此 IRB 來源值得注意——兩位作者分別隸屬 University of Pittsburgh 與 Harvard Medical School / McLean Hospital，但倫理審查卻由 Southwest Baptist University（密蘇里州一所小型教會大學）執行。文內未解釋此安排的原因，可能與作者某一階段的機構隸屬有關，但這不影響研究合規性，只是不尋常。

5. 研究結果重點整理

樣本特徵（Table 1，圖頁 p.30-32）：

  • 全樣本平均年齡 47.56 歲（SD 12.98），55.73% 女性，92.2% 白人/歐裔
  • 平均完成 13.06 場馬拉松（SD 16.50，range 0-100），週跑量 41.19 英里（SD 14.31）
  • GAD-7 平均 4.27（SD 4.06）；285 人 minimal、115 人 mild、35 人 moderate、15 人 severe
  • 16.74% 有精神科診斷，18.67% 報告目前有傷

組間差異（文內 Table 2，[限制：PDF 轉檔 markdown 未保留 Table 2]，但文中有敘述）：

  • 有診斷組：較年輕、較多女性、較少先前馬拉松經驗、較慢 PR、較高 GAD-7 與 negative emotionality
  • 兩組在訓練量、訓練週數、grit、resilience、openness、conscientiousness、agreeableness、injury status 上無顯著差異

迴歸結果摘要（完賽時間）：

  • 四個模型中精神科診斷均為顯著預測因子（β=1018–1084 秒，all p<.001），即使調整 PR、先前馬拉松數、年齡、性別、傷況、週跑量與各心理變項後仍然顯著
  • 模型解釋變異量 R²≈0.71（PR 為最強預測因子）
  • Grit、BRS、Big-Five、GAD-7 均不是完賽時間的顯著預測因子

迴歸結果摘要（目標達成率）：

  • 精神科診斷在四個模型中均顯著（β=−2.82 至 −3.27，all p≤.002）
  • 但模型解釋變異量極低：R²=0.033–0.059
  • 敏感度分析（加入 PR 與先前馬拉松數）：精神科診斷仍顯著但效果量降低（β=−2.05 至 −2.48，p<.050，注意此時已不滿足 Bonferroni 校正門檻）

標準化效果量（Figure 2，p.35）：

  • 完賽時間：精神科診斷 β=0.343 (95% CI 0.204–0.483)，為 PR (β=0.597) 之後第二大預測因子
  • 目標達成率：精神科診斷 β=−0.411 (95% CI −0.666, −0.156)，為最大預測因子

分段軌跡分析（Figure 3，p.36）：

  • Distance × diagnosis interaction：β=24.97 sec/km, SE=3.11, t=8.03, p<.001
  • 意義：有診斷組每公里額外累積約 25 秒的減速，42 公里累計約 1050 秒（~17.5 分鐘）的額外落後
  • Random slope 敏感度分析仍顯著（p=.006）

Figure 1 圖判讀（p.34）：Panel A（完賽時間）的 rain cloud plot 清楚呈現有診斷組的分布向上偏移（更慢），但兩組有大量重疊。Panel B（目標達成率）兩組分布重疊更為嚴重，平均差異很小（~2.2 個百分點），與 Mann-Whitney U 未達顯著一致。

6. 作者討論與評論重點

作者的主要訊息 [文內]：

  • 精神科診斷代表一種先前未被辨識的耐力運動表現相關脆弱性
  • 此脆弱性不能用動機、訓練或人口學因素完全解釋
  • 可能涉及粒線體/代謝功能障礙（mitochondrial/metabolic dysfunction）、乳酸處理異常等生物能量學機制
  • 實務意義：有精神科病史的跑者可能需要更長時間在賽道上，增加醫療遭遇風險，應考慮在馬拉松醫療團隊中整合精神科專業人員

限制（作者觀點） [文內]：

  1. 波士頓馬拉松為高度菁英化樣本（嚴格資格門檻），外推性受限
  2. 自願問卷可能引入回應偏差
  3. 二元自報精神科診斷未能區分診斷類別、嚴重度、病程或緩解狀態
  4. 樣本為菁英跑者，需在更多元化的馬拉松跑者中複製

[評估]：

  • 作者的限制陳述忽略了幾個重要問題：(1) 回應率僅 1.75%，選擇偏差可能嚴重——願意在賽前填寫關於精神科病史問卷的人與不願意的人可能有系統性差異；(2) 精神藥物使用完全未被測量——抗憂鬱藥、抗精神病藥等可能直接影響體溫調節、心率、疲勞感與運動表現，這比「精神科診斷本身」更可能是直接因果中介；(3) 殘餘混淆——PR 較慢本身可能反映許多未被測量的因素（訓練品質、營養、睡眠品質、跑步經驗的深度 vs 僅次數），而不僅是「基線能力」；(4) 目標達成率在未校正分析中不顯著（Mann-Whitney p=.090），作者依賴共變項調整後的顯著性，但共變項調整可能引入 collider bias；(5) 討論中提出的「粒線體/代謝功能障礙」機轉是高度推測性的敘事跳躍，缺乏任何本文數據的直接支持。

8. 臨床建議

  • 可考慮參考的臨床情境：馬拉松賽事醫療規劃——本文提供初步證據支持在大型馬拉松醫療團隊中考慮心理健康因素。對運動醫學門診來說，有精神科病史的跑者可能值得多關注其配速策略與疲勞管理。
  • 不建議直接套用的情境：
    • 不應以本文數據作為「精神科診斷直接損害運動表現」的因果結論
    • 不應用來限制有精神科病史者參與馬拉松或勸阻其參賽

    1. 馬拉松醫療人員可注意長時間仍在賽道上的跑者可能有更多醫療需求，但此與精神科病史的因果關係尚不確定
    2. 有精神科病史的跑者可與教練討論更保守的配速策略，但目前證據不足以制訂正式指引
  • 研究證據強度分級：弱——觀察性設計、極低回應率、粗糙的暴露測量、多重替代解釋未排除

SKILL-A：觀察性研究批判性評讀

A. 補充技術細節

研究設計、PICO、主次終點已詳述於 SECTION-0，此處補充統計與設計細節：

  • 樣本數估算：有事前 power analysis。t-test 目標 Cohen's d=0.50，需 N=128；迴歸目標 f²=0.15、11 predictors，需 N=123。實際 N=448 超標。但 power analysis 以 medium effect size 為目標——若真實效果較小（如 goal realization 的 R²僅 3-6%），power 可能不足以穩定估計。
  • 多重比較處理：四組迴歸模型以 Bonferroni α=0.0125 校正——合理但保守。然而，兩個主要 outcome（完賽時間 + 目標達成率）未額外校正，等於隱含 8 個 primary tests 但只校正了一半。
  • 缺失資料處理：問卷要求完整填答才能提交（mandatory completion）→ 無問卷層面遺失。但 split-level 分析 n=427（少了 21 人，未解釋原因——可能是 DNF 或 split 紀錄不完整）。
  • 迴歸假設：作者宣稱 normality、linearity、homoscedasticity、multicollinearity 均通過；但 t-test 層面已知 outcome 不符常態分布且變異數不齊（Levene's p<.003），迴歸殘差是否亦符合假設存疑。
  • Mixed-effects model：指定 random intercept for participant（合理），distance 與 diagnosis 的 interaction term 為核心檢驗。Sensitivity analysis 加入 random slope for distance 仍顯著（p=.006），但此模型的完整參數估計（如 random effect variance、ICC）未報告。

殘餘混淆嚴重關切：

  • 精神藥物使用：完全未測量。SSRI、SNRI、benzodiazepine、antipsychotics 等可直接影響心率調節、體溫調節、出汗反應、疲勞感知與運動耐受力。文章討論段（p.19-20）自行引用文獻承認「psychotropic medications have been shown to elevate the risk of medical emergencies during marathon running」，卻未將藥物使用作為共變項納入——這是關鍵遺漏。
  • 精神科診斷的異質性：將所有精神科診斷（從社交焦慮到雙極性疾患到 PTSD 到飲食疾患）打包成一個二元變項，掩蓋了可能截然不同的機制與效果方向。
  • 睡眠品質：未測量。精神疾患常伴隨睡眠障礙，而賽前睡眠品質直接影響比賽日表現。
  • BMI / 體重：未測量。某些精神藥物造成體重增加，直接影響馬拉松表現。
  • 當日比賽環境條件（天氣、corral 分組、起跑時間）：所有跑者共享同日天氣，但起跑 wave/corral 不同可能影響初始配速。

B. 批判性評估（四大面向）

B1. 假說與理論邏輯

  • 假說是否預先指定？ 是——作者在 Introduction 末段明確陳述假說方向（有診斷者應較慢、達成率較低、差異隨距離漸進出現）。[文內 Methods 段前]
  • 機轉是否與情境匹配？
    • 作者引用的核心理論鏈：精神疾患 → 降低持續目標導向行為的能力 → 在疲勞下無法維持配速。此邏輯鏈來自短時實驗室作業的證據（ref 14-16），外推至 4+ 小時的馬拉松比賽是一個重大推理跳躍。
    • 討論中提出的粒線體/代謝假說（mitochondrial dysfunction, elevated lactate）(p.18-19) 是過度敘事跳躍——本文沒有測量任何生理指標（乳酸、代謝率、心率），純粹是事後推測。
    • 最可能的替代機轉：(1) 精神藥物的直接藥理效應；(2) 與精神疾病相關的慢性睡眠品質不佳；(3) 有精神科診斷者的 PR 已較慢（Mean PR 差異），此差異可能反映訓練品質或跑步年資的深度差異，而非「精神科脆弱性」本身。

B2. 受試者與外推性

  • 受試者是否與宣稱對象一致？ 部分——作者宣稱研究對象為「波士頓馬拉松跑者的子集」，但 1.75% 的回應率意味著結果僅反映極少數願意在賽前三天填寫包含精神科病史問題的跑者。
  • 基線是否平衡？ 不平衡——有診斷組較年輕、較多女性、較少馬拉松經驗、PR 較慢、GAD-7 與 negative emotionality 較高。迴歸調整試圖校正，但殘餘混淆風險高。
  • 外推性分級：
    1. 一般健康族群跑者：不可外推。波士頓馬拉松需嚴格 BQ（Boston Qualifying）時間，這些是高度菁英化的業餘跑者，且 92% 為白人/歐裔。
    2. 菁英業餘馬拉松跑者：有限外推。但 1.75% 回應率產生嚴重選擇偏差，且精神科診斷的盛行率（16.7%）可能與一般菁英跑者群體的真實盛行率不同。
    3. 一般精神科病患族群：不可外推。這些是能夠通過波士頓馬拉松資格門檻的高功能個體，與一般精神科病患有本質差異。

B3. 研究設計與偏差

最可能造成偏差的設計點（3 點）：

  1. 極低回應率引發的嚴重選擇偏差（讓效果可能變大或變小，方向不可預測）→ 只有 1.75% 的註冊跑者完成問卷。願意在賽前揭露精神科病史的人可能與不願意的人在多個維度上系統性不同。例如：功能較差的精神疾患患者可能更不願意參加問卷（低估盛行率）；或反之，對心理健康高度關注的跑者更願意參加（高估盛行率且與訓練行為有交互作用）。(Methods)

  2. 暴露測量的嚴重非差別錯分類（most likely 讓效果變小/稀釋，但若有系統性回憶偏差可能 distort 方向）→ 「終身精神科診斷」的二元自報：(a) 未區分診斷類型——焦慮症、重鬱症、雙極性疾患、PTSD、飲食疾患的機制與對運動表現的影響可能完全不同，甚至方向相反（某些精神特質可能促進訓練投入）；(b) 未區分目前活動性 vs 完全緩解；(c) 未測量嚴重度、診斷數量、或病程時間；(d) 不同國家的精神科診斷標準不同，但樣本來自 25+ 國家。(Methods)

  3. 未測量精神藥物使用（核心遺漏的中介/混淆變項）（讓效果方向不確定，但最可能讓觀察到的效果被誤歸因於「精神科診斷」而非「藥物效應」）→ 作者在討論中自行提及 psychotropic medications 可能增加馬拉松醫療風險（p.19-20, ref 50-51），但研究中完全未收集藥物使用資料。這是因果路徑上的關鍵中介變項：精神科診斷 → 精神藥物使用 → 運動表現下降。若效果主要來自藥物副作用而非「精神科脆弱性」，整個理論框架需重新定位。

對照組適當性：本文非 RCT，無主動介入。「對照組」為自報無精神科診斷者——可能包含未被診斷但有精神健康問題的個體（undisclosed / undiagnosed），會稀釋組間差異。

B4. 測量工具與實務意義

  • 暴露測量：單一二元自報題目，無信效度資料。精神科診斷的自報有已知的低敏感度（可能低報）。
  • 結果測量：官方 BAA 完賽時間與分段數據——這是高品質、客觀的測量，是本研究的強項。
  • 目標達成率：以賽前自報目標時間計算——但目標時間本身可能受精神狀態影響。有精神科診斷者可能設定較不切實際的目標（方向不確定），使得目標達成率作為「配速維持能力」的指標產生混淆。
  • 實務意義：完賽時間差異約 20 分鐘（4:14 vs 3:54），但在調整 PR 後的殘差差異（~1018-1084 秒，即 ~17-18 分鐘）看起來很大。然而目標達成率僅差 ~2.2 個百分點（91.4% vs 93.6%），在個體層面上幾乎不可察覺。Goal realization 模型的 R²=3-6% 意味著精神科診斷只解釋了極少的變異。

C. 統計與資料完整性

C1. 結果分類（CI + MCID 框架）

本文為觀察性研究而非 RCT，嚴格的 CI+MCID 分類框架主要適用於介入試驗。但仍可就效果量與精確度做評估。

完賽時間差異：

  • 未調整差異：1812 秒（~30 分鐘），95% CI [874, 2749]秒
  • 調整後 β=1018–1084 秒（~17–18 分鐘），均 p<.001
  • 效果量穩定且 CI 不含零，但無法確定此關聯為因果

目標達成率差異：

  • 未調整差異：2.2 百分點，95% CI [0.06, 4.34]
  • CI 下界極接近零（0.06），且 Mann-Whitney U 未達顯著（p=.090）
  • 調整後 β=−2.82 至 −3.27 百分點（p≤.002），但 R²極低
  • 敏感度分析（加入 PR + 先前馬拉松數後）：β 降至 −2.05 至 −2.48，p<.050 但未報告是否通過 Bonferroni 校正門檻（α=0.0125）——此為選擇性報告的警訊

結果分類：

  • 完賽時間：效果方向穩定、統計上穩健，但因果推論受限於觀察性設計與殘餘混淆
  • 目標達成率：INCONCLUSIVE ❓——未調整的非參數檢定不顯著，調整後勉強顯著但 R²極低，敏感度分析進一步削弱效果量

C2. Underpowered 判斷與 Winner's Curse

本文 N=448，名義上 power 充足（目標 d=0.50）。完賽時間的效果量大（d≈0.55-0.70，由 CI 推算），沒有 underpowered 問題。但目標達成率的效果量小（d≈0.29，根據 t-test 結果推算），實際 power 對此效果量可能只有 50-60%——接近 underpowered 邊緣。

Winner's Curse 在本文中不是主要顧慮，因為完賽時間效果穩健。但目標達成率的邊緣顯著性加上低 R² 是需要複製確認的訊號。

C4. 報告完整性與其他統計問題

樣本數與 power（雙向）：

  • 完賽時間：adequately powered，效果穩定
  • 目標達成率：接近 underpowered，效果不穩定

多重比較：

  • 四組心理變項模型以 Bonferroni 校正（α=0.0125）——合理
  • 但兩個 primary outcomes（完賽時間 + 目標達成率）之間未額外校正——等於 8 個 primary tests 只校正了 4 個
  • 分段軌跡分析的 interaction 未納入多重比較校正框架

分析策略：

  • 完賽時間迴歸加入 PR 與先前馬拉松數；目標達成率迴歸原則上不加入（避免 overadjustment），但敏感度分析加入後效果量降低且 Bonferroni 校正可能不再通過——此結果在正文中被低度強調

統計紅旗清單：

  1. 目標達成率的 Mann-Whitney U 不顯著（p=.090）但作者將其定位為「conditional effect」而非坦承主要結果之一不穩健——此說法等於將不顯著結果重新包裝為需要共變項調整才能「釋放」的效果，但共變項調整在觀察性研究中可能引入而非消除偏差
  2. 精神藥物使用完全未測量卻被討論中引用為風險因素——自相矛盾的遺漏
  3. 目標達成率敏感度分析的 Bonferroni 校正結果未明確報告——只說「all p<.050」，但校正門檻為 0.0125
  4. Figure 3 未呈現信賴區間或誤差帶——無法判斷分段層級估計的精確度
  5. 21 名跑者在 split-level 分析中消失（448→427）但未解釋原因——若這些是 DNF（Did Not Finish），而有精神科診斷者 DNF 率不同，可能引入 survival bias
  6. R² 僅 3-6%（目標達成率模型）但被框架為「robust predictor」——統計顯著不等於解釋能力強
  7. 混合效果模型的 random effect structure 未充分報告（如 ICC、random effect variance、model fit comparison）

D. 次組分析評估

本文未執行正式的次組分析。敏感度分析（加入 PR + 先前馬拉松數於目標達成率模型、log-transformed 先前馬拉松數）屬於分析策略變異而非次組分析，此處不需要套用 JAMA Subgroup Criteria。

但值得注意的是，本文缺少一些有意義的次組探索：未依性別、年齡層、或 GAD-7 嚴重度分層分析——這些都是可能修飾精神科診斷與表現關聯的重要變項。

E. 紅旗清單

  1. 回應率 1.75%——任何試圖從此樣本推論至「波士頓馬拉松跑者」甚至「馬拉松跑者」群體的結論都高度可疑
  2. 精神藥物使用未測量——最可能的因果中介被完全忽略，使「精神科診斷本身造成表現下降」的敘事缺乏可驗證性
  3. 暴露測量品質極低——單一二元自報題目，將所有精神疾患混為一類，無法排除診斷類型是主要效果修飾因子
  4. 目標達成率在未調整分析中不顯著（p=.090）——作者依賴調整後結果但未對此不一致性做充分審慎解讀
  5. 討論中的機轉推測（粒線體/代謝假說）缺乏任何數據支撐——從觀察性問卷研究跳到細胞生物能量學的敘事距離過遠
  6. IRB 來源與作者機構不符——Southwest Baptist University vs UPMC/Harvard，未解釋
  7. 92% 白人/歐裔——種族/族群構成高度同質，外推性嚴重受限
  8. Brown 作為 BAA 馬拉松心理師的非財務利益關聯——研究結論直接支持其職業角色的價值與擴展
  9. Running title「PSYCHIATRIC DIAGNOSIS PREDICTS BOSTON MARATHON PERFORMANCE」使用因果語言「predicts」——觀察性研究不應使用暗示因果的語言，雖然正文較謹慎

F. 反向解釋

  1. 精神藥物效應假說：有精神科診斷者中可能有顯著比例正在服用精神藥物（SSRI/SNRI/benzodiazepines/mood stabilizers）。這些藥物已知影響體溫調節（增加熱衰竭風險）、造成疲勞感、影響心率反應與體重——這些藥理效應可直接解釋較慢的完賽時間與後段更明顯的減速，而無需援引「精神科脆弱性」本身。文內支持：作者自行引用 ref 50-51 承認 psychotropic medications 增加馬拉松醫療風險。反對此解釋的線索：無——因為藥物使用完全未被測量。

  2. 選擇偏差 + 回憶偏差假說：願意在賽前揭露精神科病史的跑者可能是準備狀態較差、對比賽焦慮較高、或一般而言較不避諱討論弱點的個體。這些特質可能獨立地與較保守的訓練、較不優化的賽前準備有關，而非精神科診斷本身影響表現。文內支持：診斷組 PR 已較慢、先前馬拉松經驗較少（Table 2 描述）。反對線索：迴歸調整了 PR 和經驗，但殘餘混淆無法排除。

  3. 反向因果 / 共同原因假說：較差的體適能或健康狀態可能同時增加獲得精神科診斷的機率（例如慢性疼痛、睡眠障礙、功能下降導致就診並獲得精神科診斷）和降低馬拉松表現。因果方向可能是：「整體健康狀態較差 → 精神科就診 + 較差的運動表現」，而非「精神科診斷 → 較差的運動表現」。文內支持：診斷組 PR 較慢、negative emotionality 較高。反對線索：訓練量與 grit 兩組相當，但這不能排除訓練品質或身體健康狀態的差異。

  4. 目標設定差異假說：有精神科診斷者可能設定較不切實際的（過度樂觀或過度悲觀的）目標時間，而非在配速維持能力上有實質差異。若目標時間本身受精神狀態影響，「目標達成率」就不是配速能力的純粹指標。文內支持：目標達成率的未調整分析不顯著（p=.090），效果量很小（2.2 百分點）。反對線索：完賽時間的差異在調整 PR 後仍然顯著。

G. 最終裁決

  • 整體可信度：低至中

    • 完賽時間的關聯性較為穩健（調整後效果大且穩定），但因果推論因觀察性設計與嚴重殘餘混淆（尤其精神藥物未測量）而無法成立
    • 目標達成率的結果不穩定（Mann-Whitney 不顯著、R²極低、敏感度分析削弱效果量）
    • 極低回應率（1.75%）與高度同質的樣本（92% 白人）嚴重限制外推性

  • 可採用的條件：

    • 作為「精神科病史與馬拉松表現可能存在關聯」的探索性證據，用來生成假說
    • 作為馬拉松賽事醫療規劃中考慮心理健康因素的初步支持
    • 但不可作為因果結論或臨床指引的基礎

  • 不建議採用的情境：

    • 不應用來制訂針對精神科病患的參賽限制或分層建議
    • 不應將「精神科診斷影響耐力表現」作為已確立的事實引用
    • 不應作為擴大馬拉松心理服務的唯一證據基礎

  • 若要改觀，最需要的 3 個關鍵改進：

    1. 測量精神藥物使用並將其作為中介/混淆變項納入分析——這是區分「精神科診斷本身」vs「藥物效應」的必要條件
    2. 區分精神科診斷類型、目前活動性 vs 緩解、以及嚴重度——解除二元混合的異質性
    3. 在更高回應率（至少 >10%）且種族多元化的馬拉松樣本中複製——排除嚴重選擇偏差的可能性

  • 一句話結論：波士頓馬拉松中自報精神科診斷者完賽較慢且後段減速更多，但極低回應率、未測量精神藥物與粗糙的暴露定義使結論停留在假說生成階段。
