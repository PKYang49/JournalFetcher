3. 研究背景 [文內]

  • 既有事實：IE 少見但可致命；現行 AHA/ACC（2018）與 ESC（2023）指引僅對人工瓣膜、既往 IE、特定先天性心臟病建議抗生素預防；HCM 不列高風險。
  • 知識缺口：多個 case report/series 與小型登錄研究顯示 HCM（尤其 LVOT obstruction）可能有臨床上有意義的 IE 風險，但缺乏大樣本量化。
  • Research question：HCM 病人 5 年 IE 風險相對配對對照與瓣膜介入參考族群為何？（明確陳述）

4. 研究設計與方法（含混淆控制）

  • PICO
    • P：≥45 歲、2015-01-01～2019-12-31 有門診紀錄、ICD-10-CM I42.1/I42.2（HCM）；排除既往 IE、先天性心臟病（Q20–Q28）、任何瓣膜介入史、物質使用疾患（F11/F14/F15/F19）。
    • E（Exposure）：HCM 診斷。
    • C：有門診紀錄但無 HCM 之病人，1:1 propensity-score 配對；另設「既往瓣膜介入」參考組（n=1916）當高風險基準。
    • O：主要=5 年累積 IE（I33.x、I38、I39）；次要=全因死亡。
  • 關鍵設計：logistic PS + nearest-neighbour matching、caliper 0.1 pooled SD；共變項以 causal DAG 選「minimally sufficient set」（figure S1，未保留）；追蹤自 HCM 初診起算，截尾於 IE / 死亡 / 5 年；Cox PH（Schoenfeld 檢定 PH 假設）；明白承認 competing-risks 分析因 TriNetX 限制未做；person-years 以「cohort size × median follow-up」粗估（自承假設均勻追蹤）。
  • 主要 outcome 操作型定義：純以 ICD 碼定義，無影像 / 血培養 / Duke criteria 佐證。

6. 作者討論與評論重點 [文內]

  • 主要訊息：HCM 為 IE 的「中度風險」族群，5 年風險是一般族群 2 倍餘、約瓣膜病人一半；主張重新評估指引、對高風險表型（LVOT 阻塞、左房擴大、既往中膈縮減術）「合理考慮」抗生素預防。
  • 與文獻異同：自承粗發生率（~6.5/1000 PY）高於 Spirito（3.8/1000 PY，僅阻塞型 224 例）、Thornhill（0.8%/5yr）、Somendra（0.57%/6.1yr），歸因於樣本大、機構多元、社經未捕捉。
  • 作者限：ICD 碼誤分類、無法取得預防性抗生素使用、無法依表型次組、HR 非恆定因果、對照組 IE（1.3%）偏高。
  • [評估]：限制清單避重就輕——完全未提 IE 這種「需被偵測才會被編碼」的結果在 HCM（高度醫療接觸族群）與門診對照間存在嚴重偵測 / 監測偏差；也未討論死亡的競爭風險如何影響累積發生率。臨床建議（考慮預防）明顯超出資料所能支持的範圍。

8. 臨床建議

  • 可謹慎參考的情境：作為「HCM 病人 IE 絕對風險並非可忽略」的訊號生成證據；提醒臨床對阻塞型、左房擴大、既往中膈縮減、帶 CIED 導線的 HCM 病人，於菌血症事件時提高 IE 警覺。
  • 不建議直接套用：不應據本文改變抗生素預防決策。本文並未證明 (a) HCM 是 IE 的因果驅動、(b) 抗生素預防能降低 HCM 的 IE——兩者都是「重新分類為 intermediate-risk 並給預防」主張的必要前提，本文皆未提供。
  • 實務建議：現行 AHA/ACC 2018、ESC 2023 立場（HCM 不常規預防，除非併瓣膜介入或既往 IE）仍應維持；此研究不足以推翻。
  • 證據強度分級：弱（單一資料庫、純碼定義結局、偵測偏差與殘餘混淆方向一致地把 HR 往上推、無競爭風險校正）。

SKILL-A：觀察性研究批判性評讀

A. 補充技術細節（僅補 SECTION-0 未涵蓋者）

  • Power/樣本：無事前 power 估算（觀察性、便利樣本 3.6 萬人，統計精度非瓶頸）。
  • 配對變項：由 DAG「minimally sufficient set」決定，但清單在未保留的 figure S1——無法驗證是否納入關鍵混淆（醫療接觸強度、牙科處置、留置導管、洗腎、免疫抑制）。
  • PH 假設：Schoenfeld χ²=8.899，p=0.003（統計上違反），作者卻寫「no meaningful violations」——自相矛盾（見 C）。
  • 缺失資料 / 追蹤：person-time 以 cohort×median follow-up 粗估，自承假設均勻追蹤（EHR 幾乎不成立）。
  • 競爭風險：未做（TriNetX 限制），對「罕見結局＋12.4% 死亡」是實質缺陷。

B. 批判性評估（四大面向）

B1. 假說與理論邏輯

  • 機轉合理：阻塞型 HCM 的 mitral-septal contact、高速湍流、二尖瓣逆流、左房擴大 → 內皮損傷 → 菌血症時附著。可信機轉 1–3：LVOT 湍流內皮損傷、MR jet lesion、左房擴大瘀滯。
  • 敘事跳躍：機轉只適用於阻塞型（Spirito 早已指出 IE 幾乎專屬阻塞型），但本文用 ICD 碼（I42.1 含 obstructive、I42.2 為 other HCM）無法區分阻塞與否，卻把整體 HR 2.62 的因果解釋掛在阻塞型機轉上——機轉與被測族群不匹配。

B2. 受試者與外推性

  • ≥45 歲門診 HCM；排除物質使用（好，降低 IV drug use 混淆）。但排除 <45 歲，恰好可能排除機轉最相關的年輕阻塞型。
  • 對照為「有門診紀錄但無 HCM」、且自承「顯著共病負擔」——對照組 IE 1.3% 偏高，作者稱這會「低估」HCM 真實風險；但同時對照組缺乏 HCM 病人那種密集心臟影像追蹤，反而使 HCM 端 IE 更容易被偵測，方向相反。
  • 外推性分級：低–中。單一美國 EHR 網絡、純碼結局。

B3. 研究設計與偏差（方向判斷）

  1. 偵測 / 監測偏差（最關鍵，效果被放大）：IE 是「查了才會發現」的結局。HCM 病人終身接受年度心臟超音波、心臟科追蹤、症狀時做血培養與 TEE；門診對照則否。差異化的偵測強度會系統性把 HCM 端 IE 發生率往上抬 → HR 2.62 高估。作者完全未觸及。
  2. 殘餘混淆（效果被放大）：AFib、缺血性心臟病、主動脈瓣疾病配對後仍嚴重不平衡，而這三者本身就是 IE / 菌血症 / 心內膜受損的風險因子。作者辯稱「反映 HCM 內在重塑而非配對偏差」——但無論成因為何，只要它們同時預測 IE，未被平衡即為殘餘混淆，把 HCM 效果往上推。
  3. 競爭風險未校正（效果方向不定但偏高估）：12.4% 死亡下用 KM 估累積發生率會高估 IE 累積機率（本應用 Aalen-Johansen / Fine-Gray）。
  • 對照組適當性（Gyawali）：此為病因學而非療效研究，對照為「無 HCM 門診族群」尚合理，但監測強度不對等破壞可比性。

B4. 測量工具與實務意義

  • IE 純以 I33.x/I38/I39 定義，無 Duke criteria、無血培養 / 影像佐證；I38「valve unspecified」與 I39 誤分類率高。
  • 就算關聯為真：ARD ≈1.94% / 5 年、NNH≈52——距離「值得對整個 HCM 族群給抗生素預防」還缺兩步：預防有效性證據（缺）、以及鎖定真正高風險（阻塞型）表型的能力（本資料做不到）。

C. 統計與資料完整性

C1. 結果分類（觀察性關聯，改以偏差方向判讀）

  • 關聯統計上穩健（HR 2.62，CI 2.20–3.12，精度佳）——問題不在精度，而在偏差。
  • 綜合 B3：偵測偏差 ＋ 關鍵風險因子殘餘混淆 ＋ 競爭風險未校正，三者方向一致地使 HR 高估。因此真實因果 HR 很可能明顯低於 2.62，甚至部分為偽關聯。不做 MCID 分類（非療效試驗）。

C2 / C3. Winner's curse / Bayesian

  • 不適用（大樣本、非 underpowered、非療效試驗）。

C4. 報告完整性與其他統計問題

  • PH 假設自相矛盾：Schoenfeld p=0.003 表示 PH 被違反，作者卻稱「no meaningful violations」並照報單一 HR。搭配 KM 曲線（見下）呈近乎線性恆定發散，若 PH 真被違反，單一 HR 只是時間平均，解讀應保留。作者亦自承 HR 未必反映恆定因果效果。
  • person-years 粗估：cohort×median follow-up 假設均勻追蹤，EHR 中並不成立 → ~6.5/1000 PY 這個「高於 Spirito」的比較不可靠，不能當作「HCM 風險更高」的證據。
  • 統計面紅旗（≥5）：(1) 純碼結局無臨床佐證；(2) 偵測偏差未評估；(3) 關鍵 IE 風險因子配對失敗（SMD 0.20–0.39）被辯解掉；(4) 競爭風險未做；(5) PH 違反卻稱無違反；(6) 未做任何敏感度 / negative-control / E-value；(7) ICD 次組 CI「0.77–6.94% 圍繞點估計 6.3%」在數學上不合理（點估計幾乎等於上界），疑為計算或轉錄錯誤。

圖表判讀（page_002 Figure 1，解析度足以判讀）

  • Panel A（HCM 藍 vs 對照橘）：兩曲線於第一年內即分離並近乎線性穩定發散至 3.25% vs 1.31%；Y 軸自 0 起、上探 14% 留大量空白，未以截軸誇大（若有，反而是視覺上壓縮效果）。

  • 🚩 PH 假設 p=0.003 違反，卻自稱無違反。
  • 🚩 結局純 ICD 碼、無 Duke criteria；HCM 無法分阻塞 / 非阻塞，機轉與被測族群不匹配。
  • 🚩 ICD 次組 CI（0.77–6.94% vs 點估計 6.3%）數學上不合理，疑計算 / 轉錄錯誤。
  • 🚩 臨床倡議超出資料：由「關聯」跳到「重新分類 + 考慮抗生素預防」，缺預防有效性證據。
  • 🚩 核心方法（DAG、完整 baseline table）落在未經同儕審查、且本次未保留的 supplement。

F. 反向解釋

  1. 偵測偏差主導：HCM 端因密集心臟監測，IE 被「發現並編碼」的機率高於對照，關聯部分為人為。文內支持：對照 IE 1.3% 已偏高、HCM 端接觸密集；反對線索：作者稱一致編碼實務可部分緩解（但無法消除差異化偵測）。
  2. 殘餘混淆（AFib / 瓣膜 / IHD）：不平衡的共病本身驅動 IE，HCM 只是其標記。文內支持：SMD 0.20–0.39；反對：作者主張這些是 HCM 內在路徑（若真是中介，調整與否各有偏差，但仍非「HCM 直接致 IE」的乾淨證據）。
  3. 競爭風險假象：KM 在高死亡率下高估累積 IE。文內支持：12.4% 死亡、未做競爭風險、圖 at-risk 異常平緩。
  4. 關聯為真但僅限阻塞型：整體 HR 稀釋自阻塞型的高風險（與 Spirito 一致）。文內支持：機轉論述；反對：資料無法分型驗證。

G. 最終裁決

  • 整體可信度：低–中。「HCM 病人 IE 絕對風險並非可忽略、且高於一般門診族群」這一訊號方向可信；但 HR 2.62 的因果數值高度可疑（偵測偏差＋殘餘混淆＋競爭風險三者同向高估），不足以支撐指引層級的預防決策。
  • 可採用：作為病因學訊號與未來前瞻 / target-trial emulation 的假說來源。不建議採用於改變抗生素預防臨床決策。
  • 要改觀最需要的 3 項：(1) 對監測強度做量化偏差分析（如以就醫次數 / 影像次數為 negative-control 或納入 PS，並給 E-value）；(2) 用 Aalen-Johansen / Fine-Gray 處理死亡競爭風險，並報告真實 person-time 而非均勻假設；(3) 分出阻塞型 vs 非阻塞型、以血培養 / 影像佐證 IE 結局（提高結局效度）。
  • 一句話結論：這篇 TriNetX 研究提示 HCM 病人心內膜炎風險或許不容忽視，但因監測偏差與殘餘混淆，尚不足以據此改變抗生素預防的臨床決策。

因果推論 Appendix（觀察性因果宣稱）

  • Target trial 對照 [參考: hernanrobins_WhatIf_2jan25.md]：理想試驗應「隨機把等監測強度下的病人分到 HCM-like 暴露」——不可行，且關鍵在於本觀察研究無法讓兩組接受等同的 IE 偵測強度（differential ascertainment），這是 emulation 最大破口。
  • 三大可識別性條件
    • Exchangeability（無未測混淆）：不滿足。監測強度、牙科處置、留置導管 / 洗腎、免疫狀態等未測；已測的 AFib / 瓣膜 / IHD 甚至未被平衡。
    • Positivity：大致可接受（PS matching + caliper 已在共同支持區內配對）。
    • Consistency：「HCM 暴露」定義為首次編碼，非發病；「初診」起算引入 prevalent-diagnosis / 左截斷與潛在 lead-time 問題。
  • 時間變動混淆：追蹤期間新發 AFib、瓣膜手術、CIED 植入等 time-varying 因子未處理；本文為簡單 baseline 配對 Cox，不足以承載因果結論。
