3. 研究背景 [僅根據本篇文內資料]

既有事實：

  • 2026 ACC/AHA/multisociety 血脂指引以 PREVENT 方程式取代 Pooled Cohort Equations (PCE) 估計 10 年 ASCVD 風險 [文內, ref 1,2]。
  • 指引框架：borderline 風險「考慮」statin，intermediate/high 風險「建議」statin；當 borderline 或 intermediate 者在醫病討論後仍不確定，可用 CAC 進一步分層 [文內, ref 1]。
  • CAC 能顯著細化 ASCVD 風險評估，尤其在治療決策不確定時 [文內, ref 3 = Nasir 2015]。

知識缺口：既有 CAC 證據幾乎全在 PCE 時代產生；PREVENT 的風險刻度與治療門檻和 PCE 不同（PREVENT 系統性給出較低的預測風險），因此 CAC 在 PREVENT 框架下的角色「remains incompletely defined」[文內, Introduction]。

Research question [推論，依據 Introduction 末段 + Objectives]：在 2026 指引定義的 statin 適應性分組與 PREVENT 風險級距內，各 CAC 分層的實際觀察事件率落在何處？特別是：是否會跨越指引的治療門檻，因而改變治療歸類？

4. 研究設計與方法

PICO（預後研究改寫）：

  • P（Population）：MESA 世代，2000–2002 年自美國 6 個社區收案，45–84 歲、基線無臨床 ASCVD。本分析納入 n = 5,698（具備計算 10 年 PREVENT-ASCVD 與判定 statin 適應性所需完整基線資料者）。
  • I（Index / Exposure）：基線 CAC（分層：0 / 1–99 / ≥100；二分：0 vs >0）
  • C（Comparison / 分層變項）：2026 指引定義的 statin 適應性三組（not recommended / considered / recommended）；以及 10 年 PREVENT-ASCVD 風險四級（<3% / 3–<5% / 5–<10% / ≥10%，限 LDL-C 70–189 mg/dL 且無糖尿病者，n = 4,746）
  • O（Outcome）：Incident ASCVD 複合終點 = 心肌梗塞 + 復甦成功之心跳停止 + 中風（不含 TIA）+ 中風死亡 + 冠心病死亡；追蹤上限 10 年，經心臟科/流病/神經科醫師團隊 adjudication

Statin 適應性分組定義 [文內, Methods]：

  1. Recommended：LDL-C ≥190；或糖尿病；或 LDL-C 70–189 無糖尿病且 PREVENT ≥5%
  2. Considered：LDL-C 70–189 無糖尿病且 PREVENT 3–<5%
  3. Not recommended：LDL-C 70–189 無糖尿病且 PREVENT <3%；或 LDL-C <70 無糖尿病

關鍵測量細節：

  • CAC：electron-beam CT（Northwestern / UCLA / Columbia）或 multidetector ECG-triggered CT（Hopkins / Wake Forest / Minnesota）；phantom 校正；≥130 HU 跨 3 連續像素；中央判讀（Los Angeles Biomedical Research Institute）
  • LDL-C：Friedewald 公式（TG <400 mg/dL）
  • eGFR：MDRD 公式
  • 統計：Kaplan-Meier；未校正 Cox（proportional hazards 以 standardized score process plot + supremum test 檢驗，通過）；主模型含 CAC group、eligibility group 及其交互作用項；bootstrap CI 計算絕對風險差；敏感度分析（competing risk subdistribution hazard；納入基線已服 statin 者）；補充 Cox 納入連續 PREVENT + CAC group（Wald test）；calibration slope；categorical NRI

  • 無論方向為何，一個決定 15% 樣本去留、且明顯改變風險結構的排除條件未寫入 Methods，是實質的報告缺陷，且無流程圖可供讀者自行核對。

6. 作者討論與評論重點

作者主要訊息：

  1. CAC 在治療決策不確定時最有價值，尤其 borderline（PREVENT 3–<5%）族群——CAC 0 使觀察事件率降至治療門檻以下。
  2. 已達治療門檻者（PREVENT ≥5%），無論 CAC 有無，事件率均高於門檻 → CAC 0 不應用來停用 statin。
  3. 在高風險者，CAC 的角色從「重新分類」轉為「脈絡化絕對風險、決定預防強度」。
  4. 低風險（<3%）但 CAC ≥100 的小族群風險被 10 年估計低估 → 應考慮 30 年 PREVENT（引用自家 ref 6）。

與現有文獻：宣稱延伸 Nasir 2015（PCE 時代）至 PREVENT 時代 [文內, Discussion]。

作者自承限制 [文內]：(1) 基線資料為 2000–2002 年，可能不反映當代風險因子分布；(2) CAC 未對受試者/醫師盲化，可能影響後續預防照護並削弱觀察到的 CAC 相關風險；(3) MESA 是相對健康的初級預防世代，絕對事件率偏低；(4) 本文 ASCVD 終點定義對齊 PREVENT 推導/驗證框架，與 2026 指引較廣的臨床 ASCVD 定義不同；(5) statin recommended 組混合了臨床異質的次族群（LDL ≥190 / 糖尿病 / PREVENT ≥5%）；(6) 三分法是對指引 Calculate–Personalize–Reclassify–Reassess 框架的簡化，未納入 risk-enhancing factors、HIV、CKD stage 3–4 等特殊族群，可能造成錯誤分類。

[評估]：限制清單誠實且不流於形式——特別是主動承認 CAC 未盲化與分組簡化，值得肯定。但有四項應列而未列的缺漏：

  1. 未列：基線已服 statin 者（n=1,010）被排除（見第 4 節）。
  2. 未列：主要結論所依賴的信賴區間跨越決策門檻（見 C1）——限制清單完全沒有提到精確度問題。
  3. 未列：交互作用檢定（p=0.36、0.47）並不支持「CAC 在不同適應性組別價值不同」這個核心敘事（見 D）。
  4. 未列：複合終點中 40% 是中風，而 CAC 是冠狀動脈標記；「CAC 0 仍高於門檻」有相當部分可由此解釋（見 B4）。

臨床建議是否超出數據支持：部分超出。結論句「absence of CAC identified observed event rates below the threshold for statin initiation」在點估計層次為真，在統計推論層次未被支持（2.7 的 CI 上界 4.6 遠高於 3）。而「CAC 0 should not generally be used to withhold statin therapy in these individuals」則確實被數據支持（5.8 的 CI 下界 4.4，整段高於門檻）。兩者證據強度差異巨大，但 Abstract 與 Conclusions 以同等確信度並列陳述。

8. 臨床建議

可採用本研究結論的情境：

  1. PREVENT ≥5%（intermediate/high）且 CAC 0 的初級預防者——本研究提供了目前最直接的證據，說明此族群的 10 年觀察事件率（5.8/1,000 py，CI 4.4–7.6，全區間高於門檻）仍明確高於治療門檻。不要因為 CAC = 0 就不開 statin。 這是本文最紮實、也最可直接執行的結論。
  2. PREVENT <3%、外表低風險但 CAC ≥100 者——事件率 11.3/1,000 py，明確超過門檻。可作為與病人討論「10 年風險估計低估了你」的量化依據。但請注意此族群極小（僅佔 not recommended 組的 5.4%、全世代的 1.8%，且僅基於 10 個事件），不足以支持對低風險族群普篩 CAC。
  3. 50–70 歲、無糖尿病、LDL-C 70–189 mg/dL、以 PREVENT 評估的美國多族裔門診族群——與 MESA 收案條件最接近。

不建議直接套用的情境：

  • 已在服用 statin 者：這群人（n=1,010）被排除於主要分析之外，本文所有事件率都不適用於他們。
  • PREVENT 3–<5%（borderline）且 CAC 0 者的「停藥/延後」決策：這是本文的頭條主張，但也是證據最弱的一項（詳見 C1、D）。可作為醫病討論的參考素材，不應作為系統性延後治療的政策依據。
  • 女性 borderline 族群：作者自承「absence of CAC lowered risk below the threshold only in men」（Supplemental Table 5，markdown 未保留內容）。borderline 組有 51.1% 是女性（458/897），意即本文頭條主張在超過一半的目標族群中可能不成立。
  • 年輕族群（<45 歲）、非美國族裔結構、其他 CKM 風險結構（如高 UACR、高 HbA1c）：本文使用的是 PREVENT 基本模型（age、sex、TC、HDL-C、SBP、eGFR、DM、smoking、antihypertensive），未納入 UACR / HbA1c / SDI 的完整 CKM 版本。
  • 以中風預防為主要考量者：CAC 是冠狀動脈鈣化標記，對本文複合終點中 40% 的中風事件不具直接對應性。

給臨床醫師的 3 點實務建議：

  1. CAC = 0 在 PREVENT ≥5% 的病人身上，不是停藥的理由，尤其若對方年齡偏高（本組平均 68.5 歲）或考量中風風險。此點證據明確。
  2. 在 PREVENT 3–<5% 且 CAC = 0 的病人，可以把 CAC 當作醫病共享決策的溝通工具，但不要當作二分開關。 誠實的說法是：「這群人的 10 年事件率大約 2.7/1,000 人年，但統計上的合理範圍是 1.6 到 4.6——可能低於也可能高於決策門檻。」而不是「你在門檻以下，不用吃藥。」
  3. 不要對 PREVENT <3% 的低風險者常規安排 CAC。 依本文數據，需要掃描約 19 人才能找到 1 位 CAC ≥100 而需上調治療者（103/1,924 = 5.4%），且該判斷僅奠基於 10 個事件。

「未校正 HR」的判讀 —— 這一項不是缺陷，而是設計選擇：

本文目標是預後分層（CAC 帶來多少額外的預測訊號），不是估計 CAC 的因果效果。對預後目的而言，unadjusted association 正是想要的量（你要的是總預測訊號，不是去除混淆後的獨立效果）。作者也明言「the main purpose of the analysis was not to develop a prediction model」[文內]。因此 unadjusted HR 在此是合理的，不應以「未校正混淆」批判之。

但由此衍生一個作者未處理的推論界線：正因為這些 HR 是未校正的關聯量，它們不能被詮釋為治療決策的效果依據。JAMA Users' Guide 對此有明確論述——觀察性研究中被比較的群體必然存在預後不平衡（prognostic imbalance），任何校正策略（包括不校正）都無法排除 residual confounding，因此觀察性估計不可替代隨機化提供的預後平衡 [參考: jama_agoritsas_2017_ug_160001.md — "The Challenge of Prognostic Imbalance" 節；該節以抗氧化補充劑為例，說明觀察性世代中「使用者本來就比較健康」如何製造完全虛假的保護效應]。本文從未校正的事件率跳到「should not be used to withhold statin therapy」的處置建議，正是跨越了這條界線。

Time-varying confounding：本文最實質的未處理偏差

CAC 對受試者與醫師未盲化（作者自承）。這在追蹤期間製造了一條系統性的、由 CAC 決定的處置路徑：

基線 CAC >0 → 醫師/病人得知 → 追蹤期間更可能開始 statin → 事件率被壓低
基線 CAC = 0 → 「power of zero」的心理效應 → 更可能不開/停用 statin → 事件率被推高

這是典型的 treatment paradox（也可視為 time-varying treatment 被基線暴露所影響的中介偏差結構）。正確的處理是 marginal structural model 或 g-formula，本文完全未做，也未提供追蹤期間各 CAC 層 statin 使用率的描述性資料。

方向性分析（作者只做了一半）：

  • 對 CAC >0 vs CAC 0 的對比：兩個方向都使對比被低估（bias toward the null）。作者正確指出了這一半——「may have... attenuated the observed risk associated with CAC」。
  • 對 「recommended + CAC 0 = 5.8/1,000 py」這個絕對數字：CAC 0 者可能被系統性地少治療，使該數字被高估。而這個數字正是「不要因 CAC 0 停藥」結論的唯一支柱。作者完全未討論此不對稱性。

[評估]：CAC 未盲化同時強化了本文兩項主要結論——它讓 borderline+CAC 0 那格看起來更安全（因為那些人本來就更少被治療？不，反向：更少治療應推高其事件率，所以此處偏差不利於作者），也讓 recommended+CAC 0 那格看起來更危險。整體而言，未盲化對「不要停藥」的結論方向不利於作者卻仍得出陽性結果，反而增強該結論的穩健性；對「可延後治療」的結論則方向難以確定。這個細緻的方向差異，作者一句都沒有處理。

  • Temporality：✅ CAC 於基線測量，事件於後續 10 年發生，時序清楚。
  • Positivity：✅ 各 CAC × eligibility 格位皆有觀察值（最小 n=103），無結構性 positivity violation，但 n=103/114 的格位屬隨機性 positivity 稀疏，估計極不穩定。
  • Consistency：「Statin」的版本未定義（強度、藥物、劑量、依從性），追蹤期間亦未測量。

B. 批判性評估

B1. 假說與理論邏輯

❶ 決策規則存在尺度錯配（scale mismatch），且作者從未言明

問題：本文的整套論證是「將**觀察到的事件率（per 1,000 person-years）與指引的預測風險門檻（10 年 3%）**相比較」。Figure 3 的判準線就是「3 per 1,000 person-years」，圖說明白寫著「The threshold for statin consideration (blue dotted line) is at an ASCVD event rate of 3 per 1,000 person-years」[圖頁 page_007, Figure 3 caption]。

文內證據：指引門檻是 10 年 PREVENT-ASCVD 預測風險 ≥3% [文內, Methods]；本文將其換算為 3/1,000 py 使用。

風險方向：此換算隱含三個假設，皆未陳述：(i) 危險率在 10 年間為常數；(ii) 無檢查/競爭死亡導致的 censoring 效應（但 Figure 2C 顯示 9 年時已流失 19–36%）；(iii) 群體平均觀察率可代換為個體預測風險。第 (iii) 點最關鍵：指引門檻是給個別病人用的預測值，本文卻拿群體平均去比。在「considered + CAC 0」這 520 人中，個體 PREVENT 風險橫跨 3.0% 到 4.99%，加上 CAC 0 的下修，個體風險散布極廣——用一個群體平均去代表所有人，本身就是生態謬誤的一種形式。

需要什麼才放心：直接報告該格位的10 年累積發生率（作者其實算了，見 Supplemental Table 3，但 markdown 未保留）與其 CI，並與 3% 直接比較；或報告該格位內個體預測風險的分布。

❷ 門檻幾何學的循環性（最根本的邏輯問題）

問題：「considered」組的定義就是 PREVENT 3–<5%，也就是說，這群人的預測風險依定義橫跨 3% 這條線的上方。當你用任何與風險相關的變項去切分這個區間，在數學上幾乎必然產生「一半落在 3 以下、一半落在 3 以上」的結果。CAC 並不特別——年齡、SBP、吸菸、eGFR 中的任何一個都會產生類似的圖像。

文內證據：Central Illustration 明白呈現此結構：3–<5% 組 CAC 0 為 2.7、CAC >0 為 5.2，正好跨立於 3 的兩側 [圖頁 page_009]。

風險方向：使 CAC 看起來具備獨特的決策價值，實則部分是分層變項定義所產生的機械性結果（regression to the threshold）。

需要什麼才放心：以其他等強度的風險標記（例如 hs-CRP、Lp(a)、或單純的年齡中位數切分）做相同的門檻跨越分析作為 negative control。若年齡二分也能讓 borderline 組跨立門檻兩側，則 CAC 的「決策價值」宣稱需大幅打折。

❸ 從預後量跳到處置建議，橋接假設從未言明

問題：結論句「CAC 0 should not generally be used to withhold statin therapy」與「supporting the use of CAC to help withhold or defer statin therapy」都是治療決策主張。要從事件率推到治療決策，必須假設 statin 的相對風險下降率在所有 CAC 層一致（CTT 的假設），如此絕對獲益才會與基線絕對風險成正比。

文內證據：全文（Methods / Results / Discussion / Conclusions）未出現任何一句關於 statin 效果、RRR、NNT 或預期絕對獲益的陳述。

風險方向：讓讀者誤以為本研究提供了關於「治療與否」的證據，實際上它只提供了「風險有多高」的證據。更正確的決策框架應是預期絕對獲益 vs 傷害（近期同期刊即有 AHA/ACC 的 "Use of Predicted Risk and Expected Benefit" 科學聲明處理此議題 [外部: JACC 2026, DOI 10.1016/j.jacc.2026.05.007]），而非單純的風險門檻跨越。

需要什麼才放心：明言此橋接假設；並將事件率乘以合理 RRR（如 CTT 的每 mmol/L LDL-C 下降約 22% RRR）呈現預期絕對獲益，讓讀者看見在 2.7 vs 5.2/1,000 py 之間，10 年 NNT 的差異究竟是多少。

最可能合理的機轉（1–3 點）：

  1. CAC 直接影像化冠狀動脈粥狀硬化負擔，捕捉的是「累積終生暴露的整合結果」，而 PREVENT 只捕捉「當下的風險因子橫斷面」——兩者訊息在生物學上確實互補。此為 CAC 增量價值的紮實機轉基礎，Wald test（p<0.001）也支持。
  2. CAC = 0 在年長者身上訊息量更大（68.5 歲仍無鈣化，代表真正的低終生暴露），因此「recommended + CAC 0」若真的仍高於門檻，可能反映的是複合終點的非冠狀動脈成分（見 B4），而非 CAC 0 的訊息失效。
  3. CAC ≥100 在低預測風險者身上識別出的是「風險因子驅動模型看不見的個體」（基因、發炎、Lp(a)、未測量暴露），這與 30 年風險論述一致。

最可疑的敘事跳躍（1–3 點）：

  1. Abstract 的「CAC provided its greatest clinical value when statin treatment decisions were uncertain」——這是一個效果修飾（effect modification）主張，但作者自己報告的交互作用檢定（binary CAC × eligibility p=0.36；binary CAC × PREVENT category p=0.47）明確不支持它。此句與該數據直接矛盾（詳見 D）。
  2. 「absence of CAC identified observed 10-year ASCVD event rates below the threshold」——把一個 CI 為 1.6–4.6 的點估計描述為確定跨越門檻。
  3. Discussion 引用自家 ref 6 支持「30 年風險」論述，但本文並未分析 30 年 PREVENT。這是把他處的證據移植進來，讓本文的結論看起來比實際更完整。

B2. 受試者與外推性

問題：Statin 適應性三組在很大程度上其實是年齡三組。

文內證據：平均年齡 52.4 / 59.0 / 68.5 歲 [文內, Table 1]。PREVENT 與 PCE 一樣高度受年齡驅動；CAC 盛行率同樣高度受年齡驅動（22.6% / 41.7% / 64.9%，與年齡梯度平行）。

風險方向：「CAC 在不同適應性組別的價值不同」的觀察，有相當部分其實是「CAC 在不同年齡層的意義不同」。CAC = 0 在 52 歲與在 68 歲是完全不同的臨床訊息（前者可能只是「還沒開始鈣化」，後者是真正的低終生暴露）。作者從未在組內按年齡再分層，也未報告年齡校正後的結果。這使得跨組比較的詮釋高度受年齡結構污染。

需要什麼才放心：在各 eligibility 組內按年齡（如 <60 / ≥60）再分層報告 CAC 的事件率梯度；或至少報告年齡校正 HR 與未校正 HR 的對比。

其他外推性議題：

  • 收案年代：2000–2002 年收案，10 年追蹤約涵蓋 2000–2012。這段期間大致落在高強度 statin 普及前、ezetimibe/PCSK9 抑制劑之前。當代同等風險族群的背景治療更積極，實際事件率應更低，因此本文的絕對事件率相對於當代族群可能系統性偏高——這個方向對「不要停藥」的結論不利，卻仍得出陽性結果（增強穩健性）；但對「borderline + CAC 0 可延後」的結論則意味著當代該格位事件率可能更低（有利於作者）。作者僅泛泛提及「may not fully reflect current population-level risk factor distributions」，未分析方向。
  • PREVENT 版本：本文使用基本模型（age、sex、TC、HDL-C、SBP、eGFR、DM、smoking、antihypertensive medication）。PREVENT 的設計特色是納入 CKM 健康（UACR、HbA1c、SDI），本文未使用完整版。若使用完整版，部分人會重新分類，CAC 的增量價值可能改變——未檢驗。
  • 統計分組簡化：作者自承未納入 risk-enhancing factors、HIV、CKD 3–4 期。實務上，2026 指引的 Calculate–Personalize–Reclassify–Reassess 框架比本文的三分法複雜得多，因此本文的「statin considered」組不等於臨床上真正會落入決策不確定區的病人。

B4. 測量工具與實務意義

測量信度：CAC 以 phantom 校正、中央判讀（Los Angeles Biomedical Research Institute）、標準化 Agatston 方法（≥130 HU、3 連續像素）[文內]。這是 CAC 測量的黃金標準流程，信度佳。但未報告 inter-reader / intra-reader reliability 或 scan-rescan 變異度，而 CAC 的 scan-rescan 變異在低分數區間（正是本文最關鍵的 CAC 1–99 區間）可達 20–30%。此外，本世代混用 electron-beam CT 與 multidetector CT 兩種機型，且與研究中心綁定（Northwestern/UCLA/Columbia 用 EBCT；Hopkins/Wake Forest/Minnesota 用 MDCT），造成機型與中心/族群結構混淆，未做機型敏感度分析。

終點是否有臨床意義：ASCVD 複合終點（MI、復甦成功之心跳停止、中風、中風死亡、冠心病死亡）全部是硬終點，且經多科團隊 adjudication——這是本研究的實質優點，優於許多使用 surrogate 或行政資料庫代碼的分析。

⚠️ 複合終點中 40% 是中風，而 CAC 是冠狀動脈標記 —— 本文最重要的未分析議題

文內證據：374 個事件中，MI 166 (44%)、中風 149 (40%)、CHD death 48 (13%)、復甦心跳停止 11 (3%)[文內, Results]。

問題：CAC 測量的是冠狀動脈鈣化。它對中風的預測能力遠弱於對冠狀動脈事件的預測能力。當複合終點有 40% 是中風時，「CAC 0 仍無法把事件率降到門檻以下」這個結果有相當部分是可預期的、且與 CAC 的訊息量無關——CAC 0 本來就不應該被期待可以排除中風風險。

為何這關鍵：這正是本文最強結論（「recommended + CAC 0 = 5.8/1,000 py，不應停藥」）的另一種完整解釋。若把終點限縮為冠狀動脈事件（MI + CHD death + 心跳停止 = 225/374 = 60%），該格位的事件率可能會降到 約 3.5/1,000 py（若中風在 CAC 0 者中佔比更高，甚至可能更低）——非常接近甚至可能低於門檻。

作者做了什麼：完全沒有按終點成分拆解 CAC 分層的事件率。全文未出現任何按 MI / 中風分開呈現的分析，連 Supplemental 都未提及。這是一個會實質改變臨床詮釋的分析缺口，而非枝節。

需要什麼才放心：按 CAC 層報告冠狀動脈事件 vs 中風事件的分別事件率。這是用現有資料就能做、成本為零、卻缺席的分析。

「就算結果完全是真的，真實世界能有多大用處？」

以本文自己的數字計算：

  • borderline 族群（n=897，佔世代 15.7%）：若採用「CAC 0 → 延後 statin」，需對 897 人全數掃描，其中 520 人（58%）CAC 0 可延後。這 520 人 10 年間發生 13 個事件（2.5%）。若 statin 能降低約 25% 相對風險，延後治療 10 年約多出 3.25 個事件——換言之，每掃描 897 人以避免 520 人服藥 10 年，代價約為 3 個 ASCVD 事件。這個 trade-off 是否值得，取決於病人對服藥的重視程度、掃描成本與輻射，本文完全未量化。
  • 低風險族群（n=1,924）上調治療：需掃描約 19 人才找到 1 位 CAC ≥100（103/1,924 = 5.4%）。而該次族群的整個證據基礎是 10 個事件。
  • CAC ≥100 者中已被建議 statin 的比例：82.2% [圖頁 page_005, Figure 1A]。也就是說，CAC ≥100 的人裡有超過八成，不用做 CAC 也已經被指引建議用藥。這個數字（來自 Figure 1，正文未強調）是對 CAC 常規檢查臨床產出的最直接量化——CAC 在多數人身上不會改變處置。

C3. Bayesian 補充分析（適用性判定）

本研究無治療對比、無 p ≈ 0.05 的假設檢定爭議，因此 Zampieri 式的三 prior 框架（Pr(benefit) / Pr(ROPE) / Pr(harm)）不直接適用。

但頭條主張確實是一個可用 Bayesian 語言精確表述的問題，而作者從未如此表述：

給定觀察到 13 個事件、事件率 2.7 (1.6–4.6)/1,000 py，「真實事件率低於 3/1,000 py」的機率是多少？

以 Poisson 近似（13 事件；person-time ≈ 13/2.7×1,000 ≈ 4,815 py）搭配無資訊 prior 粗略推算，Pr(rate < 3) 約為 0.6–0.7（推算，非文內數據；標註 [推算]）。也就是說，即使完全接受本文數據，「borderline + CAC 0 真的在門檻以下」的把握大約只有六到七成——遠不足以支撐 Central Illustration 上那個綠燈。

作者只需計算並報告這一個數字，就能把整篇論文的誠實度提升一個層級。他們沒有做。

  且三組分解無法對上。                                            ✗

結論：Table 2 標頭的 2,799 是排版/報告錯誤，正確值應為 2,860，誤差 61 人。

D. 次組分析評估

本文的分層本身即是主要分析，但**「CAC 在不同組別價值不同」是一個效果修飾（次組）主張**，故適用 JAMA 五項次組可信度準則。以下逐條檢驗本文的核心次組主張。

主張：「CAC provided its greatest clinical value when statin treatment decisions were uncertain, particularly among individuals with borderline predicted risk.」（Abstract Conclusions）

# JAMA 準則 本文表現
1 是否有交互作用 p 值？ ✅ 有報告，但結果與主張相反：binary CAC × eligibility p = 0.36；binary CAC × PREVENT category p = 0.47；3-category CAC × eligibility p = 0.047。兩個二分交互作用皆明確不顯著，唯一勉強顯著者是三分類交互作用，且 p=0.047 在未校正的多重檢定家族中屬邊緣。
2 方向是否與其他研究一致？ ⚠️ 部分不一致。Nasir 2015（PCE 時代，同一世代，本文 ref 3）呈現的是 CAC 在所有風險層皆有分層效果的一致模式。本文若真的發現 CAC 的價值在 borderline 組特別大，那是新主張；但實際上，本文自己的 HR 顯示 borderline 組的 CAC 效果最弱（2.0, CI 1.0–4.0），與主張方向相反。
3 假說是否事前指定並有預期方向？ ⚠️ 形式上事前（Objectives 即為「evaluate event rates across CAC strata within statin eligibility groups」），但那是描述性目標，不是效果修飾假說。「CAC 在 borderline 組最有價值」的結論性方向是在看到資料後形成的。無 protocol、無 pre-registration（本文未提及任何分析計畫預先註冊）。
4 是否有合理的生物機轉？ ⚠️ 有，但機轉支持的是另一個結論。「CAC 在預測風險接近門檻時最能改變分類」是決策幾何學的性質，不是生物學性質。生物學上，CAC 在任何風險層都提供同一種訊息（累積動脈粥狀硬化負擔）——這恰恰是為什麼交互作用不顯著。作者把一個門檻幾何現象包裝成 CAC 的生物特性。
5 是否為 within-study 比較？ ✅ 是（同一世代內分層），此項無問題。

可信度評分：低（推測性）

這是本次評讀最重要的單一發現：作者所報告的交互作用檢定主動否證了其 Abstract 與結論的核心敘事。CAC 的相對分層能力在三個 statin 適應性組別之間沒有統計上可辨識的差異（p = 0.36），在四個 PREVENT 風險級距之間也沒有（p = 0.47）。

真正在變動的，不是 CAC 的效能，而是每一組的基準事件率相對於那條固定的 3/1,000 py 決策線落在哪裡。這是一個關於門檻位置的觀察，不是關於 CAC 效能的觀察。

應該怎麼寫才誠實：「CAC 在所有 statin 適應性組別中皆提供一致的相對風險分層（交互作用 p = 0.36）；由於 borderline 組的基準風險正好座落於決策門檻附近，CAC 分層在該組最可能改變分類歸屬，儘管其相對分層強度並不優於其他組別。」

另一項次組分析（性別）：

  • 「In the statin considered group, absence of CAC lowered risk below the threshold for statin initiation only in men; however, this analysis was exploratory and limited by low events」[文內, Supplemental Table 5]
  • 五項準則檢核：(1) 未報告性別交互作用 p 值；(2) 與其他研究方向：女性 CAC 發展較晚、中風佔比較高，CAC 0 在女性的陰性預測值理應較弱——與觀察方向一致；(3) 事後、無預期方向；(4) 有生物機轉；(5) within-study ✅。

F. 反向解釋

替代解釋 1：門檻幾何學假象（regression to the threshold）

CAC 之所以「在 borderline 組最有決策價值」，可能純粹是因為 borderline 組的定義（PREVENT 3–<5%）使其平均風險正好座落於決策門檻（3%）之上一點點。用任何與風險相關的變項去切分這個窄帶，都會機械性地產生「一半落在門檻下、一半落在門檻上」。

  • 文內支持：交互作用 p = 0.36 / 0.47（CAC 的相對效能在各組無差異）；Central Illustration 顯示 3–<5% 組的兩格（2.7 / 5.2）正好跨立於 3 的兩側 [圖頁 page_009]。
  • 文內反對：Wald test 顯示 CAC group 在校正連續 PREVENT 後仍顯著（p<0.001），證明 CAC 帶有 PREVENT 以外的獨立訊息——但這證明的是「CAC 有增量訊息」（無爭議），不是「CAC 在 borderline 組特別有用」。
  • 判定：此替代解釋的證據強度不亞於作者的解釋。

替代解釋 2：中風污染了複合終點，造成「CAC 0 仍高風險」的假象

「recommended + CAC 0 = 5.8/1,000 py」之所以高於門檻，可能有相當比例是因為複合終點中 40% 是中風，而 CAC 對中風的預測力遠弱於對冠狀動脈事件。

  • 文內支持：149/374 (40%) 事件為中風 [文內]；statin recommended 組平均 68.5 歲、SBP 135.0 mm Hg、22% 糖尿病、46.9% 使用降壓藥——這是一個中風風險極高的族群。
  • 文內反對：無。作者完全未做終點成分拆解，因此無法排除此解釋。
  • 判定：這是對本文最強結論的一個嚴肅且未被排除的替代解釋。若成立，「CAC 0 不應停藥」的正確理由不是「CAC 0 不夠可靠」，而是「你在用冠狀動脈標記去排除一個 40% 為腦血管的複合終點」——這兩者的臨床意涵完全不同（後者暗示應同時評估中風風險因子，而非單純繼續開 statin）。

替代解釋 3：CAC 未盲化造成的處置反饋，同時製造了兩個方向的假象

CAC >0 者在追蹤期間更可能開始服藥 → 其事件率被壓低；CAC 0 者受「power of zero」影響更可能不服藥 → 其事件率被推高。

  • 文內支持：作者自承 CAC 未盲化；MESA 為社區世代，參與者確實收到 CAC 結果。
  • 文內反對：若此機制強烈，CAC 的分層效果應被削弱；但觀察到的 HR 仍達 2.0–3.8，代表真實效果只會更大（對 CAC 有效性的結論而言是保守的）。
  • 判定：對「CAC 有效」的結論不構成威脅（方向保守）；但對「recommended + CAC 0 = 5.8」這個具體數字構成向上偏差的威脅，而該數字正是「不要停藥」結論的唯一支柱。作者只討論了前半，未討論後半。

替代解釋 4：年齡結構驅動，而非 CAC 驅動

Statin 適應性三組本質上是年齡三組（52.4 / 59.0 / 68.5 歲）。CAC 0 在 68 歲與在 52 歲的預後意義完全不同。

  • 文內支持：年齡梯度與 CAC 盛行率梯度（22.6% / 41.7% / 64.9%）完全平行 [文內, Table 1]。
  • 文內反對：分層設計本身已縮小組內年齡變異；且 Wald test 顯示 CAC 在校正連續 PREVENT（其中已含年齡）後仍獨立顯著。
  • 判定：不威脅「CAC 有增量價值」的結論，但威脅「跨組比較 CAC 價值」的乾淨性。

G. 最終裁決

整體可信度：中

理由：資料來源與終點品質是一流的（MESA、adjudicated 硬終點、標準化中央判讀 CAC、追蹤損失 0.4%、無產業資助、主動檢驗 PH 假設）。統計執行大致稱職且做了適切的敏感度分析。扣分不在資料，而在推論的紀律——(i) 頭條主張的 CI 跨越決策門檻卻被以確定語氣書寫；(ii) 作者自己報告的交互作用檢定否證了核心敘事，卻未進入 Abstract 或 Limitations；(iii) 一個 15% 樣本的關鍵排除未寫入 Methods 且無流程圖；(iv) Central Illustration 的顏色編碼傳達了數據不支持的確定性；(v) 一個可由圖表交叉核對發現的算術錯誤存活到最終出版；(vi) 團隊結構（指引第一作者 + 前作原作者 + 世代擁有者）與結論方向高度耦合。

可採用的條件：

  • 用於支持「PREVENT ≥5% 的初級預防者不應因 CAC 0 而不給 statin」——這是本文唯一在統計推論層次紮實的結論（CI 4.4–7.6，全區間高於門檻，53 個事件）。
  • 用於支持「CAC 在 PREVENT 框架下仍提供 PREVENT 以外的獨立預後訊息」（Wald p<0.001，且 CAC 梯度在所有組別一致）。
  • 用於醫病共享決策時的風險溝通素材（附上 CI，而非只給點估計）。

不建議採用的情境：

  • 不要把「borderline + CAC 0 → 延後 statin」當作系統性政策依據。統計推論不支持（13 事件、CI 跨門檻），且作者自承可能只在男性成立。
  • 不要引用「CAC 在治療決策不確定時價值最大」作為 CAC 效果修飾的證據——作者自己的交互作用檢定（p=0.36 / 0.47）不支持。
  • 不要單獨引用 Central Illustration 的顏色編碼或 CAC ≥100 次族群的點估計（HR 9.5）——前者過度精確化，後者有 Type M error 風險（應引用 CI 下界 4.4）。
  • 不要外推至已服 statin 者、女性 borderline 族群、<45 歲、或以中風預防為主要考量者。
  • 不要外推至台灣族群而不加保留：PREVENT 未經本地驗證，且中風在東亞佔 ASCVD 事件比例更高，會進一步削弱 CAC 的分層能力。

最需要的 3 個關鍵改進（若要改觀）：

  1. 按終點成分拆解：分別報告各 CAC 層的冠狀動脈事件率（MI + CHD death + 心跳停止）與中風事件率。這用現有資料就能做、成本為零，卻可能實質改變主要結論的詮釋——若冠狀動脈事件在 recommended + CAC 0 組確實落至門檻附近，整篇論文的臨床訊息就要重寫。
  2. 誠實呈現決策不確定性：報告「該格位真實事件率低於 3/1,000 py 的機率」（Bayesian 或 bootstrap 皆可），並在 Central Illustration 上呈現 CI 而非二分顏色；同時把交互作用檢定結果（p=0.36 / 0.47）與其對核心敘事的意涵寫進 Abstract 與 Limitations。
  3. 獨立世代複製 + 完整報告：在 CARDIA、Rotterdam、DHS 或 CAC Consortium 等獨立世代中重複，最好由非指引撰寫團隊執行；同時補上 participant flow diagram（明確標示 1,010 位基線 statin 使用者的排除）、C-statistic 變化與 decision curve analysis。

一句話結論（給一般讀者）：

這篇 MESA 分析可靠地說明「心臟鈣化分數 0 不足以讓已達治療標準的人停用 statin」，但它宣稱「邊緣風險加上鈣化 0 就能不吃藥」的部分，數據其實還不夠確定。
