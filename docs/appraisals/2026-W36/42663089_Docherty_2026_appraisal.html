3. 研究背景 [僅根據本篇文內資料]

既有事實：人口老化與糖尿病、肥胖、慢性腎病盛行率上升，社區新發心衰竭疑似個案將持續增加；心臟超音波量能已飽和、等待時間長（引 NHS England 診斷等待報告）。診斷延誤導致更多病人以「住院」作為首次心衰竭診斷，而住院診斷的成本與死亡風險均高於社區診斷。

知識缺口：現行指引建議以利鈉肽濃度作為 rule-out 測試以決定是否轉介心臟超音波，但 NT-proBNP 濃度會受年齡、族裔、腎功能、心律（心房顫動）、BMI 等因素影響，且現行的各種「特徵校正閾值」都把 NT-proBNP 當作類別變項處理，且每次只校正一個臨床特徵。院內急性心衰竭情境已有 CoDE-HF 工具證明多變項個人化機率法優於單一閾值（ref 19），但社區/門診情境（pre-test probability 與臨床脈絡皆不同）尚無對應工具。

Research question：在社區疑似新發心衰竭且測量 NT-proBNP 的成人中，將 NT-proBNP 以連續變項形式結合多項常規可得臨床特徵所產生的個人化機率，能否較 ESC 固定 rule-out 閾值與 HFA 年齡校正 rule-in 閾值提供更好的診斷表現？[文內: Graphical Abstract "Key Question" 明確陳述]

關鍵設計細節

  • 設計類型：回溯性世代研究，以電子病歷資料庫進行診斷模型開發與驗證（CPRD Aurum 12/2025 build + HES linkage，涵蓋約 24% 英國人口）。
  • 候選模型：GLM、LASSO glmnet、Random Forest（以上三者用完整個案分析）、XGBoost（完整個案版與全資料集版）。最終選用 XGBoost 全資料集版（利用 XGBoost 原生缺值處理，不做任何插補）。
  • 變項選擇：a priori 指定 13 項（NT-proBNP 連續變項 + 年齡、性別、族裔、BMI、eGFR、收縮壓、貧血、AF 病史、糖尿病、心肌梗塞、COPD、迴圈利尿劑處方），非資料驅動篩選。
  • 缺值：BMI 43.0%、收縮壓 13.8%、族裔 3.8%、血紅素 3.8%、eGFR 1.7%；46.4% 的參與者至少有一項預測變項缺失。
  • 驗證策略：隨機切分（derivation n=374,909 / internal validation n=160,674，70:30）；外部驗證為瑞典 REVOLUTION-HF 世代（n=4,492），直接套用模型係數與閾值、不重新校準。
  • 閾值訂定：rule-out 取 sensitivity ≥90%（對應預測機率 4.7%）；rule-in 取 specificity ≥90%（對應預測機率 21.6%）。
  • 樣本量：以 Riley 等人的 pmsampsize（17 個候選參數、預期 C-statistic 0.75、outcome prevalence 10%）計算最小需求 1,965 人 / 197 事件；實際遠超。作者自承此計算對無固定迴歸係數的 XGBoost 只是近似。
  • 軟體：R 4.5.1，xgboost 3.2.1.1。
  • 重要的排除規則：追蹤未滿 12 個月者，以及 12 個月內死亡但無心衰竭診斷紀錄且無心臟超音波紀錄者，均被排除（作者理由為避免錯誤分類）。

6. 作者討論與評論重點

作者主要訊息：PRECISE-HF（13 變項與 6 變項版本）較現行 NT-proBNP 閾值有「favourable」診斷表現；rule-out 可減少 29% 不必要的心臟超音波（代價為每 1000 人多漏 3 例），rule-in 可減少 34% 的 rule-in 轉介量並把 PPV 從 32.8% 提升到 44.1%；模型同時具預後分層能力（grey zone 7 倍、rule-in 40 倍風險）；因此可用於優先排序心臟超音波，加速確診與疾病修飾治療的啟動。

與現有文獻的關係：作者定位本文為 CoDE-HF（急性住院情境）概念向社區/門診情境的延伸，並明確指出既有的各種特徵校正閾值的兩大限制——把 NT-proBNP 當類別變項、一次只校正一個特徵。

作者自陳的限制（文內逐條）：① 回溯性、依賴診斷碼而非標準化定義，未經專家前瞻性判定；② 英國實務使用 400 pg/mL 作為轉介門檻，低於此值者較不會被轉介、較不會被診斷，可能造成 verification bias 並虛高 rule-out sensitivity（作者辯稱本世代中 400 pg/mL 的 sensitivity 為 80%，顯示相當比例低於此值者仍被確診）；③ 外部驗證缺乏 NT-proBNP <300 pg/mL 的病人；④ 無 LVEF 表型或心臟超音波資料；⑤ AF 校正是以「病史」而非測量當下心律；⑥ 未掌握 NT-proBNP 檢驗方法（assay）差異；⑦ 變項為 a priori 選定，其他變項可能改善表現；⑧ PPV/NPV 隨盛行率而異；⑨ 無法推論在無症狀 Stage B 篩檢情境的表現；⑩ 未收集會造成 NT-proBNP 上升的替代診斷（顯著瓣膜疾病、新發 AF 等）。作者亦在 Discussion 中明確表示臨床採用前應以隨機對照試驗前瞻性檢驗其效能、安全性與成本效益。

[評估] 對作者解釋的判讀

作者的限制清單是相當完整且誠實的——尤其主動點出 verification bias、缺乏獨立判定、外部驗證缺低值區段、以及必須經 RCT 檢驗，這在同類 EHR 模型論文中屬於高標準。但仍有三處避重就輕：

  1. 對 verification bias 的辯護不成立。 作者以「400 pg/mL 閾值在本世代的 sensitivity 為 80%，故仍有相當比例低值者被確診」來淡化此偏差。但這個數字本身就受同一個偏差污染——它是在同一組（受轉介行為影響而形成的）reference standard 上計算的。用被污染的參考標準去證明污染不嚴重，是循環論證。

  2. 對外部驗證失敗的描述過度樂觀。 原文稱瑞典資料「reassuring without any need for recalibration」。實際上 rule-in specificity 從 90.0% 崩到 55.5%（見 D 段量化分析），而 rule-out 閾值在該世代根本無法被檢驗。這不是「不需要重新校準」，而是「無法判斷是否需要」。

  3. 對漏診者風險的陳述超出數據支持。 Discussion 稱多漏的 3 例心衰竭「at a low risk of adverse outcomes」。此推論來自整個 ruled-out 組的平均事件率（1.1/100 人年），而非那 10 位（每 1000 人中）實際被漏掉的心衰竭患者的個別結局。被漏掉的心衰竭病人本身的預後從未被報告。這是一個明確的「宣稱超出證據」之處。

另需指出摘要與正文的宣稱強度不一致：Abstract Conclusions 用 "superior diagnostic performance"，而正文 Conclusions 與 Graphical Abstract 都用 "favourable diagnostic performance"。摘要是多數臨床醫師唯一會讀的部分，卻使用了正文作者自己不願意使用的最強措辭。

8. 臨床建議

可考慮採用本研究結論的情境

  • 醫療體系層級的心臟超音波量能配置與優先排序決策，且該體系的臨床路徑與英國 NHS 高度相似（基層醫師開立 NT-proBNP、需排隊等候心臟超音波、等候時間以週至月計）。
  • 作為風險溝通與分流的輔助：把 PRECISE-HF 機率當作「這位病人該多快排到心臟超音波」的排序依據，而非「該不該做」的守門依據。ruled-in 組 38.5/100 人年的死亡或心衰竭住院率，本身就足以支持優先安排。

不建議直接套用的情境

  • 台灣及多數亞洲醫療體系。 三個獨立理由：(a) 模型 85.1% 為白人，亞裔僅 6.2%（n=33,367），且各族裔次組表現僅見於未取得的 Supplementary Table 5；(b) 台灣心臟超音波的可近性遠高於 NHS，「省下 29% 心臟超音波」這個核心價值主張在台灣的邊際效益低得多，但「多漏 3/1000 例心衰竭」的代價完全不變——成本效益比在台灣是不利的；(c) 模型部分學習的是英國基層照護的編碼與轉介行為（見 B/D 段），此行為模式不可轉移。
  • 急性/院內疑似心衰竭（本模型的 pre-test probability 與臨床脈絡完全不同；該情境應用 CoDE-HF）。
  • 無症狀者的 Stage B 心衰竭篩檢（作者已明確排除此推論）。
  • NT-proBNP 檢驗平台與英國不同的機構（作者自承無法校正 inter-assay 差異）。
  • 任何以本模型取代臨床判斷、直接決定「不做心臟超音波」的用法——rule-out 的 LR− 為 0.14，並未達到「大幅改變診斷機率」的 <0.1 標準。

給臨床醫師的實務建議

  1. 把 PRECISE-HF 當成排序工具，不是守門工具。 rule-in 的 LR+ 7.06 意味著被「ruled in」的病人仍有 55.9% 沒有心衰竭；rule-out 的殘餘機率為 1.5%。這兩個數字都不足以取代心臟超音波，但足以決定誰該在兩週內做、誰可以排到六週後。
  2. 記住這個換算比例：每少做約 48 次心臟超音波，就多漏掉 1 例心衰竭（144 ÷ 3 = 48）[自行計算]。這個比值是否可接受，取決於你所在體系的心臟超音波稀缺程度——在 NHS 可能划算，在台灣多數醫學中心大概不划算。這是本文最應該、卻沒有明白呈現給讀者的臨床決策數字。
  3. 若要使用線上計算器，務必填滿所有欄位。 XGBoost 的原生缺值處理會把「欄位空白」本身當成一個有訊息量的訊號來學習（見 D 段）；在英國基層資料中「沒量 BMI」與「有量 BMI」代表不同的病人族群，但在台灣門診留白通常只代表「懶得輸入」。空白欄位在此模型中不等於「無資訊」，而等於「英國式的無紀錄」，可能導致系統性誤估。

SKILL-C：診斷研究與臨床預測模型評讀

A. 補充技術細節

  • Reference standard 是否為公認黃金標準？ 否。 標準為「12 個月內基層照護 SNOMED-CT 心衰竭診斷碼，或住院紀錄任一診斷欄位的 ICD-10 心衰竭碼」。這既非影像學確認（無 LVEF、無任何心臟超音波參數），亦非依 ESC/通用定義的標準化條件（利鈉肽 + 結構/功能異常 + 症狀徵象）。住院端採「任一診斷欄位」（any diagnostic position）進一步降低特異度——住院期間任何被記錄的心衰竭合併症碼都會被計為 outcome。41.2% 的 outcome 來自這個低特異度的住院定義。

  • Reference standard 是否獨立於 index test？ 明確不獨立，這是本研究最核心的內部效度問題。 在英國，NT-proBNP 於基層照護僅獲授權用於心衰竭診斷用途，且 NICE NG106 以 400 pg/mL 決定轉介急迫性。因此：NT-proBNP 值 → 決定是否/多快轉介心臟超音波 → 決定是否被確診並編碼 → 即為 outcome。這不是輕微的部分驗證偏差（partial verification bias），而是index test 直接位於產生 reference standard 的因果路徑上。由於 NT-proBNP 貢獻模型預測的 >80%，模型在相當程度上學到的是「誰會被英國基層醫師編碼為心衰竭」，而非「誰真的有心衰竭」。

  • Index test 施測者是否對 reference standard 盲目（反之亦然）？ 不適用於盲化設計，但實質上是反向的完全揭露——做出診斷的臨床醫師知道 NT-proBNP 值，且該值正是他做決定的主要依據。

  • 潛在的 incorporation bias（納入偏差）：模型的第 4 重要變項為「NT-proBNP 前 12 個月內的迴圈利尿劑處方」（14.8% 的世代有此處方）。在基層照護中，開立迴圈利尿劑往往已代表醫師懷疑並經驗性治療心衰竭/體液滯留。以「醫師已經在治療心衰竭」來預測「醫師會不會把心衰竭編碼上去」，其預測力有一部分是套套邏輯而非診斷資訊。同樣的疑慮較輕微地適用於「AF 病史」（新發 AF 常同時觸發心衰竭編碼）。

  • 疾病嚴重度分布 / spectrum bias：世代中位 NT-proBNP 僅 123 pg/mL（IQR 54–340），代表近半數受測者的 NT-proBNP 低於 ESC rule-out 閾值。這在真實社區情境是恰當的（避免只納入「明顯正常 vs 明顯異常」），是本研究的明確優點——與外部驗證世代（全部 >300 pg/mL）形成鮮明對比。

  • Cut-off 設定方式：非預先指定，且源自同一資料集。 rule-out 4.7%、rule-in 21.6% 這兩個機率閾值是在資料中搜尋以達成「sensitivity ≥90%」「specificity ≥90%」的目標而反推得出。文中未說明是在 derivation set 還是 internal validation set 上搜尋。若在 validation set 上搜尋（正文的敘述順序「The best performing model was chosen and rule-out and rule-in thresholds were identified」暗示在選定模型之後），則報告於同一 validation set 的 90.0% / 90.0% 是被最佳化過的樂觀估計（optimism bias），實際的樣本外表現會略低。[推論：依正文方法段敘述順序；未明確說明]

  • 測試結果的可重複性：NT-proBNP 檢驗平台不明、無法校正 assay 間差異（作者自承）。BMI/血壓/eGFR 取「NT-proBNP 前 12 個月內最近一筆」，時間偏移可達 12 個月，測量情境不受控。

核心判讀：本文報告的 LR 皆已由作者計算，無需自行推導；重點在解讀。依 LR 的臨床意義分級，PRECISE-HF 的 rule-out 與 ESC ≥125 落在同一個 LR− 級距（0.1–0.2），兩者在「排除心衰竭的資訊量」上沒有臨床上有意義的差別。真正改變的是 rule-out 的 specificity（55.3% → 70.9%），也就是「少轉介多少沒病的人」，而不是「排除得多乾淨」。這一點在論文的呈現方式中被 "superior diagnostic performance" 的措辭模糊掉了。

rule-in 端的改善較實質：LR+ 從 4.37 提升到 7.06（+62%），是本研究最紮實的增益。但 7.06 仍未達 >10，意味著被「ruled in」的人裡 55.9% 沒有心衰竭——這是一個「加速排隊」的閾值，不是一個「可以開始開藥」的閾值。

Diagnostic odds ratio 的誠實摘要：DOR 從 17.5 → 22.0（rule-out 端）與 17.2 → 21.5（rule-in 端），即整體診斷資訊量提升約 25%。這是對「PRECISE-HF 到底好多少」最不受閾值選擇影響的一句話回答：中等幅度的改善，而非量級躍升。

臨床意涵：

① 建模（Derivation）— 部分達標

缺值處理的深層問題（本研究最被低估的風險）

作者選用「XGBoost + 原生缺值處理 + 完全不插補」的組合，並將其宣傳為臨床便利性（「有些變項在評估當下可能取不到，XGBoost 可以處理缺值」）。但這帶來三個未被討論的後果：

  1. 缺值本身成為預測訊號。 XGBoost 的原生處理方式是為每個分裂節點學習一個「缺值往哪一邊走」的預設方向。當 43% 的 BMI 缺失、46.4% 的人至少缺一項時，模型必然學到「沒有紀錄 BMI 的人」與「有紀錄的人」在心衰竭機率上的差異。在 CPRD 中，是否有 BMI/血壓紀錄反映的是診所的資料登錄習慣、病人的就診頻率與慢性病管理計畫納入狀況——這些是英國基層照護的組織特徵，不是病人的生理特徵。

  2. 這極可能是外部驗證 AUROC 從 0.898 掉到 0.757 的重要原因之一。 瑞典的資料完整性模式與英國 CPRD 不同，模型所依賴的「缺值訊號」在瑞典代表完全不同的意義。作者將外部表現下降完全歸因於「缺乏 NT-proBNP <300 的病人」，這是一個合理但未經檢驗的單一解釋；缺值模式不可轉移是同樣合理的競爭解釋，而文中完全未提。

  3. 對線上計算器使用者的實質安全疑慮。 在 https://uogheartfailure.shinyapps.io/precise_hf/ 上，「留白 BMI」與「填入實際 BMI」會走向樹的不同分支，產生不同機率。對英國以外的使用者而言，留白代表「我懶得量」，但模型會把它解讀為「英國基層資料庫中沒有 BMI 紀錄的那類病人」。這個行為差異對使用者不可見，且未在論文中警告。

② 驗證（Validation）— 未達標

內部驗證的核心缺陷：隨機切分不等於驗證。

  • 採簡單隨機切分（70:30）。這只檢驗了同一資料生成過程下的統計穩定性，完全沒有檢驗跨時間或跨機構的可轉移性。
  • 叢集問題（clustering）未被處理：CPRD 資料以「診所（general practice）」為單位聚集，而心衰竭的編碼習慣、NT-proBNP 開單門檻、轉介行為在診所之間差異極大。隨機切分病人意味著同一家診所的病人同時出現在 derivation 與 validation set 中。模型因此可以學習並「驗證」診所層級的編碼特徵——這會系統性高估 AUROC。正確的做法應為 leave-one-practice-out 或以診所為單位的分群交叉驗證，論文未執行也未討論。
  • 未做時間驗證（temporal validation）：資料橫跨 2018-01 至 2025-03，涵蓋 COVID-19 對基層照護與轉介路徑的巨大擾動；且文中自陳 NT-proBNP 檢測量在 2018→2023 增加 88%，代表受測族群的組成在研究期間持續改變（檢測門檻放寬 → 受測者 pre-test probability 下降）。在如此明顯的時間漂移下，未以早期資料訓練、晚期資料驗證，是一個實質的遺漏。

外部驗證：實際上是失敗的，但被描述成「reassuring」

REVOLUTION-HF 世代（n=4,492；HF 1,235 [27.5%]）與 derivation 世代差異極大：中位年齡 78.7 歲 vs 68.8 歲、全部 NT-proBNP >300 pg/mL vs 中位 123 pg/mL、盛行率 27.5% vs 10% [外部: REVOLUTION-HF, Eur Heart J 2025;46:1493]。

(a) rule-out 閾值根本沒有被驗證。 報告的 sensitivity = 100%、NPV = 100%。但被 ruled out 的百分比從未報告。 當全體受試者的 NT-proBNP 都 >300 pg/mL、而 NT-proBNP 佔模型預測 >80% 時，幾乎沒有人的預測機率會低於 4.7% 的 rule-out 門檻。一個排除掉近乎零人的規則，其 sensitivity 與 NPV 必然是 100%，這在資訊上是空洞的（vacuous）。 沒有分母就無法評估一個 rule-out 閾值。這是一個必須補上而未補上的數字，而論文卻把這個空洞的 100%/100% 列為外部驗證的正面結果。

(b) rule-in 閾值的可轉移性實際上崩潰了。 由報告的 specificity 55.5% 與 PPV 40.5%，可反推完整的 2×2 表 [自行計算]：

需要公平地說明：外部世代因 NT-proBNP >300 的入選條件而被高度富集，理論上本就會有更多人越過閾值。但這正是重點——閾值是在特定 case-mix 下訂定的，換一個 case-mix 就失效。作者宣稱「without any need for recalibration」，指的是 calibration slope 1.02 / intercept −0.01；然而 slope/intercept 良好與「操作閾值可直接沿用」是兩件不同的事。前者說的是機率排序與平均水準大致對得上，後者要求整個機率分布相對於固定切點的位置不變。本研究的資料顯示後者不成立。

③ 臨床有效性（Clinical Effectiveness）— 完全未執行

  • 無任何前瞻性試驗證明本模型改善臨床醫師決策或病人結局。 作者誠實承認並明確要求 RCT，這是加分項。
  • 未分析 failure modes：哪些病人型態最容易被模型誤判？被 ruled out 卻確實有心衰竭的那 1,611 人（internal validation）的特徵完全未描述。這是評估臨床安全性的必要資訊。
  • 公平性（fairness）分析不足：ESC ≥125 閾值在黑人族裔的 sensitivity 僅 81%（白人 94%、亞裔 87%），這正是本研究要解決的問題之一。作者宣稱 PRECISE-HF₁₃ 在各次組間「變異較小」，但具體的族裔別 sensitivity/specificity 只存在於無法取得的 Supplementary Table 5。以黑人 n=15,505、亞裔 n=33,367、族裔缺失 3.8% 的樣本，且英國基層照護的族裔登錄品質本身參差，這項核心宣稱在正文中不可核實。既然「族裔造成的診斷不平等」是本文 Introduction 明確舉出的動機，把驗證此動機的數據全部放進補充資料而不在正文呈現，是呈現優先順序上的問題。
  • 可解釋性：僅有變項重要性排序（Supplementary Figure 2，不可得），無 SHAP 或個案層級解釋。對一個要交給基層醫師在門診使用、且要據以「不做檢查」的工具，可解釋性不足。

D. 臨床預測模型評估

D-1. 辨別力（Discrimination）

  • Internal AUROC 0.898（95% CI 0.895–0.900）；精簡版 PRECISE-HF₆ 為 0.894。External AUROC 0.757（未報告 CI）。
  • 極窄的 CI 反映的是樣本量（n=160,674），不是估計的無偏性——CI 寬度無法保護模型免於系統性偏差（叢集、verification bias、閾值最佳化）。
  • AUROC 0.898 的解讀必須考慮世代的異質性。 依 JAMA 指南：「辨別力取決於模型使用族群中預測變項的分布……模型在預測變項差異極大的異質族群中可以很好地辨別，但在較同質的族群中可能失敗」[參考: jama_alba_2017_ug_170001.md，"What Makes a Good Model?" 節]。CPRD 世代年齡 SD 14.2 歲、NT-proBNP IQR 54–340（跨越 6 倍）、涵蓋全 eGFR 光譜——這是一個極度異質的族群。外部世代（全部 NT-proBNP >300、中位年齡 78.7）較同質，AUROC 掉到 0.757 完全符合此原理。 因此 0.898 這個數字不可作為模型在任何特定臨床次族群中的表現預期。

D-2. 校準度（Calibration）

  • Internal：slope 1.023、intercept 0.038、Brier 0.061，Figure 2 十分位點貼合對角線。這是本研究執行得最好的部分之一（許多 ML 診斷論文只報 AUROC 不報校準）。
  • External：slope 1.02、intercept −0.01，Brier 0.163。
  • 但如 C-② 所述：(i) Figure 2 的尺度使得臨床決策所在的 0–6% 區段無法解析；(ii) 未報告 Hosmer-Lemeshow 或等效檢定（在 n=160,674 下 H-L 檢定必然顯著，故省略尚可接受，但應明說）；(iii) external Brier 0.163 在盛行率標準化後代表資訊增益從 33% 降至 18%。
  • 校準良好卻閾值失效是本研究一個值得記住的教訓：slope/intercept 是全域平均的性質，而 rule-out 4.7% / rule-in 21.6% 是局部切點的性質。兩者可以完全脫鉤。任何要以固定機率切點做決策的模型，都應額外報告該切點鄰域的局部校準，本文未做。

D-3. 最關鍵的缺失分析：增量價值（incremental value）從未被量化

這是本文最重要的單一方法學問題。

論文的核心主張是「個人化（把多項臨床特徵與 NT-proBNP 整合）優於通用閾值」。但論文所做的比較是：

【NT-proBNP 連續值 + 12 項臨床特徵 + XGBoost】 vs 【NT-proBNP 二分為 ≥125 pg/mL】

這個比較把兩個獨立的改變綁在一起：(a) 不再把 NT-proBNP 二分化，與 (b) 加入 12 項臨床特徵。二分化一個連續生物標記本身就是眾所周知的資訊浪費；光是 (a) 就足以大幅提升表現。

論文全文從未報告「NT-proBNP 單獨作為連續變項」的 AUROC。 而作者自己報告 NT-proBNP 佔模型預測的 >80%。因此高度可能的情況是：AUROC 0.898 當中，絕大部分來自單純把 NT-proBNP 連續化，而 12 項臨床特徵的邊際貢獻很小。支持此推論的間接證據是：把 13 變項砍到 6 變項（等於刪掉 7 個變項），AUROC 只從 0.898 掉到 0.894（−0.004）。若刪掉 7 個變項只損失 0.004，那麼從 1 個變項加到 6 個變項所帶來的增益，很可能也相當有限。[推論：依據作者報告的變項重要性 >80% 與 13→6 變項的表現差異]

若不報告 NT-proBNP 連續值單獨的 AUROC，就無法回答本文標題所宣稱的問題（「個人化」是否有價值）。 這個分析成本極低（一行程式碼）、且是 TRIPOD 對「新模型是否優於既有預測因子」的標準要求。它的缺席，加上 22 天的審查時程，是相當顯眼的。

同樣缺失的等敏感度比較：正確的模型對比應在相同 sensitivity 下比較 specificity。ESC ≥125 的 sensitivity 為 93.4%；論文應報告「PRECISE-HF 在 sensitivity 設為 93.4% 時的 specificity 是多少」。Figure 1 的 ROC 顯示曲線在 sensitivity ≈0.87 之後已明顯平坦化，暗示此數值會遠低於 70.9%。目前呈現的「specificity 55.3% → 70.9%」有相當部分只是沿著 ROC 曲線往下移動所換來的，而非模型本身的優越性。

D-4. 選擇性排除的偏差方向

方法段規定：12 個月內死亡、且無心衰竭診斷紀錄、且無心臟超音波紀錄者被排除。

被排除者的畫像是：測了 NT-proBNP（因懷疑心衰竭）→ 在一年內死亡 → 但從未被確診也從未做超音波。這群人高度富集於「未被診斷的心衰竭」與「高 NT-proBNP」（極高齡、末期共病、緩和醫療路徑）。把他們移除，等於系統性地移除了一群「NT-proBNP 高但 outcome 為陰性」的人——亦即移除偽陽性。

偏差方向明確：所有策略的 specificity 與 PPV 都被向上偏移。 這對 ESC 與 PRECISE-HF 都適用，故相對比較受影響較小；但兩者的絕對數值（特別是 rule-in PPV 44.1% 與「省下 29% 超音波」）被系統性高估。由於被排除的人數從未報告（無 flow diagram），此偏差的量級無法評估。作者將此排除規則描述為「避免錯誤分類的風險」，未討論其偏差方向。

E. 紅旗清單

設計層面

  1. 🚩🚩🚩 Reference standard 與 index test 之間存在結構性循環：NT-proBNP 決定轉介 → 轉介決定確診 → 確診即為 outcome。模型（NT-proBNP 佔權重 >80%）有相當部分在預測英國基層照護的轉介與編碼行為，而非疾病本身。作者以「400 pg/mL 的 sensitivity 為 80%」辯護，但該數字本身取自同一被污染的參考標準，屬循環論證。
  2. 🚩🚩 Incorporation bias：「NT-proBNP 前 12 個月的迴圈利尿劑處方」為第 4 重要變項。以「醫師已在治療心衰竭」預測「醫師會編碼心衰竭」有套套邏輯成分。
  3. 🚩🚩 內部驗證未處理診所層級叢集：同一家診所的病人同時出現在訓練與驗證集，而心衰竭的編碼與轉介習慣具強烈診所效應 → AUROC 系統性高估。應做 leave-one-practice-out。
  4. 🚩🚩 無時間驗證，但資料橫跨 COVID 且檢測量增加 88%（受測族群組成明顯漂移）。
  5. 🚩 選擇性排除（12 個月內死亡且無診斷無超音波者）方向性地移除偽陽性，向上偏移所有 specificity 與 PPV；排除人數未報告。
  6. 🚩 無 STARD/流程圖、未聲明 TRIPOD/TRIPOD+AI；篩選至納入的完整人數鏈未見。
  7. 🚩 參考標準的住院端採「任一診斷欄位」ICD-10，特異度低，卻貢獻 41.2% 的 outcome。
  8. 🚩 無 LVEF 表型資訊，因此無法得知模型偵測的是 HFrEF 還是 HFpEF（兩者的 NT-proBNP 分布差異極大，臨床處置也不同）。作者已承認。

統計層面

  1. 🚩🚩🚩 從未報告 NT-proBNP 單獨（連續變項）的 AUROC，因此本文標題所宣稱的「個人化的價值」在數據上從未被分離出來。13→6 變項僅損失 AUROC 0.004，強烈暗示臨床特徵的邊際貢獻有限。
  2. 🚩🚩🚩 外部驗證的 rule-out 閾值實質未被檢驗：sensitivity 100% / NPV 100%，但被 ruled out 的百分比未報告；在全數 NT-proBNP >300 的世代中此結果近乎空洞，卻被列為正面結果。
  3. 🚩🚩🚩 外部驗證的 rule-in 閾值失效但被描述為「reassuring」：specificity 90.0% → 55.5%，反推 LR+ 由 7.06 降至 ≈1.79、ruled in 比例由 16.1% 升至 54.2%（[自行計算]）。calibration slope 良好 ≠ 固定切點可沿用。
  4. 🚩🚩 Brier score 未以盛行率標準化即跨世代比較：Brier Skill Score 由 32.8% 降至 18.3%（[自行計算]），實際資訊增益腰斬，被 0.061 vs 0.163 的原始數字掩蓋。
  5. 🚩🚩 無等敏感度（sensitivity-matched）比較：ESC 為 93.4% 敏感度，PRECISE 為 90.0%；「specificity 55.3% → 70.9%」有相當部分是沿 ROC 曲線移動的結果，非模型優越性。
  6. 🚩 閾值在資料中搜尋最佳化，且很可能在報告表現的同一 validation set 上（正文敘述順序暗示如此），造成 optimism bias；未說明超參數調校是否在獨立資料上進行（JAMA ML 指南明列的必查項）。
  7. 🚩 43% BMI 缺失、46.4% 至少缺一項，完全不插補，改由 XGBoost 學習缺值模式 → 缺值本身成為預測特徵；此為外部表現下降的合理競爭解釋，論文未提，且對線上計算器的使用者不可見。
  8. 🚩 LR− 0.14 未達 <0.1 的「大幅改變機率」門檻，與 ESC 的 0.12 同一級距，卻被冠以 "superior"。
  9. 🚩 Figure 4 的預後驗證部分循環：複合終點包含心衰竭住院，而心衰竭住院正是 outcome 定義的組成（占 41.2%）；「7 倍/40 倍風險」被高估，且未提供全因死亡的單獨曲線。

敘事層面

  1. 🚩🚩 摘要用 "superior"，正文結論與 Graphical Abstract 用 "favourable"。摘要是多數讀者唯一會讀的部分，卻使用了作者自己在正文中不願意使用的最強措辭。
  2. 🚩🚩 對照組選擇偏向有利：頭條比較的是 ESC ≥125 pg/mL，但作者自己指出英國實際使用的是 NICE 的 400 pg/mL。400 pg/mL 的 sensitivity（80%）在文中只被順帶提及一句以辯護 verification bias，完整的 400 pg/mL vs PRECISE-HF 2×2 比較從未呈現。以非實務使用的閾值作為主要對照，會誇大在英國情境下的實際增益。
  3. 🚩🚩 「多漏的 3 例處於低風險」超出數據支持：該推論來自整個 ruled-out 組的平均事件率，而非那些實際被漏掉的心衰竭病人的個別結局，後者從未被報告。
  4. 🚩 只講「73 fewer false positives」，不講「9 fewer true positives」：Figure 3 顯示 PRECISE-HF 的 rule-in 組比 ESC 少捕捉 9 例真正的心衰竭（每 1000 人），這 9 人被降級到 grey zone、失去優先排序。正文從未提及。
  5. 🚩 未提供任何 pre-test → post-test 換算，使讀者無法評估在自身盛行率下的適用性，儘管作者明確承認 PPV/NPV 依賴盛行率。
  6. 🚩 族裔次組表現（本文的核心動機之一）全部放在無法取得的補充資料，正文僅以「變異較小」一句帶過。

外推層面

  1. 🚩🚩 整個價值主張綁定於「心臟超音波稀缺」的 NHS 情境。在超音波可近性高的體系（含台灣），「省下 29% 檢查」的效益大幅縮水，但「多漏 3/1000」的代價不變 → 成本效益方向可能反轉。論文的 Discussion 只討論「不同國家路徑不同故需進一步驗證」，未討論此不對稱性。
  2. 🚩🚩 族裔組成 85.1% 白人、亞裔 6.2%、黑人 2.9%、族裔缺失 3.8%；且英國基層照護的族裔登錄品質參差。直接外推至非英國族群缺乏支持。
  3. 🚩 NT-proBNP assay 不明、無法校正 inter-assay 差異（作者承認）；不同平台的絕對值差異可達 10–20%，對一個以 NT-proBNP 為 >80% 權重的模型是實質風險。
  4. 🚩 AF 以「病史」而非測量當下心律定義（作者承認）；而急性 AF 是造成 NT-proBNP 假性升高的最主要原因之一，這正是模型宣稱要校正的目標之一。
  5. 🚩 未收集會造成 NT-proBNP 升高的替代診斷（顯著瓣膜疾病、新發 AF、肺高壓等）（作者承認）。被 PRECISE-HF「ruled out」而未做超音波的病人，也同時失去了發現這些疾病的機會——這是把 rule-out 用於「不做超音波」而非「延後超音波」時，一個被完全低估的機會成本。作者僅將此列為「值得未來研究」，但它其實直接削弱了 rule-out 的臨床安全性論證。
  6. 🚩 贊助者利益與結論框架對齊：AstraZeneca 出資、兩位藥廠員工掛名；核心訴求「更早確診 → 更早啟動疾病修飾治療」與擴大 SGLT2i 使用族群方向一致。且本版本完全沒有 COI 揭露聲明。

F. 最終裁決

診斷測試可信度：中

支持「中」而非「低」的理由：樣本量極大且來自真實社區情境（中位 NT-proBNP 僅 123 pg/mL，避免了 spectrum bias，這是同類研究少見的優點）；變項 a priori 指定而非資料挖掘；辨別力與校準度都有報告（多數 ML 診斷論文只報前者）；有外部驗證嘗試；作者的限制清單誠實且完整，並明確表態臨床採用前需 RCT；所有可核對的內部算術（53,525 = 31,460+22,065 = 37,373+16,152；Figure 3 兩側各 101 例、各 1000 人；Figure 4 三組 at-risk 相加 = 160,674）完全一致；圖表座標軸未見任何截斷或誇大手法。

排除「高」的理由：參考標準為未經判定的行政編碼，且與 index test 存在結構性因果依賴；內部驗證僅為隨機切分、未處理診所叢集、未做時間驗證；外部驗證的兩個操作閾值一個空洞、一個失效；且本文標題所宣稱的核心貢獻（「個人化」的增量價值）從未被與 NT-proBNP 連續值單獨比較而分離出來。

有用的臨床情境（pre-test probability 範圍）

  • 最適用：pre-test probability 5–15% 的社區疑似心衰竭族群，且該體系的心臟超音波為稀缺資源。 在此範圍內，rule-out 可把機率壓到 0.7–2.3%，rule-in 可提升到 27–56%，兩端都有可操作的意義。
  • 使用方式應限於「排序」而非「守門」：把它當成決定「兩週內 vs 六週後」的工具，而不是決定「做 vs 不做」的工具。這樣可以保留大部分效率增益，同時規避漏診與遺漏替代診斷（瓣膜疾病、新發 AF）的風險。

不建議使用的情境

  • pre-test probability >25% 的族群（rule-out 後殘餘機率 ≥5%，且外部驗證顯示 rule-in 閾值在此類族群中 LR+ 僅約 1.8）。
  • 台灣及其他心臟超音波可近性高的醫療體系（效益/代價比不利）。
  • 非白人為主的族群（族裔次組數據不可核實）。
  • 急性/院內情境、無症狀篩檢情境。
  • NT-proBNP 檢驗平台與英國常規不同的機構。
  • 任何情況下都不應在線上計算器中留白欄位（缺值在此模型中是有訊息量的訊號，不是中性的「未知」）。

若要改觀，最需要的 3 個關鍵改進

  1. 報告 NT-proBNP 單獨（連續變項）的 AUROC，以及等敏感度（sensitivity = 93.4%）下的 specificity。 這兩個數字成本近乎為零，卻是回答「個人化到底值多少」與「模型是否真的優於閾值移動」的唯一途徑。在補上這兩個數字之前，本文的核心宣稱在方法學上是未經檢驗的。
  2. 以獨立的、經專家判定（含心臟超音波與 LVEF 表型）的前瞻性社區世代重新驗證，且該世代必須包含完整的 NT-proBNP 光譜（含 <300 pg/mL），並以診所為單位分群、以時間切分驗證。同時報告被 ruled out 卻確有心衰竭者的後續結局與替代診斷（瓣膜疾病、新發 AF）的漏失率。
  3. 在真實臨床路徑中執行隨機對照試驗（PRECISE-HF 導引 vs 現行 NICE/ESC 路徑），主要終點應為病人層級結局（至確診時間、至疾病修飾治療啟動時間、12 個月心衰竭住院或死亡），而非中介的檢查量指標。作者已明確同意此點。

一句話結論（給一般讀者）

把 NT-proBNP 和年齡、腎功能等常規資料一起算成個人化機率，在英國五十多萬人的資料中可減少約三成不必要的心臟超音波，但代價是每省下 48 次檢查就多漏 1 例心衰竭；且此模型在英國以外的可轉移性尚未被證實，臨床採用前仍須隨機試驗檢驗。
