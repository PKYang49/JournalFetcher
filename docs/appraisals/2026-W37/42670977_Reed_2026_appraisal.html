[評估] 事前立場（prior commitment）風險——這是本篇最值得注意的作者層面議題：

ASPIRED 的 sample size calculation 建立在三個假設之上，而這三個假設全部來自主持人自己的既有著作：

  • 未治療 1 年復發率 42.5% → 來自 Reed 本人共同執筆的 2018 ESC guideline（Sup Table 10）
  • 介入組 10.5% 症狀性顯著心律不整診斷率 → 來自 Reed 本人的 PATCH-ED pilot
  • 治療後 90% 不再復發 → 來自 ISSUE-2（Brignole 團隊，與 Reed 為 ESC guideline 共同作者群）

這不是造假，但形成一個封閉的證據循環：pilot 定假設 → guideline 背書假設 → 用假設算 power → 主試驗。當這三個假設有任何一個系統性樂觀，樣本數就會系統性不足。後文 C 節會證明其中一個假設偏差達 30–100 倍。

3. 研究背景 [僅依本次輸入的 protocol 文內資料]

作者引用的既有事實（protocol §1.1）：

  • 英國每年約 650,000 名 syncope 病人到急診
  • 評估後仍有約 50% 病人診斷不明
  • 一個月內嚴重病理事件約 7/100
  • Holter（24–48 小時）診斷率 <20%
  • 已診斷並治療心律不整者，1 年復發率降至約 10%，發作次數下降 >90%（引用 ISSUE-2）
  • SYNARR-Flash：15 天內裝置的診斷 OR 6.2（95% CI 1.3–29.6, p=0.021）
  • Canadian Syncope Risk Score 驗證研究：91.7%（176/192）心律不整事件在 index 後 15 天內出現

知識缺口（§1.1.3）：既有 ambulatory monitoring 研究多為單中心、無對照組、族群異質。作者明確指出關鍵問題——syncope 復發本來就會自發下降（可達 70%），因此觀察性資料會系統性高估任何療法效果，必須做 RCT（§1.1.3）。

**[評估] 這段自我批判寫得非常好，也是本試驗最強的正當性論述。**作者完全正確地識別出 regression-to-the-mean 是這個領域的核心陷阱，並用 RCT 設計去對抗它。諷刺的是，作者隨即在 power calculation 中，把同樣來自單臂 pilot 的診斷率與同樣來自非隨機研究（ISSUE-2）的治療效果，當成確定參數餵進樣本數公式（詳見 C 節）。

Research question（§1.2.1）：在急診 index visit 立即施用心臟監測，是否為偵測、診斷、治療與排除潛在心律不整的最佳策略。

4. 研究設計與方法

PICO [文內, protocol §3]

內容
P ≥16 歲、急性 syncope（TLoC + 無法維持姿勢張力 + 立即完全自發恢復）、經 ED/AMU 初步評估後仍原因不明；當地居民；前 1 個月自述發作 <5 次；有同意能力
I 立即施用 14 天 ambulatory patch monitor（Preventice BodyGuardian Mini），貼於胸骨區，可淋浴/游泳；有症狀事件按鈕 + 紙本症狀日記；14 天後郵寄回廠商判讀
C Standard care monitoring — 「各院對 unexplained syncope 的常規照護，加上某種形式的標準監測，包含但不限於 wired inpatient telemetry、Holter、或 ILR」（V6.0 §3）
O（主要） 1 年病人自述 syncope 發作次數（V6.0）；V1.0 原為「病歷記載 + 自述之複合」

排除條件（§4.3）：已有明確病因（典型 vasovagal 且無結構性心臟病、體位性低血壓、ECG 上已見心律不整、PE/AMI、CVA/TIA/SAH、出血、酒精/藥物、癲癇、低血糖、頭部外傷）、無同意能力、在監所、非當地居民、前 4 週 ≥5 次發作。懷孕不排除。

關鍵設計細節 [文內]

  • 設計：open-label, prospective, parallel-group, 1:1, pragmatic superiority RCT
  • 中心數：protocol V1.0 寫 ~26 家 → V6.0 寫 ~35 家 → SAP V3.0 寫 ~45 家 → 主論文 45 家 [外部: PubMed abstract]。中心數在試驗期間持續向上調整，與 protocol §11.2.1 的「Amber 時擴增中心」stop-go 機制一致，屬透明的適應性招募管理，不是問題。
  • 隨機化：ECTU 管理的 web-based 系統確保 allocation concealment；ECTU database programmer 以電腦產生 pseudo-random number 建立分派序列；依中心 stratify（V6.0 §3）。→ allocation concealment 描述充分且可信。
  • 致盲：「參與者與治療醫師均不致盲」（§5.2）。唯一致盲層級為 central study team 打電話催收資料時對分組致盲（§6.2、§9.2.2）。
  • 收案時窗：V6.0 收緊為「ED/AMU 到院後 72 小時內完成招募與隨機化」；裝置「盡可能在隨機化後儘早施用」，但明文承認「若接近 72 小時才隨機化，裝置施用可能在 index 就診後數天」，且部分中心可用郵寄方式寄裝置給已出院病人（V6.0 §6.1）。
  • 追蹤：2 年；每 4 週（±14 天）自動簡訊/email 連結至網頁問卷，詢問「自上次回報以來的 syncope 次數」與「因任何原因看 GP 的次數」；連續 3 個月未回覆者由致盲的 central team 電訪；月均 ≥5 次者亦電訪確認是否為真正 syncope。EQ-5D-5L 於 baseline、1 年、2 年。
  • 統計：negative binomial regression；中心為 random effect、分組為 fixed effect、追蹤時間為 offset；報告 incidence rate ratio + 95% CI。ITT。
  • 多重比較：SAP 明文 「不做任何多重檢定校正」，理由是「只有一個主要終點，次要終點屬 explanatory 且已預先指定」。
  • Interim：單次 futility analysis（conditional power ≤20% 觸發討論，non-binding）；另有盲性樣本數重估（blinded sample size re-estimation）於 50% 隨機化後執行，且只准往上調。
  • DMC 停止規則：僅針對 30 天死亡率增加（V1.0：「5% level, 90% power」——寫法本身不成立；V6.0 改為單側 2.5%）。無效益方向的停止界線。
  • Adverse events：只記錄與 ambulatory ECG 記錄直接相關的 AE；「住院不記為 AE」；嚴重臨床結果改列次要終點（§10）。

主要變項操作型定義

「Syncope 發作次數」= 病人在每月網頁問卷自述的次數。SAP V3.0 §4.5.1 加入具體歸戶規則：使用到 1 年後第一次完成的回報為止的資料，並將該次回報的事件數依 1 年時點前後的追蹤時間比例分割、四捨五入歸入 1 年主要終點。

8. 臨床建議

可採用本研究結論的臨床情境：

  1. 急診/急診後門診面對 經完整評估仍原因不明的 syncope、且你的照護目標是「縮短取得節律診斷的時間」時——14 天 patch 讓臨床顯著心律不整偵測率由 9% 提升至 22%、診斷時間中位數由 55 天縮短至 22 天 [外部]。這是本試驗最穩健、方向一致、且與機轉相符的發現。
  2. 需要縮短住院觀察 telemetry 的醫療體系決策討論（但成本效益分析尚未發表，見下）。

不建議直接套用的情境：

  1. 不要用「減少昏厥復發」來說服病人或行政單位。主要終點 IRR 0.89（0.68–1.18）既未證實有益、也未排除有意義的益處（見 C1）。
  2. 絕對不要引用「死亡率減半」作為採用理由。這是 ≥30 個未校正次要比較之一，試驗未針對它設計檢定力，效果量的生物合理性亦有嚴重疑問（見 C4）。
  3. 台灣情境外推須極度保守：本試驗為 UK NHS 體系，對照組的「standard care」在部分中心已包含 ILR，在其他中心可能只有 Holter 或什麼都沒有——對照組本身異質且未量化。台灣的 syncope 照護路徑、14 天 patch 的給付狀態、以及心臟科門診可近性都不同。族群方面，收案僅限「當地居民」的英國人口，主論文摘要僅報告年齡與性別，族裔組成無法取得；protocol 有收集 ethnicity，但外推至台灣族群的依據不明。
  4. 成本效益尚未回答。本試驗的健康經濟分析走獨立的 HEAP，尚未發表；NICE 型的採用決策實質上懸而未決。

給臨床醫師的實務建議（3 點，直接可操作）：

  1. 把 14 天 patch 定位為診斷加速工具，不是預後改善工具。對病人的說法應是「這能讓我們更快知道你的心跳有沒有問題」，而不是「這能減少你昏倒」。
  2. 若你的中心正在評估導入，要求看的是「診斷時間」與「後續檢查資源置換」數據（本試驗顯示 patch 可大幅取代後續 Holter/門診 monitoring），而非死亡率。
  3. 不要因為這篇 NEJM 而改變高風險 syncope 的住院決策。試驗設計上刻意不把住院記為 adverse event（protocol §10），且 protocol §1.1.4 事先就用「沒有研究證明住院能改善 syncope 預後」來預先合理化「臨床醫師因為有 patch 而更敢讓病人回家」——這意味著「因裝置而提早出院所導致的傷害」在本試驗的安全性架構中系統性地無法被偵測。

A1. 特殊設計子模組：Pragmatic 裝置策略試驗

本試驗不是 non-inferiority、非手術 RCT、非 platform trial，也非前臨床研究。適用的特殊考量是 pragmatic strategy trial：

  • 對照組未標準化：V6.0 §3 定義 standard care 為「各院常規 + 某種形式的標準監測，包含但不限於 telemetry / Holter / ILR」。protocol §6.1 承諾「我們會記錄各院的 usual care 並與 NICE guidance 比較」——這個承諾是否兌現、對照組實際接受了什麼，是解讀本試驗的關鍵，但無法從本次材料判定 [限制：無主文]。
    • 這一點的重要性被低估了：對照組 9% 的臨床顯著心律不整偵測率 [外部] 顯示對照組並非惰性對照。若某些中心的 standard care 已包含 ILR（診斷率遠高於 Holter），則介入效果會被稀釋；若多數中心只有 Holter，則差距會放大。未報告對照組組成，等於無法判斷這個 22% vs 9% 的差距能外推到什麼樣的基準照護環境。
  • 策略而非裝置：介入是「立即施用 14 天監測」這個策略，不是裝置本身。策略的下游（誰判讀報告、誰決定治療、多快介入）全部「由各院 treating clinician 自行裁量」（§6.1）。這使得試驗回答的是「把 patch 放進現行照護路徑會怎樣」，而非「patch 的診斷效能有多好」——這是恰當的實用性設計，但也意味著陰性主要終點無法區分是「診斷資訊沒用」還是「診斷資訊沒被有效利用」。
  • 「Immediate」的名實不符：論文標題與試驗名稱都強調 Immediate，但 protocol 允許到院後 72 小時內隨機化，且明文允許郵寄裝置給已出院病人，並承認施用可能在 index 就診後「數天」（V6.0 §6.1）。整個試驗的機轉論證建立在 SYNARR-Flash 的「15 天內施用診斷率較高」上——72 小時 + 郵寄延遲仍在 15 天內，因此機轉論證不受損，但標題的 "Immediate" 對真實介入時序有所誇大。實際的中位施用時間 [無法取得]，而這正是評估「immediate」宣稱是否成立的關鍵數字。

B. 批判性評估（四大面向）

B1. 假說與理論邏輯

問題 1：假說是否預先指定？ → 文內證據：是。Protocol V1.0（2021/08）已明確指定單一主要終點與 superiority 假說；SAP 於解盲前定稿；「無計畫中的 subgroup analysis」寫入 protocol §9.2.1。 → 風險方向：低。這是本試驗的明確優點。 → 但有一個內部矛盾：Protocol V6.0 §9.2.1 仍寫「There are no planned subgroup analyses」，而同期的 SAP V1.0/V3.0 明確指定了依 CSRS 分層的主要終點與次要終點 subgroup analysis（含 interaction term）。最終版 protocol 與最終版 SAP 對「有無計畫中次組分析」的陳述直接互相牴觸，且此矛盾在 V6.0（2023/12）時仍未修正。這是文件治理的瑕疵，實務影響有限（SAP 較晚且更具體，且 subgroup 有 interaction test），但顯示 protocol 修訂並未實質校對。

問題 2：機轉是否與情境匹配？ → 因果鏈為：早期監測 → 偵測到心律不整 → 醫師採取治療 → 復發減少 → 死亡減少。這條鏈需要每一環都成立。 → 文內證據：Protocol §9.1.2 假設第 2 環（偵測）產出 10.5%、第 3–4 環（治療 → 不復發）效率 90%。 → 外部證據顯示第 2 環實際超額達成（22% > 10.5% 的假設），但主要終點仍為陰性/不確定。 → [評估] 這是本試驗最有臨床價值的機轉推論：失敗（若真為失敗）不在「偵測不到」，而在「偵測到之後轉不成臨床效益」。可能的斷點有三：

  1. 偵測到的心律不整多數與 syncope 無因果關係。Protocol Table 1 的「clinically significant dysrhythmia」定義極為寬鬆——含「Mobitz I」「sinus pause ≥2.5 秒（清醒時）」「bradycardia <40 bpm 持續 <30 秒」「新發 AF ≥30 秒」「SVT >100 bpm ≥30 秒」。這些在 14 天連續監測下，於中年、夜間、運動員、睡眠期都是常見的偶然發現。監測時間從 24–48 小時延長到 14 天（約 7–14 倍），偶然發現的機率也隨之上升。22% vs 9% 的差距，有相當比例可能是偵測到更多與症狀無因果關係的節律，而非偵測到更多真正的病因。
  2. 第 4 環（治療 → 不復發 90%）的來源是 ISSUE-2——一個非隨機的觀察性研究（早期植入 ILR 後給予特異性治療）。Protocol §1.1.3 自己就精準地警告過：「syncope 復發會自發下降，因此觀察性資料會讓任何療法看起來比實際有效」。**作者用自己識別出的偏差來源，去設定自己試驗的效果量假設。**這是本篇最深的邏輯裂縫。ISSUE-3（隨機、雙盲、pacemaker on vs off）顯示的效果遠比 ISSUE-2 溫和，protocol 未引用 ISSUE-3。
  3. 可治療族群的稀釋：即使 22% 有「顯著心律不整」，實際導向治療的只有節律器 +2.2 pp、抗心律不整藥 +3.5 pp [外部]。也就是說，在 1000 位介入組病人中，只有約 57 人因這個介入而多接受了某種治療。要靠這 57 人去改變全體 1000 人的平均發作次數，數學上幾乎不可能產生 15% 的 rate ratio 變化。

最可能合理機轉（1–3 點）：

  1. 早期 14 天連續監測確實提高「症狀—節律相關性」的捕捉機率（SYNARR-Flash + CSRS 驗證研究支持 15 天窗口），並顯著縮短診斷時間 → 機轉成立且已被本試驗證實
  2. 提早診斷 → 提早植入節律器 → 對「真正的緩脈性 syncope」次族群有效 → 機轉合理，但該次族群在全體中佔比太小，無法驅動 ITT 層級的主要終點
  3. 監測本身的「保證效應（reassurance）」可能降低就醫與自我通報 → 與 3 相反方向的 ascertainment 效應共存

最可疑的敘事跳躍（1–3 點）：

  1. 「偵測率翻倍 → 應納入常規照護」：protocol §1.2.4 在收案前就寫下「能減少發作、減少復發、減少住院、降低成本、提升生活品質」，而試驗只證實了「偵測」。從偵測到臨床效益的跳躍，protocol 從頭到尾當成理所當然。
  2. 「死亡率減半」：見 C4，生物合理性不足。
  3. Protocol §1.1.4 的預先免責：「若某些臨床醫師採用此策略（讓原本會住院的病人回家），不應對結果造成不利影響，因為沒有研究顯示住院能改善 syncope 預後」。用「缺乏證據」來論證「沒有風險」，是標準的邏輯謬誤，且這個假設被寫進了 AE 收集規則（住院不記為 AE），使潛在傷害在設計層次即不可偵測。

(2) 致盲 —— 結構性不可行，且未做任何補償設計 → 文內證據（§5.2）：「Neither participants nor treating clinicians will be blinded to allocation.」唯一致盲是電訪的 central team。 → 這是本試驗最大的偏差來源，且與主要終點的選擇直接相撞：主要終點是病人自述的主觀事件計數，而病人知道自己有沒有戴裝置。SAP §2.2 辯稱主要終點是「quantitative endpoint... 自動化回報直接匯入資料庫以減少 reporting bias」——這混淆了「資料傳輸的客觀性」與「事件認定的客觀性」。自動化匯入解決的是資料謄寫錯誤，完全無法解決「病人是否把一次頭暈算成一次 syncope」。SAP V1.0 原文寫「The primary outcome is an objective endpoint」，V3.0 改為「a quantitative endpoint」——作者自己在後期修訂中悄悄把「客觀」降級為「量化」，等於默認了原始說法站不住腳。 → 風險方向（雙向，淨方向不明）：

  • 偏向介入組不利：介入組被要求「有症狀時按裝置按鈕」+「填寫紙本症狀日記」（V6.0 §6.1）——這是明確的注意力訓練，會提高後續 12 個月對前驅症狀與輕微事件的敏感度與通報傾向。介入組觀察到 mean 1.37 vs 對照 1.58，若存在此偏差，真實差距大於 0.89。
  • 偏向介入組有利：14 天監測結果正常帶來的 reassurance 可能降低通報與就醫。
  • 淨效應無法判定，而 protocol 完全沒有設計任何工具去區分（例如：未收集「事件嚴重度」「是否有目擊者」「是否有外傷」等可用來校正通報閾值的變項）。這是可以事先設計卻沒有設計的缺口。

(3) 主要終點選擇本身 —— 這是設計層次的核心爭議 → 文內證據：Protocol §1.2.3 稱其為「patient focussed primary endpoint」，並引用 James Lind Alliance 急診研究優先順序（§1.1.3）作為正當性。 → [評估] 選擇病人中心終點的動機值得肯定，但執行上選錯了具體指標。「1 年發作次數」有三個致命特性：

  1. 極端過度離散（見 C2，這是本篇最重要的量化發現）
  2. 完全依賴主觀自述，且在 open-label 設計下不可致盲
  3. 只有一小部分病人的發作是介入可能影響的（心律不整性），其餘的 vasovagal / 未明原因發作構成了純粹的統計雜訊，稀釋任何真實訊號 → 更合適的選擇本應是：「達成確定診斷的時間」（作者的次要終點，且結果穩健）或**「syncope 相關再入院/再就診」**（客觀、病歷可查、對病人與體系皆重要）。

(4) 試驗是否提早停止 —— 否 → 單次 futility interim（CP ≤20% 觸發討論，non-binding），DMC 僅監測 30 天死亡率增加。試驗完成全額招募（2234）。無提早停止導致效果誇大的問題。

(5) 依從性 —— 中度稀釋 → 1122 位分派介入者中，930 位（約 83%）產生可判讀紀錄；平均配戴約 12/14 天 [外部]。SAP V2.0（2025/08）才新增 adherence 指標定義（<7 天 vs ≥7 天）。 → 風險方向：ITT 下 17% 無資料者會把效果向無效方向拉。這是實用性試驗的合理代價，但應在主文報告 per-protocol 敏感度分析——[無法取得]。

(6) 對照組適當性（Gyawali 框架）

核心提問：「這是我日常臨床會給病人的治療嗎？」

→ 答案：不確定，因為對照組未被定義。 V6.0 §3 的「包含但不限於 telemetry / Holter / ILR」是一個範圍，不是一個對照組。 → 這產生一個實務上很重要的後果：讀者無法知道 22% vs 9% 的差距，是「patch 對比 Holter」還是「patch 對比 ILR」還是「patch 對比什麼都沒做」。在不同基準照護水準下，這個差距的臨床意義完全不同。 → Protocol §6.1 明訂所有參與者（無論分組）都會被轉介至 syncope 評估、且「理想上 4–6 週內看診」，並依 NICE CG109 安排後續檢查 → 這使對照組優於英國真實世界的一般照護（真實世界中很多病人根本沒有結構化轉介）。對照組被試驗參與行為本身提升了（Hawthorne 效應的一種），這會系統性縮小組間差距，使主要終點偏向無效。 → 這一點對解讀陰性主要終點很關鍵：ASPIRED 比較的是「patch + 結構化 syncope 轉介」vs「結構化 syncope 轉介」，而不是「patch」vs「現行實務」。

(7) 前期 Phase II 支撐 → PATCH-ED（單中心、單臂 cohort pilot，Emerg Med J 2018）。它是單臂的——它可以支持「可行性」與「診斷率」，但在設計上不可能支持任何關於復發率的效果量估計。而 protocol 恰恰用它來設定復發率的效果量。這是「用可行性研究的資料驅動療效試驗的檢定力計算」的典型問題。

B4. 測量工具與實務意義

(1) 測量工具的信度/變異度 → 主要終點沒有任何信效度評估。protocol 唯一的品質控管是「月均 ≥5 次者由致盲 central team 電訪，確認是否為真正 syncope 事件」（§6.2）——只針對高端離群者做單向確認。低估者（把 syncope 誤記為「頭暈」而未通報）沒有任何偵測機制。 → 這個不對稱的資料清理規則值得注意：它只會下修高值，不會上修低值。若兩組的通報閾值不同（因致盲失敗），這個規則的效果也會是不對稱的。

(2) 終點是否有臨床意義？ → 主要終點：中等。 「1 年發作次數」對病人重要（生活品質、駕駛、跌倒風險），但作為連續計數，它把「一次無外傷的 vasovagal 前驅暈厥」與「一次導致骨折的 asystolic syncope」等值計算。這是嚴重的 outcome hierarchy mismatch——病人在意的不是次數，是嚴重度與後果。 → 次要終點「臨床顯著心律不整偵測」：surrogate。 它是診斷過程指標，不是病人結果。本試驗的核心弔詭就是：**surrogate 大幅改善，patient-important outcome 未改善。**這正是為什麼不能用偵測率去支持「應納入常規照護」。 → 次要終點「診斷時間」：有意義的過程指標。 55 → 22 天的縮短，對「等 Holter 排程等三個月」的體系是真實的價值。

「就算結果是真的，真實世界可能有多大用處？」

以外部數字推算 [推算，假設每組約 1000 人]：

  • 多偵測到心律不整：(22% − 9%) × 1000 ≈ 130 人
  • 多植入節律器：(6.8% − 4.6%) × 1000 ≈ 22 人
  • 多起始抗心律不整藥：(10.8% − 7.3%) × 1000 ≈ 35 人
  • 減少的 syncope 發作：(1.58 − 1.37) × 1000 ≈ 210 次（但 95% CI 涵蓋「多 250 次」到「少 500 次」）

→ **也就是說：每 1000 位病人多做 1000 次 14 天監測、多偵測 130 個「顯著心律不整」，最終只轉化為 22 個額外節律器。約 108/130（83%）的額外偵測沒有導向任何節律介入。**這個轉化率本身就是本試驗最重要的臨床訊息：大部分被 14 天 patch 抓到的「clinically significant dysrhythmia」，臨床醫師看完之後決定不處理。

Neutral vs Negative vs Inconclusive 的實務差異：

  • 若為 Neutral，臨床建議會是「兩種策略等效，選便宜的」
  • 若為 Negative，建議會是「不要為了減少復發而做」
  • 實際為 Inconclusive，正確的建議是：「這個問題還沒有被回答，需要一個檢定力足夠的試驗，或改用更合適的終點」

C2. Underpowered 判斷與 Winner's Curse ⭐ 本評讀的核心量化發現

Underpowered 定義：CI 同時包含 null 與 MCID → 樣本不足以回答問題。本試驗符合此定義。

但真正嚴重的是為什麼它 underpowered。

(a) Overdispersion 假設的災難性偏誤

Protocol §9.1.2 明訂：over dispersion = 0.25。在 negative binomial 的標準參數化下（Friede & Schmidli 2010，即 protocol 引用之文獻 [26]）：

$$\mathrm{Var}(Y) = \mu + \phi\mu^2$$

以計畫假設代入（μ ≈ 1.5、φ = 0.25）：

$$\mathrm{Var} = 1.5 + 0.25 \times 2.25 = 2.06 ;\Rightarrow; \mathrm{SD} \approx 1.44$$

實際觀察到的（NEJM 摘要）[外部]：

組別 mean SD 隱含 Var 隱含 φ
介入 1.37 5.10 26.0 ≈ 13.1
對照 1.58 8.56 73.3 ≈ 28.7

真實的過度離散參數比 protocol 假設值高出約 50–115 倍。

這不是小幅偏差，而是根本性的分布誤判。作者在 protocol §9.1.2 中寫道「ESC Guidelines 建議發作次數對 Poisson 分布有良好配適」——實際資料離 Poisson（φ=0）遠到不能再遠。少數病人一年發作數十次（SD 8.56 搭配 mean 1.58，數學上要求存在極端長尾），主導了整個變異數。

(b) 由此推算的實際檢定力 [推算，方法如下]

從發表的 CI 反推主要分析的標準誤：

$$\mathrm{SE}[\log(\mathrm{IRR})] \approx \frac{\ln(1.18/0.68)}{2 \times 1.96} = \frac{0.5517}{3.92} \approx \mathbf{0.141}$$

計畫所需的標準誤（90% power、雙側 α=0.05、偵測 IRR 0.85）：

$$\mathrm{SE}{\text{required}} = \frac{|\ln 0.85|}{z{0.975} + z_{0.90}} = \frac{0.1625}{1.96 + 1.282} = \mathbf{0.0501}$$

$$\Rightarrow \text{實際 SE 為計畫值的 } \frac{0.141}{0.0501} \approx \mathbf{2.8 \text{ 倍}}$$

對應的實際檢定力：

$$z = \frac{0.1625}{0.141} = 1.15 ;\Rightarrow; \text{Power} = \Phi(1.15 - 1.96) = \Phi(-0.81) \approx \mathbf{21%}$$

ASPIRED 在計畫階段宣稱有 90% 檢定力偵測 IRR 0.85；依發表的信賴區間反推，實際執行時對同一效果量的檢定力約為 20%。

[推算依據：假設報告之 CI 為 Wald 型、對數尺度對稱；實際模型含中心 random effect 與 follow-up offset，故此為近似值。核心結論——實際精確度遠低於計畫值——對合理的模型設定變化都穩健。]

(c) 為什麼盲性樣本數重估沒有救到它？——這是本試驗最尖銳的方法學缺陷

Protocol §9.1.2 與 SAP §4.3 都預先指定了盲性樣本數重估，其目的正是為了防範 overdispersion 假設錯誤：

「將對兩組合併的主要終點資料配適 negative binomial 模型，估計整體事件率與 shape parameter（反映過度離散程度），再代入標準樣本數公式取得修正後的樣本數估計。只有在盲性重估建議增加樣本數時才會修訂目標樣本數。」

這個機制設計得完全正確。但：

  1. 時機錯誤：重估在「約 50% 參與者完成隨機化」時執行。收案期 24 個月（2022/07–2024/06），主要終點需 12 個月追蹤。在收案進行到一半（約 2023 年中）時，絕大多數受試者尚未完成 1 年追蹤。此時可得的主要終點計數是被截斷的部分追蹤資料——而截斷的計數資料會系統性低估長尾與過度離散。這個重估在設計上就注定會低估 φ。
  2. 最終樣本數 = 原始目標：2234 人 [外部]，與 protocol V1.0（2021/08）的 2234 完全相同。也就是說，重估沒有觸發任何樣本數增加，儘管最終資料顯示 φ 被低估了 50–115 倍。
  3. Protocol V6.0 唯一的招募面調整是把收案期由 18 個月延長至 24 個月（V6.0 版本異動理由），這是為了達成原目標，不是增加樣本數。

**一個為了防範特定失效模式而預先設計的保護機制，因為執行時機的選擇而在該失效模式真正發生時失去了作用。**這是本試驗最值得寫進方法學教材的一點，也是主文若未討論即構成報告缺漏之處。

(d) 這是 Winner's Curse 的反面情境

本試驗的主要終點是非顯著的，因此不存在「underpowered positive → Type M 誇大」的問題。但同樣的低精確度邏輯，直接適用於被大力宣傳的次要終點死亡率（見 C4）：在極低檢定力的環境中，唯有隨機偏高的估計值才能跨過 p<0.05 的門檻。「死亡率減半」正是這樣一個估計值。

(e) 明確排除的錯誤做法

本評讀未使用、也不應使用 post-hoc power（= f(p-value)，零資訊量，CONSORT 2010 明文禁止）來判定檢定力不足。上述判定完全基於：(i) CI 同時涵蓋 null 與預先指定的 MCID；(ii) 由發表 CI 反推的實際 SE 與 protocol 明訂的計畫 SE 之比較。這兩者都是先驗設定與觀察精確度的對照，不是 p 值的重新包裝。

C3. Bayesian 補充分析的必要性評估

依 Zampieri / Harrell 框架，Bayesian 補充分析在兩種情境下最有價值：(1) p 接近 0.05；(2) Neutral vs Negative 的區分有臨床意義。

本試驗兩者皆不適用：

  • p = 0.42，遠離 0.05
  • CI 寬度（0.68–1.18，比值跨幅 1.74 倍）使 Pr(ROPE) 在任何合理的 ROPE 界定下都不可能高。若以 ROPE = [0.85, 1.18]（即 MCID 之間），CI 有相當比例落在 ROPE 之外，等效性主張無法成立。

因此 C3 的正確結論是：本試驗不需要、也無法藉由 Bayesian 分析從「inconclusive」升級為「neutral」。任何形式的分析都無法從這筆資料中製造出它沒有的精確度。唯一的解方是更大的樣本或更合適的終點。

（依 Skill 規範，本節不編造未執行的 Bayesian 數值。）

  2. 實際流失是預期的 10 倍以上。Protocol §9.1.3 依 pilot 預期流失 <1%，並僅額外招募 5% 作為緩衝。實際 11.8% 遠超緩衝，這本身就會侵蝕檢定力（與 C2 的 overdispersion 問題疊加）。
  3. 差異性流失 2.5 個百分點，對照組較高。方向上，這意味著對照組中「完全不回應」的病人被排除的比例較高。若不回應與健康狀態相關（重病、死亡、失能、對研究失去興趣），兩組被排除者的性質可能不同，違反 MAR 假設。
  4. 與死亡率分析的交互作用是關鍵未解問題：一位在第 2 個月死亡、從未完成任何月度問卷的病人，是否被排除？若主要分析排除他而死亡率分析納入他，兩個分析的分母不同；若死亡率分析也用 1970 的分母，則早期死亡者被系統性排除，而早期死亡正是可能出現組間差異之處。[無法取得]——需要主文的分析族群定義與 CONSORT flow 才能判定。這是本篇最需要被審稿人追問、而本次材料無法回答的問題。

SAP 的缺失資料規則是否被執行？ SAP §3 寫「若結果變項缺失 >5%，將考慮（will consider）進行 multiple imputation」。缺失達 11.8%，遠超門檻。「will consider」是弱承諾用語，未預先指定觸發後必須執行。主文是否執行 MI [無法取得]。若僅呈現 complete-case 分析而未做 MI 或 tipping-point 敏感度分析，即為報告缺陷。

一個被試驗自己的統計分析計畫定義為「僅供解釋用途」的終點，在主要終點陰性/不確定的情況下，被推上了新聞標題、並被用來支持改變臨床實務的建議。這是本試驗最嚴重的 claim–evidence mismatch。

(4) ⭐ 死亡率次要終點的定量檢驗

(a) 統計脆弱性 [推算]

以 1.5% vs 2.9%、分母約 1004 / 966 推算：

  • 介入組死亡數 ≈ 15；對照組 ≈ 28
  • $\ln(\mathrm{OR}) = \ln!\left(\frac{15/989}{28/938}\right) = \ln(0.508) = -0.677$
  • $\mathrm{SE} = \sqrt{\tfrac{1}{15}+\tfrac{1}{989}+\tfrac{1}{28}+\tfrac{1}{938}} = 0.323$
  • 95% CI ≈ 0.27 – 0.96

[推算依據：假設分母為主要分析族群、事件數由百分比回推取整；實際數值需以主文為準。]

→ 即使在完全未校正的情況下，上界已逼近 0.96。**若對 40 個檢定做任何形式的多重性調整（即使只是 Holm 的前幾步），這個區間就會跨越 1。**這個發現的統計穩健度極低。

(b) 生物合理性——更致命的問題 [推算]

介入所產生的、唯一可能影響死亡率的因果路徑，是「多做的治療」：

  • 額外節律器植入：2.2 pp × 1000 ≈ 22 人
  • 額外抗心律不整治療：3.5 pp × 1000 ≈ 35 人
  • 需要解釋的死亡差：約 13–14 人

要讓這 22 個額外節律器解釋 13 個避免的死亡，等於要求「每 1.7 個額外植入的節律器就在 1 年內救回 1 條命」。

這在臨床上不可信。族群平均 58.3 歲，1 年全因死亡 1.5–2.9%——這個量級的死亡絕大多數來自惡性腫瘤、感染、心衰竭、腦血管疾病等與節律毫不相關的原因。即使節律器對緩脈性猝死有 100% 的預防效果，可歸因的死亡分率也遠低於觀察到的差距。

(c) 反向解釋更合理

  • 對照組 2.9% 可能是偶然偏高（28 例的 Poisson 變異相當大）
  • 差異性排除（對照組多排除 145 人 vs 介入組 119 人）可能與死亡/重病相關，造成分母與事件的錯配
  • 純粹的多重比較偶然（40 個檢定中期望 2 個假陽性）

(d) 唯一誠實的表述

「觀察到 1 年全因死亡的數值差異（1.5% vs 2.9%）。這是一個未經多重性校正的次要終點，試驗未針對死亡率設計檢定力，效果量的大小超出可歸因於所觀察到之治療差異的合理範圍。應視為需要獨立驗證的假說產生（hypothesis-generating）發現，不得作為臨床決策依據。」

主持人自己說的「further research explores the observed survival benefit」方向正確，但「survival benefit」這個名詞已經預設了結論——正確的用語是 "the observed mortality difference"。

(5) Adverse event 收集的系統性不足

  • 文內證據（protocol §10）：「唯一會記錄的 AE 是那些與初始 ambulatory ECG 記錄直接相關者」；「住院不會被記為 AE」；嚴重臨床結果改以次要終點收集；且只在第 2 個月的自動問卷詢問一次「前 2 個月是否有配戴裝置的相關併發症」。
  • 實際：49 vs 8 AE（約 6 倍）[外部]，SAE 各 1。推測主要為皮膚反應/接觸性皮膚炎。
  • [評估] 三個問題：
    1. 只問一次、只問前 2 個月 → 系統性低估
    2. 對照組的「AE」定義是「與初始 ambulatory ECG 記錄相關」，但多數對照組病人可能根本沒戴任何裝置 → 兩組的 AE 分母在概念上不對等，6 倍差距的解讀受限
    3. 最重要：因裝置而改變的處置決策（例如原本會住院觀察的病人被直接出院）所導致的傷害，在設計上被排除於 AE 收集之外，且 protocol §1.1.4 事先就用「沒有證據顯示住院有益」加以合理化。這是傷害的設計性盲區。

E. 紅旗清單

設計

  • Open-label 試驗以病人自述主觀事件計數為主要終點，且介入組被訓練用按鈕與日記記錄症狀 → 通報敏感化的方向性偏差，且無任何設計可校正

  • 支持：Table 1 定義寬鬆；14 天連續監測必然增加偶然發現；83% 的額外偵測未導向節律介入——臨床醫師看完報告後決定不處理，這本身就是「這些發現多半不重要」的臨床判斷；syncope 復發本就自發下降（作者自己在 §1.1.3 指出）
  • 反對：診斷時間中位數 55 → 22 天的縮短是真實的；22% vs 9% 的差距太大，不太可能全是雜訊；節律器植入率確實上升
  • [評估] 部分成立。最可能的真實情況是解釋 1 與 2 的混合：介入對真正的心律不整性 syncope 次族群有效，但該次族群在全體中佔比太小，且被大量偶然發現與非心律不整性發作稀釋。

替代解釋 3：主要終點的測量誤差淹沒了真實訊號

  • 支持：SD 5.10 / 8.56（mean 僅 1.37 / 1.58）顯示極端長尾——少數病人主導整個變異數，而這些高頻發作者最可能是 vasovagal 而非心律不整性（心律不整性 syncope 通常不會一年發作數十次）；SAP V2.0 需要專門新增離群值排除敏感度分析；自述計數在 open-label 下不可致盲
  • 反對：negative binomial 模型正是為過度離散設計的；SAP 有預先指定敏感度分析
  • **[評估] 高度成立，且與解釋 1 是同一件事的兩種說法：測量的雜訊淹沒了訊號 = 精確度不足以偵測效果。**這也直接指向改進方向：換終點。

替代解釋 4：觀察到的死亡率差異是偶然 + 差異性排除的產物，而非真實效果

  • 支持：未校正 CI 上界逼近 1（推算 0.27–0.96）；40 個檢定中期望 2 個假陽性；效果量生物不合理（22 個節律器解釋 13 個死亡）；對照組多排除 26 人（145 vs 119），若排除與健康狀態相關則分母失衡；主要終點方向溫和（0.89）而死亡率方向極端（0.50）——兩者的效果量不一致本身就是偶然性的訊號
  • 反對：方向與早期診斷的因果邏輯一致；理論上早期發現致命性心律不整（VT/VF/完全性阻斷）可救命
  • [評估] 這個解釋明顯優於「真實存活益處」。兩組主要終點差異溫和、次要終點差異極端，這種效果量的內部不一致是典型的偶然發現特徵。

G. 最終裁決

整體可信度：中

評分理由：

內部效度的執行面（試驗如何被跑）——高： 中央 web 隨機化 + 分派隱藏、中心分層、45 個 NHS 中心、獨立 CTU（Edinburgh CTU）主導分析、獨立 TSC 與 DMC、事前 SAP、預先指定的盲性樣本數重估與 futility interim、預先指定含 interaction test 的次組分析、完整的 protocol 與 SAP 版本異動史公開。這份 protocol 與 SAP 的透明度，坦白說優於多數 NEJM 論文的補充資料——本評讀之所以能做出上述診斷，正是因為作者公開了完整版本史。這一點應予明確肯定。

內部效度的設計面（試驗問了什麼、怎麼量）——低至中： 主要終點的選擇（open-label 下的病人自述主觀計數）與其分布特性（過度離散被低估 50–115 倍）共同摧毀了試驗回答自己主要問題的能力。實際檢定力約 20%。這不是執行失誤，是設計階段的統計誤判，而且是唯一為此設計的保護機制（盲性樣本數重估）因時機選擇而失效。

結論效度（從資料到主張）——低： 主要終點 inconclusive 卻被表述為陰性；SAP 自定義為 explanatory 的次要終點死亡率被推上新聞標題並用於支持臨床實務改變。

可採用的條件

  1. 「14 天早期 patch 提高心律不整偵測率（22% vs 9%）並縮短診斷時間（55 → 22 天）」 — 可採用。這是大型 RCT 的穩健發現，方向明確、效果量大、與機轉一致，且優於試驗自己的事前假設（10.5%）。
  2. 在缺乏及時 Holter/ILR 排程的體系中，作為診斷路徑加速工具 — 可採用，但應同時告知病人「這不會減少你昏倒的次數」。
  3. 「14 天監測對 1 年 syncope 復發的效果尚未被回答」 — 這是本試驗最誠實的可採用結論。

不建議採用的情境

  1. 不得引用死亡率降低。 未校正次要終點、無檢定力設計、效果量生物不合理、內部效果量不一致。
  2. 不得將主要終點解讀為「證實無效」。 CI 完全涵蓋預先指定的 MCID。
  3. 不得直接外推至台灣的成本效益或給付決策。 健康經濟分析尚未發表；對照組組成未報告；族裔與體系差異未評估。
  4. 不得作為改變高風險 syncope 住院決策的依據。 該方向的傷害在本試驗設計上不可偵測。
  5. 不得外推至 >75 歲、衰弱、或無同意能力族群。 設計上被排除。

若要改觀，最需要的 3 個關鍵改進

  1. 更換主要終點。 「1 年發作次數」在 open-label 設計下不可致盲、極端過度離散、且把 vasovagal 與心律不整性事件等值計算。應改為 (a) 客觀的 syncope 相關再就診/再入院（病歷可查、對病人與體系皆重要），或 (b) 「達成確定病因診斷的時間」（本試驗已證實此終點穩健且效果量大）。若堅持用發作次數，必須採用分層或加權嚴重度的複合，而非單純計數。

  2. 修正樣本數與盲性重估的設計。 以真實的過度離散參數（φ ≈ 10–30，而非 0.25）重算；且盲性重估必須在有足夠比例受試者完成完整 1 年追蹤時執行，而非在 50% 隨機化時（此時計數被截斷，必然低估離散度）。依實際 SE 推算，要在 φ ≈ 9–29 下對 IRR 0.85 達到 90% 檢定力，所需樣本數約為本試驗的 8 倍（SE 需縮至 1/2.8，n 需增為 ~7.9 倍）[推算] — 這實際上意味著**「發作次數」作為主要終點在可行的試驗規模內不可行**，回到改進點 1。

  3. 報告端的紀律。 主文與所有新聞傳播必須：(a) 明確將主要終點表述為「未排除臨床重要益處」而非「無效」；(b) 對死亡率標註「未校正的探索性次要終點，試驗未針對其設計檢定力」；(c) 完整報告對照組實際接受的監測組成；(d) 揭露主要終點推導規則寫定於 2025/08、即全部 1 年追蹤完成之後；(e) 公開 264 位被排除者的基線特徵與死亡狀態，並提供 tipping-point 或 multiple imputation 敏感度分析。

一句話結論

14 天貼片能讓你更快、更常抓到心律不整，但這篇試驗的檢定力其實只有計畫的五分之一，所以「能不能減少昏倒」根本還沒被回答，而「死亡減半」不該相信。

主要終點 p = 0.42，屬 INCONCLUSIVE，非 Negative，更非 Neutral：
