3. 研究背景 [僅根據文內]

既有事實：

  1. SELECT 主試驗顯示 semaglutide 2.4 mg 每週皮下注射，在 BMI ≥27、已有心血管疾病、無糖尿病病史的成人中，將 3-point MACE 降低 20%（6.5% vs 8.0%；HR 0.80, 95% CI 0.72–0.90, P < .001）[文內, Introduction, ref 1]。
  2. 同一試驗中，semaglutide 同時改善了體重、脂肪分布、血糖、血壓、hsCRP、血脂與腎功能 [文內]。
  3. GLP-1 RA 對動脈粥樣硬化的作用可能經由多重機轉（脂質沉積減少、血流動力學壓力降低、內皮功能改善）[文內, ref 3–7]。
  4. 其他 GLP-1 RA 的中介分析：LEADER（liraglutide）指出 HbA1c 為主要中介、UACR 次之；REWIND（dulaglutide）同樣指向 HbA1c 與 UACR [文內, ref 8, 9]。

知識缺口：這些風險因子的綜合改變，是否足以解釋 MACE 的益處，尚不清楚 [文內]。SELECT 排除糖尿病，故基線 HbA1c 與 UACR 分布與既往 GLP-1 RA 糖尿病試驗不同，既有中介結論不能直接外推。

先前內部分析：SELECT 曾做過一次 Cox 迴歸校正分析，結果是「校正體重幾無影響，但校正腰圍使治療效果估計下降三分之一」[文內, ref 10]。本文自我定位為該初步分析的正式升級版。

Research question：在 SELECT 族群中，已測量的心血管風險因子變化，能在多大程度上統計性地解釋 semaglutide 對 MACE 的治療效果？

作者自己設下的認識論界線（值得肯定）：Introduction 明確寫出中介分析「cannot prove causality」、依賴「無未測混淆」等強假設、且「cannot differentiate between a biological mediator and biomarkers of the protective mechanism」。這段自我設限寫得很清楚 — 但如後文所示，這條界線在 Discussion、Graphical Abstract 與新聞稿中逐步失守。

關鍵統計方法細節

  • 主分析方法：Vansteelandt repeated regression（counterfactual 架構）[文內, ref 13]。邏輯為：估計「若 semaglutide 組的中介物軌跡被替換成安慰劑組的軌跡，其 MACE-free survival 會是多少」（= adjusted semaglutide survival）；直接效果 = adjusted semaglutide survival − placebo survival；% mediation = 100 × (1 − 直接效果 / 總效果)。
  • 評估時點：36 個月（預先指定，為完成試驗者的預期最短追蹤時間）。平均追蹤 39.8 個月。
  • 中介物資料：使用至少到 24 個月的重複測量值；所有模型均納入該中介物的基線值作為潛在混淆因子。
  • 遺失值處理：LOCF（last observation carried forward）。各次訪視經 LOCF 填補的比例為 8%–23%，兩組相近 [文內, Table S3]。
  • 主分析族群：ITT（隨機分派至最終追蹤訪視）；另有 on-treatment 補充分析（停藥定義為連續 5 週未用藥）。
  • 補充分析 1：reverse counterfactual — 改以「安慰劑組若經歷 semaglutide 組的中介物值」估計直接效果。兩者差距大時，可能代表真實的 treatment–mediator 交互作用、隱藏混淆，或中介物—結局關係非線性。
  • 補充分析 2：time-dependent Cox regression — 以中介物的 updated mean（AUC/time）為時間相依共變項，% mediation 以 log HR 計算。
  • 收斂問題的後果：體重、SBP、DBP 僅納入部分訪視（週 12, 20, 39, 52, 78, 104, 130）「以避免收斂問題」；多變量模型中血壓只留 SBP、血脂只留 LDL-C，同樣因為「納入太多變項會造成收斂問題」[文內, Methods & Results]。
  • 軟體：SAS 9.4 TS1M5，基於個案層級資料。
  • CI 計算：1000 次 bootstrap 重抽的百分位數。

預先指定程度的實際檢視 [評估]

文章反覆強調此為「pre-specified」「full pre-specified mediation analysis」，候選中介物為「selected a priori」。但 Methods 同時寫道：「After unblinding, the treatment effect on each candidate was evaluated to confirm its viability as a potential mediator」— 這是一個解盲後對中介物清單進行的篩選步驟。加上多變量模型中「留哪個血壓變項、留哪個血脂變項」與「體重/血壓納入哪幾次訪視」均由收斂性事後決定，實際的分析者自由度（analyst degrees of freedom）明顯高於「pre-specified」一詞所暗示的程度。文內未提供統計分析計畫（SAP）的版本、日期或可查閱連結，因此外部讀者無法驗證哪些是真正預先寫定、哪些是事後調整。

③ Graphical Abstract（page_002.png）— 發現一處可驗證的事實錯誤

Key Finding 段落原文可清楚讀到：

「…the treatment effect on major adverse CV events could not be ascribed to these changes with certainty, body weight reduction explaining only 31% of risk reduction.」

這句話是錯的。31%（31.4%）是 Table 2 中八項中介物聯合模型的估計值；體重單獨的估計是 19.5%（Table 1），Cox 法下更只有 9.1%（Table 3）。論文把「所有中介物合計」誤植為「體重」。

這不是無關緊要的排版瑕疵：

  1. Graphical Abstract 是本文流通最廣的元件（社群媒體、簡報、二手引用的主要來源）。
  2. 它系統性地誇大了體重的中介角色達 1.6 倍，而「體重減輕不足以解釋益處」正是本文的核心賣點 — 錯誤的方向恰好削弱了作者自己的論點，但也同時製造了一個容易被錯誤引用的數字。
  3. ESC 新聞稿與後續媒體報導反而是正確的（「約 20% 由體重中介、約 30% 由全部風險因子合計中介」）[外部: ESC press release]，可見 Graphical Abstract 是此處唯一的離群錯誤。

6. 作者討論與評論重點

作者的主要訊息：在 SELECT 中，已知心血管風險因子的改變無法有把握地完整解釋 semaglutide 對 MACE 的效果；值得進一步探索其他生物標記與機轉。

與現有文獻的異同：

  • HbA1c：LEADER 估計高達 83%（Vansteelandt 法）、REWIND 估計 36%（time-updated Cox）；本文 Vansteelandt 為 29%、Cox 僅 13%。作者歸因於 SELECT 排除糖尿病、基線 HbA1c 分布不同。此解釋合理。
  • UACR：LEADER 33%、REWIND 29%；本文僅 14.6%。作者歸因於 SELECT 基線正常白蛋白尿比例較高（84% vs LEADER 63%、REWIND 65%）。此解釋同樣合理且有具體數據支撐。
  • 作者並提及 FLOW 試驗基線白蛋白尿較高，但 FLOW 未觀察到基線白蛋白尿與 MACE 效果的交互作用。

限制（作者觀點） [文內, Discussion 末段] — 逐條列出：

  1. SELECT 未針對任何中介分析做效力計算（not powered for mediation）。
  2. 中介物測量頻率不足；若更頻繁，估計會更精確。
  3. COVID-19 疫情導致共變項遺失（幅度不大且兩組相當），降低精確度。
  4. 競爭風險：部分病人可能在中介物效果顯現前死於非心血管原因，且兩組頻率可能不同；SELECT 已知 semaglutide 減少 COVID-19 與感染死亡，這些非 CV 死亡在安慰劑組構成 CV 死亡的競爭風險。
  5. 最重要：所有中介分析都依賴「無未測混淆」這個無法檢驗的假設；當中介物包含體重與體脂分布時，此問題尤其嚴重，因為體重變化與結局的關係取決於體重為何改變。混淆可能導致 % mediation 被高估或低估。
  6. 明確聲明：「all mediation analyses are exploratory, and the results should therefore be interpreted with caution」。

[評估] 作者限制陳述的完整度：這份限制清單罕見地誠實且具體，特別是第 5 點直指問題核心，並在 Discussion 中用 Table S5 的分組分析、reverse counterfactual 的不一致、以及 ref 10 中「安慰劑組第 20 週減重 >5% 反而 MACE 增加」的觀察，三條線索交叉論證「非意圖性體重減輕（frailty / 共病驅動）是隱藏混淆因子」。這是一段方法學水準很高的自我批判，值得肯定。

但有三項重要限制未被列出：

  • 未討論 LOCF 對中介估計的偏差方向。作者只說遺失比例兩組相當 —「兩組平衡」保護的是總效果的無偏性，完全不保護中介物—結局關聯的估計。LOCF 會壓縮個體內變異、衰減中介物—結局關聯，系統性地把 % mediation 往下拉。8%–23% 的填補比例並非小數目。
  • 未討論 % mediation 這個指標本身在小總效果情境下的病態行為。作者把寬 CI 歸因於「未針對中介分析做效力計算」與「測量頻率不足」，但真正的主因是：% mediation 是一個比值，分母（總效果 = 0.012, CI 0.004–0.020）自身就跨越 5 倍範圍且逼近 0。分母接近 0 時比值會爆炸 — 這就是為什麼 CI 會出現 (−119.2, 158.4) 這種數值。這是指標選擇的結構性問題，而非樣本數問題。
  • 未對競爭風險做任何敏感度分析。作者識別了問題（第 4 點），但僅止於陳述，未執行 cause-specific 分解或 Fine-Gray 模型。在一個橫跨 COVID-19 疫情、且已知非 CV 死亡兩組不均衡的試驗中，這是可以做而未做的分析。

[評估] 臨床建議是否超出數據支持範圍 — 是，且超出得相當明顯：

論文正文的措辭克制（「could not fully ascribe… with any certainty」），但同一組作者在三個不同載體上逐步放大結論：

載體 表述 評估

核心邏輯謬誤：本文得到的是一個不精確的結果，而非一個陰性的結果。四個主要中介物的直接效果 CI 全部包含 0（體重 −0.001–0.019、腰圍 −0.004–0.013、HbA1c −0.001–0.018、hsCRP −0.001–0.016）。形式上，這代表對這四者中的任何一個，都無法排除「完全中介」。作者自己也承認 CI 涵蓋 100%。但接著推論「因此存在未被辨識的機轉」，這在邏輯上是把「證據不足」（absence of evidence）當成「不存在的證據」（evidence of absence）反向使用 — 把無法證明中介，說成證明了非中介。

8. 臨床建議

可採用本文結論的情境：

  1. 在向病人解釋 semaglutide 的心血管益處時，可以說明「益處似乎不只來自減重」 — 但務必同時說明這是一個不確定的推論，不是已證實的機轉。
  2. 不要把「體重下降幅度」當成心血管保護的療效指標或治療目標。本文最可靠的單一發現是 Table S5：時間更新後的體重與 MACE 在兩個治療組中皆無顯著關聯。臨床上這意味著：不應因為某位病人減重幅度不如預期，就推論他沒有得到心血管保護，或據此停藥。這一點的實務意義甚至高於論文的主結論。
  3. 在 SELECT 族群（≥45 歲、BMI ≥27、已有 ASCVD、無糖尿病）繼續依主試驗結果處方 semaglutide 2.4 mg。本文完全沒有削弱 SELECT 主要結果（HR 0.80, 95% CI 0.72–0.90）的效力 — 它只是無法解釋那個結果是怎麼來的。用不用藥的決策，不依賴機轉是否已知。

不建議直接套用的情境：

  1. 不要把任何一個 % mediation 數字引用為定量事實。「腰圍解釋 64%」「減重只解釋 31%」這類說法都不應進入臨床論述 — 前者在反向分析下掉到 21.5%、在 Cox 法下掉到 32.0%；後者在論文自己的 Graphical Abstract 中就是誤植。
  2. 不要外推至糖尿病族群。LEADER 的 HbA1c 中介估計高達 83%，本文為 13%–29%。在糖尿病病人身上，血糖控制的中介角色很可能遠大於本文所示。
  3. 不要外推至初級預防、口服 semaglutide、tirzepatide 或其他 GLP-1 RA。SELECT 為次級預防族群、72% 為男性、66.4% 為 prediabetes、68% 曾有 MI。
  4. 不要用本文支持「應把 hsCRP 當作 semaglutide 治療的監測指標」。hsCRP 雖是本文最穩健的中介訊號，但中介分析無法證明「降 hsCRP 會降 MACE」的因果方向，更無法支持以 hsCRP 為治療目標（target）。

給臨床醫師的實務建議（三點，直接可操作）：

  1. 把這篇論文讀成「一篇誠實的陰性方法學報告」，而不是「一個新機轉的發現」。它真正證明的事情是：SELECT 的資料量不足以回答「為什麼有效」這個問題。這不是壞事，但也不是新發現。
  2. 若要從本文挑一個可信的訊號，挑 hsCRP，不要挑腰圍。hsCRP 是唯一在正反反事實方向、兩種統計方法、兩個治療組別中都保持一致的中介物（42.1% vs 43.1%；Cox 31.0%；兩組皆顯著）。腰圍雖然點估計最大，卻在這三項檢驗中失敗兩項。論文摘要的排序與其自身的穩健性證據方向相反。
  3. 處方決策不需要等機轉釐清。這一點與社論立場一致：SELECT 的隨機化結果本身就是充分的處方依據；機轉知識的價值在於未來的藥物開發與精準分層，不在於當下的用藥決定。

B1. 假說與理論邏輯

問題一：候選中介物清單在解盲後被篩選過

  • 文內證據：「Since including too many variables causes convergence issues in such models, in this multivariable model we included only one of the blood pressure variables (SBP) and one of the lipid variables (LDL cholesterol)」[Results]；以及體重、SBP、DBP「a subset of the assessments (weeks 12, 20, 39, 52, 78, 104, 130) was included in order to avoid convergence issues」[Methods]。

問題三：最合理的生物機轉排序，與論文的呈現順序相反

綜合本文全部內部證據，機轉假說的可信度排序應為：

  1. 抗發炎（hsCRP 路徑）— 最可信。三項穩健性檢驗全部通過（正反反事實 42.1% vs 43.1%；Cox 法仍達 31.0% 且 CI 不跨 0；兩個治療組別皆顯著）。且有獨立外部證據支持：STEP 1/2/3 顯示 hsCRP 下降 39%–48% 與基線 BMI 無關、STEP-HFpEF 顯示 hsCRP 下降非由減重驅動 [外部: EHJ editorial 全文轉述]。

  4. 脂肪量/體脂分布（體重、腰圍）— 不可判定。估計值在各種分析下劇烈擺盪，且已被作者自己診斷為受混淆汙染。

敘事跳躍（最可疑的三處）：

  1. 「無法證明中介」→「存在未知機轉」。Take Home Message：「These data suggest that other unidentified mechanisms could contribute」。但四個主要中介物的直接效果 CI 全部包含 0 — 資料同樣相容於「其中任一者完全中介」。從一個雙向都無法排除的結果，只朝單一方向推論，是選擇性詮釋。
  2. 「腰圍是最大中介物」的呈現。摘要與 Discussion 均以腰圍 64.0% 領銜，但論文自己的 reverse counterfactual（21.5%，CI 跨 0）、Cox 法（32.0%）與分組分析（僅 semaglutide 組顯著）三重證據都指向這個數字不可靠。作者在 Discussion 中確實討論了這個不穩定性 — 但摘要沒有，Graphical Abstract 沒有，新聞稿也沒有。
  3. 「因為機轉未明，所以 semaglutide 應被重新定位為心血管藥」。這個推論在邏輯上是斷裂的：藥物定位取決於療效證據（SELECT 主結果，已充分），而非機轉是否已知。把一個方法學上的失敗轉譯為一個商業定位上的成功，是本文最值得警覺的敘事操作。

Step 4 — 統計謬誤檢查

  • ❌ 「p > 0.05 = no difference」：作者未犯此錯。全文使用 CI 而非 p 值來描述中介估計，並明確說明「CIs that encompass 100% of mediation mean that it is possible that such risk factors may explain the entirety of the drug effect」。這一點做得正確且值得肯定。
  • ❌ Post-hoc power：作者未使用。僅陳述「not powered for mediation」，未計算事後檢定力。正確。
  • ⚠️ 但作者犯了一個相關的錯誤：在正確陳述「CI 涵蓋 100%，故完全中介有可能」之後，緊接著寫「the point estimates for the most likely value of the % mediation are well below 100%, consistent with alternative factors mediating at least some of the effect」— 這是在一個 CI 橫跨 174 個百分點的情境下，訴諸點估計來支撐方向性結論。當 CI 如此之寬時，點估計並非「最可能值」，而只是一個幾乎不帶資訊的位置參數。這是實質上的「以點估計取代區間估計」謬誤。

C2. Underpowered 判斷與 Winner's Curse

Underpowered 判定：✅ 確定為嚴重 underpowered。

依定義（CI 同時包含 null 與 MCID）：

  • 12 個單一中介物中，9 個的 CI 同時包含 0% 與 25%。
  • 3 個聯合模型的 CI 全部同時包含 0% 與 100%。
  • 總效果本身：0.012（0.004, 0.020）— 分母跨越 5 倍範圍。

更根本的觀察：這個分析在執行之前就註定無法給出精確答案。當總效果的 CI 橫跨 5 倍範圍時，任何以它為分母的比值都必然有極寬的區間。作者把不精確歸因於「未為中介分析設計效力」與「測量頻率不足」— 但即使測量頻率加倍，分母的不確定性仍在，CI 仍會很寬。這是指標選擇的結構問題，不是樣本數問題。更穩健的做法是報告絕對尺度的間接效果（例如「經由 hsCRP 中介的存活機率差 = 0.006, 95% CI …」），而非比值。

Winner's Curse 風險評估：

本文無傳統意義上的 underpowered positive（沒有任何「陽性主結果」），因此不存在典型的 Type M 誇大風險。但存在一個變體風險：

  • 在 12 個中介物 × 至少 4 種分析方式（正向、反向、on-treatment、Cox）的超過 50 次估計中，未做任何多重性校正。
  • 在這個規模的估計下，即使全部真值都很小，最大的幾個點估計也必然被隨機高估。
  • 腰圍 64.0% 恰好是全部估計中的最大值 — 而它同時也是最不穩定的（reverse 掉至 21.5%、Cox 掉至 32.0%）。這正是 Type M error 的典型指紋：極端值 + 在獨立檢驗下大幅回歸。
  • 實務警告：任何後續研究若以「腰圍中介 64%」作為效果量假設來計算樣本數，將嚴重低估所需樣本數。這個數字不應被用於任何後續試驗設計。

C3. Bayesian 補充分析

本文的核心主張在形式上是一個等效性 vs 非等效性的判斷：「直接效果是否實質為零？」（即：已測中介物是否完全解釋了效果？）。頻率派的區間估計無法正面回答這個問題 — 它只能說「無法排除」。

因此本案例正是 Bayesian 分析最能發揮作用的情境（依 Zampieri 等 AJRCCM 2021 框架）。若對聯合模型的直接效果計算：

指標 定義 對本文的意義
Pr(ROPE) Pr(直接效果落在實質等效區間內，例如 |直接效果| < 0.003) 唯一能正式量化「已測中介物已完全解釋效果」機率的方法
Pr(substantial direct effect) Pr(直接效果 > 0.006，即 > 總效果一半) 直接量化作者主張的「存在實質未解釋效果」

以三組 prior（skeptical：假設無殘餘直接效果／optimistic：假設存在大量未解釋效果／non-informative）執行，並計算三者間的 I²，即可判斷結論究竟由資料驅動還是由先驗驅動。

評估：作者採用 1000 次 bootstrap 建立 CI，技術上完全有能力從同一組 bootstrap 樣本直接讀出「直接效果 < 某門檻」的比例 — 這幾乎是零額外成本的分析。未做此分析，使得本文的核心主張始終停留在「無法排除」的層次，而無法給出任何正面的機率陳述。 這是本文最可惜的方法學缺口：一個幾乎免費、且能直接回答其核心問題的分析被略過了。

F. 反向解釋

除了作者主張的「存在尚未辨識的心血管保護機轉」之外，以下四個替代解釋在本文資料下同樣（或更）相容：

替代解釋 1：已測風險因子其實完全解釋了效果，只是統計上無法證明

  • 支持線索：四個主要中介物與兩個聯合模型的直接效果 CI 全部包含 0；所有 % mediation 的 CI 上界都遠超 100%（腰圍達 179.6%、6 項聯合模型達 161.0%）。若真有大量未解釋效果，直接效果的 CI 下界應明顯高於 0 — 事實並非如此。此外，LOCF 的衰減偏差、中介物測量誤差（尤其腰圍與 hsCRP）都會系統性低估 % mediation。
  • 反對線索：所有點估計都低於 100%；Cox 法（CI 較窄）的聯合估計僅 32.8%（2.7, 90.1），上界未達 100%。
  • 評估：這個解釋與資料的相容度至少不低於作者的解釋。 作者對它的處理只有一句「CIs that encompass 100%… mean that it is possible」，隨即以點估計為由略過。這是本文最重要的未被充分討論的可能性。

替代解釋 2：整個分解是混淆的產物，% mediation 這個量在本資料中無因果意義

  • 支持線索：作者自己提供的三條證據（reverse counterfactual 不一致、聯合模型低於單項、分組 Cox 關聯不對稱）全部指向中介物—結局關係受混淆汙染且在兩組間不同。當 treatment × mediator 交互作用存在時，自然直接/間接效果的分解在因果上無定義 — 此時「31.4%」不是一個被不精確估計的真值，而是一個根本不存在的量的樣本估計。
  • 反對線索：hsCRP 在所有檢驗下保持穩定，顯示至少部分中介物的分解仍有意義。
  • 評估：對體重與腰圍，此解釋幾乎確定為真（作者自己也接近這個結論）。對 hsCRP 則不成立。這意味著論文應該做的是分別處理兩類中介物，而不是把它們丟進同一個聯合模型後得到 31.4% 並當作頭條。

替代解釋 3：hsCRP 路徑就是主要機轉，而它已被測到

  • 支持線索：hsCRP 是唯一通過三重穩健性檢驗的中介物（42.1% vs reverse 43.1%；Cox 31.0% 且 CI 不跨 0；兩個治療組別皆顯著）。外部證據支持 weight-independent 的抗發炎效應（STEP 1/2/3 中 hsCRP 下降 39%–48% 與基線 BMI 無關；STEP-HFpEF 中 hsCRP 下降非由減重驅動）[外部: EHJ editorial 轉述]。且 CANTOS 已獨立證明單純降低 IL-6/CRP 軸可降低 MACE — 本文完全未引用 CANTOS。
  • 反對線索：hsCRP 點估計為 42%（Cox 31%），未達 100%；且作者正確指出無法區辨 hsCRP 是「發炎標記」還是「體脂量標記」。
  • 評估：這個解釋被論文系統性地低估了。 若把 hsCRP 的 42% 與其在正反方向的一致性放在頭條，論文的訊息會變成「發炎是最可信的中介路徑，而體脂相關指標的估計不可靠」— 這與現有文獻高度相容，也比「存在未知機轉」保守得多。但這個版本的故事在商業上遠不如「未知機轉」有吸引力。

替代解釋 4：LOCF 與測量頻率不足造成的系統性稀釋

  • 支持線索：中介物僅測至 24 個月，結局評估在 36 個月；8%–23% 經 LOCF 填補；停藥者（semaglutide 組佔比較高）的中介物值被凍結在停藥當下。時間相依中介物的測量誤差與外推在數學上必然衰減中介物—結局關聯，進而低估 % mediation。作者自己也把「測量頻率不足」列為限制之一。
  • 反對線索：填補比例兩組相當；作者認為幅度「not very large」。
  • 評估：部分成立，且偏差方向明確有利於論文結論。 論文承認此限制存在，但從未說明它的方向。若明說「LOCF 會讓 % mediation 被低估」，「存在未解釋效果」的論點就會被實質削弱 — 論文對此保持沉默。

一句話定性：這是一份方法學執行良好、報告誠實、但結論被過度詮釋的分析。它最誠實的版本是「SELECT 的資料不足以回答為什麼有效」；它被包裝成的版本是「我們發現了一個未知機轉」。

可採用的條件

  1. 採用其定性結論：「MACE 益處無法單純歸因於減重」，並同時說明此為不確定的推論。
  2. 採用 Table S5 的臨床推論：時間更新後的體重與 MACE 在兩組皆無顯著關聯 → 減重幅度不應作為心血管保護的療效指標或停藥依據。這是本文最可靠、也最具實務價值的發現。
  3. 採用 hsCRP 為最穩健中介訊號這個定性判斷，用於研究議程規劃（而非臨床監測）。
  4. 採用其研究議程設定價值：支持投入 proteomics、發炎路徑與血管修復機轉的研究。

不建議採用的情境

  1. 不引用任何 % mediation 的具體數字作為定量事實 — 包含 64.0%、42.1%、31.4%、19.5%。
  2. **不使用「腰圍是最大中介物」**這個說法 — 論文自身的三項穩健性檢驗已否定它。
  3. 不以本文支持「semaglutide 應被重新分類為心血管藥」 — 藥物定位應依療效證據（SELECT 主結果），而非機轉是否已知。
  4. 不外推至糖尿病、初級預防、老年/frailty、女性為主族群或其他 GLP-1 RA。
  5. 不以本文任何效果量作為後續試驗的樣本數估算依據（Winner's Curse 風險）。

若要改觀，最需要的三個關鍵改進

  1. 改報絕對尺度的間接效果，並以 Bayesian 後驗機率正面回答核心問題。 捨棄比值形式的 % mediation，改報「經由 hsCRP 中介的 36 個月存活機率差 = X (95% CI …)」。並利用現成的 1000 次 bootstrap 樣本直接計算 Pr(直接效果 < 總效果的 10%)、Pr(直接效果 > 總效果的一半)，以三組 prior（skeptical / optimistic / non-informative）檢驗結論對先驗的敏感度（I² < 0.20 為穩健）。這幾乎零額外成本，卻能把「無法排除」升級為可量化的機率陳述。

  2. 以敏感度分析正面量化三個已識別但未處理的偏差。 (a) 用多重插補或聯合模型取代 LOCF，並明確報告 % mediation 變化的方向與幅度；(b) 執行 cause-specific 或 Fine-Gray 競爭風險分析；(c) 執行未測混淆的 E-value 或 bias analysis — 亦即「要有多強的未測混淆（如 frailty）才能把 64% 的腰圍中介解釋掉？」這個數字比「我們懷疑有混淆」有用得多。

  3. 重寫摘要、Graphical Abstract 與對外溝通，使其與內部證據方向一致。 具體而言：(a) 修正 Graphical Abstract 中「body weight explaining only 31%」的事實錯誤；(b) 移除「31% / 69%」二分色塊，改以區間或明確標示 CI；(c) 把 hsCRP（最穩健）而非腰圍（最不穩健）列為主要發現；(d) 把 Table S5 分組分析與 Figure 1 的 reverse counterfactual 數值移入正文；(e) 在結論中明確陳述「直接效果的 CI 包含 0，故無法排除已測風險因子完全中介」。

一句話結論（給一般讀者）

這份研究沒能查出 semaglutide 護心的真正原因，但「查不出」不等於「另有原因」——用藥該不該開，SELECT 早已給了答案，機轉未明不影響處方。
